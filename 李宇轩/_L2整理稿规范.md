# L2 整理稿规范（李宇轩系列）

## 任务定义
把每门课 `1-原始转录/` 里的 ASR 原始转录（语音识别直出：错误多、无结构）整理成可读的 **L2 整理稿**，写入同课程 `2-整理稿/`，**文件名与转录文件相同、扩展名改为 .md**。

## 转换规则（按优先级）
1. **修正听写错误**：用羽毛球领域知识校正同音字/错词。常见错例：
   - 不乏 / 不伐 / 步法混写 → **步伐**（指移动技术时）
   - 切磋球 → **切搓球**（网前搓球的一种）
   - 挥拍被听成 互拍 / 护拍 / 灰拍 → **挥拍**
   - 高远球 / 高运球 → **高远球**；滑板 / 华板 → **滑板**（吊球一种）
   - 人名、群名等按上下文合理推断（如 s群 → 私群），推断不了的原样保留并不要编造。
2. **顺句子**：删除无意义语气词（呃、啊、嗯、那个、OK 之类的纯口癖）和重复口误；把 ASR 断句整理成通顺、口语化的完整句子。
3. **忠实原意，一条不许丢**：这是"接近原意的整合"，**不是缩写、不是总结**。教练讲的知识点、动作细节、示范描述、常见错误、训练方法、答疑内容全部保留。宁可啰嗦也不许丢内容。
4. **轻结构**：按话题自然分段；话题切换明显时可加简短小标题（`## 话题词`），但**不要**做成"核心要点/避坑指南"那种高度模板化笔记——那是 L3 课程笔记的事，L2 只是把原话整理干净。
5. **格式**：第一行 `# <该课标题>`（用文件名里的课名），正文纯 markdown；结尾不加"整理说明""AI 注"之类任何尾巴。
6. **禁止**：添加教练没说的内容；改动技术含义；用 AI 腔改写（"值得注意的是""总的来说"等）。

## 完成标准
工单清单里每个转录文件都有对应的 `2-整理稿/同名.md`。
回报格式：一行 `完成X/总数Y`；如有失败，另起一行列出失败文件名（≤10 行）。不要在回报里引用文件内容。
