# 扑球与抹球（正手/反手 × 高点扑球/贴网抹球）

## 一句话定位
对方回球过网偏高时，在网前直接下压结束回合叫扑球；对方搓/挡出贴网球时，跳起来"反抓"把球快速抹下去也叫扑球。教练明确分两种："一个是高点的直接拍下去……另外一个比较难的，就是别人搓得贴网，我们要上去抹球"，先学高点扑球，再学抹球 [140]。

## 核心要点
- 挥拍框架跟后场高远球一样，只是"没有展肩、没有大引拍"；手伸直与肩同高，立手腕时小臂也往上带一点 [140]。
- 发力顺序铁律：先舒展小臂接近球 → 推手腕 → 抓紧。"千万千万不可以只动手腕""千万不可以先抓了才推"——只动手腕发不上力，提前抓紧没有速度 [140][151]。
- 空间是命根：保持立腕接近球，留出能"边舒展边推手腕"的三角形空间。"为什么你们扑的时候球不会下来，全部都在于你们的空间" [142][143]。
- 球越快，动作越短、越早做："球越快，我要把这个舒展还有往下推的速度做得更加快"，快球一启动就抬拍、迈小步 [143][153]。
- 击球时机：在挥拍速度最快那一下碰球；"太早推手腕就下网，太晚推/太接近球就飘" [141][143]。
- 扑对角比直线安全："对角距离够长，你不用怕它出界"，而且手不会下压、能保持高度；低平球更要压低重心打对角 [141][142]。
- 抹球必改握法：正手从正常握法往反手方向转（拇指放侧棱，"再转多一点是最安全的"）；反手从拇指顶宽面往斜棱转，否则必先碰网带 [146][156]。
- 抹球动作："边推边转，小臂往上收"，抹的是球的侧面不是上面，"好像往上刷的感觉"；推时球拍斜 45 度、绝不竖着立起来 [145][154][156]。

## 常见错误与避坑
- 缩着打：教练反复强调"最重要的点就是不要缩着打"，缩着打没有速度；很多人做不出来是因为没舍得打、动作不对或不会控制空间 [140][143]。
- 时机错了两种死法："太早往下推手腕就下网；往上飘就是太晚推手腕，或还没舒展就碰球" [143]。
- 抹球手放低或拍竖着立："手没有抬上来，每个人都喜欢放下面……必打网带"；抬手必须跟网带同高往外伸 [145][155]。
- 握拍太紧："握紧的话手腕就死……你握得越紧越容易打网，放松越松越好" [149][156]。
- 落地姿势：单腿飞扑落地必须前脚掌，"你用脚后跟就一定会用到膝盖，你就会弯，你就会碰网"；左手往后顶挺胸，含胸就碰网 [148][156]。
- 追身球别用正手："正中间的球最好用反手，正手很难做"——正手肘得折进来发不了力 [157]。

## 高点扑球 vs 贴网抹球 的区别对照
| 维度 | 高点扑球 | 贴网抹球 |
| :--- | :--- | :--- |
| 挥拍 | 舒展→推手腕→抓紧，推到平即可，下压只是惯性 [140][141] | 边推边转、小臂往上收，抹球的侧面，"往上刷" [145][154] |
| 握拍调整 | 三种握法都行（正常/苍蝇拍/李宗伟式），不用改 [140] | 必须改：正手转成拇指放侧棱的反手式握法；反手从宽面转斜棱 [146][156] |
| 时机/位置 | 球高于网时直接下压，右肩前击球，脚落地与推同时 [140][141] | 蹬出去/跳起来时打，不是落地才打；越靠边越要侧身转多 [147][148][157] |

## 训练方法
- 原地定型：站白线上不动，搭档从下往上扔球到网与白线之间、抬拍高度，"不要扔那么冲" [142]。
- 抹球原地练：夸张握法、球放右上方，重心在右腿抹；碰到网就"转多一点，百分百不碰网" [149]。
- 循序加移动：走一步扑 → 并步扑 → 单腿飞扑，"刚开始可以往前站一点，看你的舒适度" [149][157]。
- 多球摆放：多球先扑里面的，"你一扑外面的，手碰到网怎么办" [149]。
- 组合练习：前面接一个挡网再启动扑抹，"先挡网，然后启动并，然后再来"，让技术带着实战状态 [157]。
- 喂球用插球最贴网，能不碰网扑到说明动作和节奏都对 [149]。

## 子技能难度×收益评级表
| 子技能 | 难度 | 收益 | 一句话理由 |
| :--- | :--- | :--- | :--- |
| 正手高点扑球挥拍（舒展→推→抓） | 低 | 高 | 动作跟高远球一样，入门最快，直接得分 [140] |
| 空间感与击球节奏（快慢球调整） | 高 | 高 | 教练说扑球成败"全部都在于空间"，是所有下压球的根基 [142][143] |
| 扑对角线路选择 | 低 | 中 | 只是意识转变，立刻降低下网和出界率 [141][142] |
| 正手抹球握法调整 | 中 | 高 | 一转握拍就解决"必碰网带"的世界性难题 [146] |
| 正手抹球动作（边推边转+小臂上收） | 中 | 高 | 反抓挡网的核心武器，练熟后"直接都不用想" [145][149] |
| 步伐衔接（蹬跳时机+落地缓冲） | 中 | 中 | 决定能不能够到球和不碰网，并步版更稳先练 [147][148] |
| 反手扑球挥拍 | 中 | 中 | 理论与正手完全一样，只差握拍和击球位置 [150] |
| 反手抹球（侧身+斜棱+往上刷） | 高 | 中 | 侧身、转握、往上收三者缺一不可，最难但只在中路贴网球用 [154][155][156] |
