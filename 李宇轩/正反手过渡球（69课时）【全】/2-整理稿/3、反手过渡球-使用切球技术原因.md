# 反手过渡球-使用切球技术原因

下一个我们就会学挥拍动作了。还没开始之前，我这边要跟你们说，过渡球为什么我们不用打，而是用切或者小球呢？他就跟吊球一样。

因为要是如果你要打一个网前球，但是你是打正面打的话，他很难控制。你要是如果要打一个很好球的话，你得减速了，对吧？我们不要有这种情况。如果用一个切球技术的话，也就是说我是架拍，我可以甩的很快，他不用减速，他这个动作也有一次性，为什么他很像去发力，他就很像样打底线，对吧？我这样这样拍，你可能会觉得哦这个人要发力，他引拍那么大，他会那么快，他可能要发力。正好我用一个切球技术，这个球会减速。比起如果我做一个过渡球，我是碰（推）的话，他就要这样子慢下来了，就很明显的，因为要是做快的话，球就很远、甚至很高。

另外一点，为什么我用一个小球呢？原因就是更加好控制，就可以贴网过。什么意思呢？就是因为我们在打反手时，往往都是过了我们。那过了我们的球，我们拍面很自然就会朝上，你还打的话，球决定要往上走。但是如果在这边的球，我用一个切球的技术，他刚离开出拍的时候，他会往上走，但由于是一个切球技术，他开始飞的时候，他就会渐渐下来了，能理解吗？

所以我们用一个小球的目的，就是为了一次性，还有更加好控制球的角度。我们不会靠打，前面我们说了吗？如果你靠打的话，球再往后飞，你看，台力（抬力/力量）往上走了，说你真的过去的话，哎，球在压面（拍面）了，你要速（速/收）哎，才起（控制），对吧？啊，你要才可以，就是要很控制。

所以每个人都知道了，你看我切的话，我可以很大胆的做切球，对吧？他胆的说啊，引拍很大啊，这动作就有点好像打高远球，对吧？高远球我也可以做一个切球，懂吗？所以这就是他的隐蔽性。当然了，如果球更加远的话，那我就要引的更加大，对吧？我就得做这很大动作，因为我要借力，对吧？我才可以打出一个很好球，甚至我可以落地很好，我可以回味的（回动）很好，如果靠打那么远达不到的。如果我真的使劲的话，哎，就上来了，被扑了，能理解吗？

给所（所以）就是这些无语倦印（羽球经验）啊，我们为什么做一个切球？
