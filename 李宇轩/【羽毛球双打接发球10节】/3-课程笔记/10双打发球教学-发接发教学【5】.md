# 10. 双打发球教学—发接发教学【5】

> 📺 双打发球教学 · 发接发教学【5】 · 约 20 分钟
> 教练：李宇轩

这是发接发教学的最后一段，专门讲**接偷后场（对方偷你头顶球）**。教练一上来就说破了病根：

> 教练原话："你们接不到偷球，就是因为你们退的方法是不对的。"

## 一、为什么你不敢站前面

不敢站前面，本质是怕被偷后场。而怕，是因为倒退的方法错了。

教练模拟了最常见的反应：**第一步就交叉退**。他直接否掉："你不能直接打，因为力在这边，你的手在前面、球在后面，你打不了的。难道你要这样子吗？做不到的。"

第一步一旦交叉，人就已经失位了，只能眼睁睁看着球从头顶过去。

## 二、正确的退法：一步并，然后转身打

正确的方式很"反直觉"——**不用退很远**。

> 教练原话："当一个人发后场，我们并一步，你看我最多只并一步，然后我就转身打了。"

为什么一步就够？因为**球的飞行轨迹决定了**：

> 教练原话："球在往下掉的时候，就到这了。如果我站上来球还没有掉、球很高的话，它基本上就是出界了。当我跳起来的时候就这么高了，如果我再截不到，球就已经出界了。"

所以他给了一个很实用的判断：如果一步并到位、起跳后还够不到球，那这球**基本就是出界**，可以直接放掉——这也是为什么专业球员敢"只看一下"就放掉。

外角距离长一点，可以"再加多一个并步再转就刚刚好"。

## 三、并步的要点：前脚掌、小步、快频率

并步本身有三个细节：

**① 用前脚掌，不用脚跟**

> 教练原话："我们并步不是用脚后跟，你用脚后跟也是并不了的。我们用脚尖，你脚后跟抬得越高，你并得越快。"

**② 步子要小**

> 教练原话："并步不要大，并步越大你越慢。我在半秒里面做这个动作（小步），我已经到这边了，我用大步还在原地。所以小步一点，你越小步、你动得越远，因为你的频率多。"

**③ 球一上，先抬头弯腰**

这是所有人都会做的自然反应，教练让你把它变成习惯：

> 教练原话："球一上，我们一定会这样（抬头弯腰）。头一上，你就迈右腿，我看着球。球还很高很远，我再并一小步。"

## 四、转身：拉左手 → 带左腿 → 转腰甩拍

转身这套是后场的核心，教练说这个动作"一定要对，不然你跑到位了也打不了"。

他拆的步骤是：

1. **并到位先做确认步**（发球情况基本并一步就到了）。
2. **左手先拉，顶到肩胛骨，同时挺胸。**
3. **左腿被带动，往后撤**——这时候"下半身稍微往这边去，但腰到上半身往这边，是反方向的力量"。
4. **甩拍的同时转腰**，右腿抬起，"左腿落地和甩同时"。

> 教练原话："整个转身的作用，就是能够用上腰。上半身跟下半身一定要连在一起。"

反例就是**同步发力**（上下半身各动各的），"很多人做不了转身，就是因为他们做到这样，上半身跟下半身是分开的"。

## 五、为什么重心要"越退越低"

教练说破第二个病根。球的轨迹是**越飞越低**的：

> 教练原话："球越飞越低，也就是说我退的时候要越退越低。换句话说，我要保证我能够伸手的这个高度。球在这，我站在这太低了，我一定要还在这引拍，球就掉了。但如果重心放低，球在这我就可以直接打了。"

所以退的时候，**并的同时人是往下蹲的**：

> 教练原话："我退的时候，我一定是并、腿下去。我在并的时候是蹲下去。"

教练也提到一个替代方案：如果正着退觉得难，"可以稍微斜一点、侧站，他一发你直接并跳"，效果一样。

## 六、还有两个常见错误

- **一直站得很直着退**："即使退的方法对，他们站直了，你一站直，球可能就在这边，你要怎么打？打不了了，最后只能放掉。"
- **球一发就直接转身**："你转身的时候已经浪费时间了，你在做这动作的时候球就越来越低。" 教练说这是小众打法，不建议。

## 七、接发后场该怎么练

教练给了一个渐进练法：先固定练"抬头弯腰 → 并一步 → 跳 → 打"，找到节奏，再要求快。练的时候**站在白线上**——"我们学一个正确的方法，站在白线上"。

## 最后：总结一下（含全课程收尾）

教练最后把整个发接发体系收了一遍：

| 场景 | 握拍 / 打法 |
| :--- | :--- |
| 双数区·对方发内角 | 反拍准备；可放网、可绕回来发力、可切 |
| 双数区·对方发 2 号中间 | 反拍放网/绕回打；稍偏右则换正手推 |
| 双数区·对方发外角 | 一定正手 |
| 单数区·对方发内角 | 正手准备；挡、发力、挡腰、切、推、压底线都行 |
| 单数区·对方发中间 | 一般直接换反拍（正手打这个点容易出界） |
| 单数区·对方发外角 | 正手换反拍打 |
| 接后场（两侧一样） | 重心放低 → 抬头 → 并一步 → 打开 → 跳 |

关于握拍准备，教练最后说了句很"人味"的话：

> 教练原话："羽毛球是活的，它不是死的。羽毛球一直在进步，技术也在进步，打法一直在进步。所以没有一个东西是绝对的，只有更合理、更轻松、更容易的一个解决方案。"
