# 勾球（正手/反手 × 主动/隐蔽/被动）

## 一句话定位
勾球是把网前球贴网勾到对角线的前端进阶技术，核心目的是"引他来直线，才打对角"，让对手跑错方向 [62][63]。主动时靠抢高点快速勾（不用骗人），隐蔽性时靠摆平假象骗对手，被动时靠压腰腿的力量把球反弹带过去 [63][68][80]。单打、混双、双打都能用，尤其在业余女双"最好用"——对手挡回来不知道怎么防勾 [63]。

## 核心要点
1. 勾球不靠打，靠带过去：匀速带动，没有引拍、没有突然加速、没有突然抓紧，三种高度全部如此 [62][66][88][94][96]。
2. 动作本质是"反"的动作：翻小臂（类似小内旋），拍面从头到尾有点斜，转到快平还没平时（约45度）截住球，食指一推、拇指往下一压，球斜着往上走才过网；摆平着打一定下网 [63][65][70][71]。
3. 击球点固定在"二"：三步节奏（一翻下来、二快平未平时击球、三继续转带过去），球一定要在拍旁边而不是拍前面，正手球位在右肩往外一点点，反手在左肩（外）一点，都不能放正中间 [63][70][71][73][84]。
4. 握法：正手用李宗伟握法（正常握法拇指稍抬），不要陶菲克握法；反手用拇指顶斜棱（球靠左），球到正中间换拇指侧边顶宽面；越被动握拍可再多转一点 [63][77][83][84][86]。
5. 肘是被逼出来的、不用刻意：翻拍对准球时肘自然下来/往内/往后收，注意力放在翻拍而非肘；"肘一不会动，你整个就不行了"——肘往内、手往外是借上力的关键 [64][70][76][77]。
6. 最佳高度永远在胸口到肚子（肚子最平），球低就压左腿/压腰把击球点调回最佳高度，手最低到肚子、不能放到腰以下 [73][79][97][98][101]。
7. 主动时压低重心是关键：左腿一定压下去，重心越低越主动、越不容易下网；"球在我头以上就叫主动" [68][89]。
8. 被动靠腿和腰产生力量："这个力量下去，你只需要抬你手、转你手就够了"，压腰产生的下压力让球像反弹一样上去；脚下力量越足，往上空间越好 [80][81][100][102]。
9. 手指越松质量越好："手指一握紧，你手腕就不灵活，你勾不了"，也不要突然抓紧（球会飘）；反手后三指夹住往内挤是命门，只想拇指推就会变成抡大臂 [83][87][91][96]。
10. 一定要立上来勾，不能平着打；非持拍手（左手）往后顶住肩胛骨，是站稳和发力平衡的前提，"没有这个动作，根本站不稳" [83][90][100][101]。

## 常见错误与避坑
- 横着抡大臂、只动手腕、刻意拉肘——教练开篇示范的三大经典错法，球又高又远又难控，"只动手腕，就很奇怪的动作" [62][63][83]。
- 摆平=压手腕是错的：摆平靠往前45度翻小臂，不是压手腕（会受伤、勾不出来）；倒手腕这个动作勾球里根本不存在 [63][65][69][70]。
- 被动勾球把腰以下伸太低、往外伸太多："千万不要往外伸太多，要不然这个球一定会不过网的"，手到腰就离开重心点，正确做法是压腿压腰而不是伸手 [82][97][98]。
- 只练"翻手指/转手指"且站正中间练：实战没人正对着球站在中间，"太多人这么练了"，球够边时转手指球只会去中间到不了边线，必须扣住后三指压手腕勾回来 [95][96]。
- 不要刻意做假动作/切球：刚学别模仿国手"斩一下再勾"的花哨动作，切球球会飘、跑起来更难控；"摆平勾，简单、稳、很准" [94][96][98][102]。
- 脚步没到位、节奏分家："不要迈过去啊，完蛋"、"没跑到位，完蛋"，右脚要跟球一条直线；正反手被动勾球必须"边踏边压腰边勾"同时做，先塌再勾节奏全错 [68][100][101][102]。

## 主动/隐蔽/被动 三种勾球的区别对照
| 维度 | 主动勾球 | 隐蔽性勾球 | 被动勾球 |
| :--- | :--- | :--- | :--- |
| 适用场景 | 抢到网带以上高点 [68] | 球在网带附近到网带以下一点（正常高度）[69] | 来不及了、球已低且贴网 [80][97] |
| 动作姿态 | 抬拍到眼睛以上，不用做假动作，直接快速勾 [63][68] | 摆平（从对面看像挡网/搓球），胸口高度最平 [69][71][73] | 拍往下翻多一点、拍面往外斜更多，斜着才像打直线、才有空间 [77][80][99] |
| 力量来源 | 抢高碰撞即可，手上不用大动作 [63][65] | 转小臂+食指推拇指压，匀速带 [65][66] | 压腰压腿的反弹力，手上"不用发力" [80][81][102] |
| 球位 | 右肩往外一点点（反手左肩外一点）[63][88] | 右肩（胸口最佳）[73] | 比正常右肩/左肩再靠外一点，让球掉在拍面上 [78][79][101] |
| 难点 | 别动作过大、别刻意翻 | 摆平与控网拉的平衡 | 空间+节奏+三同时，最讲究 [77][101] |

## 训练方法
- 网带/网袋压拍练法（教练称"最好的训练，没有别的"）：把拍压在网带下面顺线勾，肘自然下来，强制体会"立上来勾"和肘的转动 [64][70][77][89]。
- 家练"肘往内、手往外"结构：握拍反复翻腕，左手跟着一起动（像左撇子对称），练熟再加高度和步伐；肘不动则一切技术都借不上力 [76]。
- 扔球/多球：搭档把球扔到拍旁边（不是正前方），球速比正常稍快即可、别扔太重；先原地练手，再并步"边踏边勾、脚后跟落地即击球" [65][68][88][96]。
- 被动专项：开大弓箭步+压腰+左手后顶三者同时，先分解（先压腰塌腿再勾）练熟后再同步；贴胶带/画线在网带下练被动肘往后收 [77][80][82]。
- 对比练"打 vs 带"：先故意做几次"打"（引拍+爆发），再做几次"带"（匀速），自己感受差别 [66]。
- 节奏与位置自检：球下网=瞄太靠前，球一直往上=瞄太远，微调球放的位置即可 [73]。

## 子技能难度×收益评级表
| 子技能 | 难度 | 收益 | 一句话理由 |
| :--- | :--- | :--- | :--- |
| 正手主动勾球 | 中 | 高 | 整个勾球体系的入门动作，抢高+压低重心即可，但别下网要练 [63][68] |
| 正手隐蔽性勾球 | 高 | 高 | 最常用最好用、骗人核心，但摆平+45度翻的火候难拿 [69][71] |
| 正手被动勾球 | 高 | 中 | 靠压腰腿反弹力+球放外侧，时机与空间要求苛刻 [78][80] |
| 反手主动勾球 | 中 | 中 | 主动时动作就一点点，但握法分情况（斜棱/宽面）要先想清 [83][84] |
| 反手隐蔽性勾球 | 高 | 中 | 后三指夹挤+拇指推的精细配合，"翻手指"误区遍地 [91][95] |
| 反手被动勾球 | 高 | 中 | 背身+三同时+压腰+右腿到位，被动球里最难控制 [100][101][102] |
| 手指/手腕细节（推压+放松） | 中 | 高 | 所有勾球共用的引擎，"手指越松质量越好"直接决定成败 [66][87][96] |
| 肘的配合（内收/外转） | 中 | 高 | 借上力的关键，肘不动则全部技术都僵 [64][76][83] |
| 步伐与节奏（脚跟落地即击球） | 中 | 高 | 所有网前技术通用的节奏地基，练勾球顺便打通 [67][72][88] |
| 过中间线判断（远网/贴网意识） | 低 | 中 | 破除迷信的认知点：贴网做不到是正常的，不用改动作 [74][75][103] |
