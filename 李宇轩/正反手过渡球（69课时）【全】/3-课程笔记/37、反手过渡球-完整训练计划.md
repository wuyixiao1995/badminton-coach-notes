# 37. 反手过渡球练到头：三种线路 + 前后启动 + 挡网后退

> 📺 正反手过渡球（69课时）· 第 37 节 · 约 3 分钟
> 教练：李宇轩

反手过渡球的技术动作学完了，这节是把它串起来练：**一球一球地循环三种线路**，然后从平行启动换成前后启动，最后加上网前挡网再后退的实战套路。教练说，这条练完，反手基本上就没什么问题了。

---

## 一、第一步：定点循环三条线路

> 教练原话："就可以让他发球，发一个，你做一个过渡直线回来，第二个过渡一个中路回来，第三个过渡一个对角球就可以了。"

顺序就是：**直线 → 中路 → 对角**，一遍一遍轮。

> 教练原话："就这么练，练到你很熟悉为止。"

练到什么时候算熟？教练的标准是——

> 教练原话："你去说哦，这个我打对角、对角、直线、中、中、对角，自己来，好吗？就一直这么练，练到 OK 了。"

**你可以自己安排线路了，就算过关。**

## 二、第二步：从平行启动换成前后启动

> 教练原话："你可以从平行启动换一个前后启动了，比方说这样子来啊，变一步这样做回来，喂对角，变一步，就这么练。"

也就是：**变一步上去 → 打完回来 → 再喂对角 → 再变一步**。

## 三、第三步：加上网前挡网再后退的实战套路

> 教练原话："挡完一个他推后场去，过渡回来，等我还在推一个，打一个中路，然后回来。"

完整流程是：**挡网 → 对方挑后场 → 后退 → 做过渡（直线/中路/对角）→ 转身还原**。

这套里的步伐，教练说他不细讲了：

> 教练原话："这个当然你学会步伐了啊，我简单的说一下。"

> 教练原话："他挑球，我后退启动，并一步，然后做一个正常的过渡，然后转身。"

> 教练原话："按理说，这个应该你们要会了啊，一定要会啊。"

**后发力的步伐属于网课要会的内容，不在这一节重新教。**

## 四、这一节最重要的一条：挡完网要斜着后并，不要直着后并

> 教练原话："当我们挡了网，你后并的时候不要直着后并啊，因为直着后并的话呢，那球可以很贴近你。"

直着往后退，球会贴上你，你的手都伸不开。所以——

> 教练原话："所以每次我们挡了网，我们后并的时候，我斜着后并一点。斜着这样这边有空间，他在挑时候，我就再去，我可以掌握好左右的。"

**斜着往后并 = 给自己留出左右的空间。**

教练说这是很多人练错的地方，说得很重：

> 教练原话："很重要这一点。很多人在练这个动作的时候呢，哦，知道挡了网直接后退，完蛋，在上面掭身很难做，不可以了，行吗？"

**挡完网直接后退 → 完蛋。**

## 最后：怎么练

| 步骤 | 原话抓手 |
| :--- | :--- |
| 1. 定点循环三条线路 | "直线、中路、对角"一个循环 |
| 2. 练到能自己安排线路 | "练到你很熟悉为止" |
| 3. 换前后启动，变一步上去打 | "从平行启动换一个前后启动" |
| 4. 加挡网+挑球后退的套路 | "挡完一个他推后场去，过渡回来" |
| 5. 挡网后必须斜着后并 | "不要直着后并……球可以很贴近你" |

教练最后提了一句后面还有的安排：

> 教练原话："学完正手后呢，我们会有一个全场的一点控3、一点控4点。等我学完正手后，我会跟你们说到底大概怎么练。"
