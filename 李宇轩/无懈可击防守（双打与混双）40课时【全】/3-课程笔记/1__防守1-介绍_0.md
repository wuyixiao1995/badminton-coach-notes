# 1. 双打防守课，到底教你什么

> 📺 无懈可击防守（双打与混双）· 第 1 节 · 约 5 分钟
> 教练：李宇轩

这是整套课的介绍。教练先照着顺序把整门课要走的路讲了一遍，中间插了几段示范给大家看效果——所以这节的价值在于：**先让你知道要学什么、最后能打成什么样**。

---

## 一、这门课要教的东西，按顺序排了一遍

教练先说的是：对手进攻的时候怎么办。

> 教练原话："当对手在进攻，不管是压球或抽球或杀球的时候，我们怎么去打底线。怎么去起球，不管是起直线或起对角。"

然后是防守本身的门道：

> 教练原话："如果在防底线的时候，他杀的高，我们应该怎么去防，他杀的低，我们应该怎么去防，他都是有他的方法的。"

接下来是抽球：

> 教练原话："我们会学抽球，他在进攻时候，我们不管高中低点怎么去抽个直线，怎么去抽个对角。"

抽球里有个专门动作，教练点出来说是国手在用的：

> 教练原话："你会看到国手，他们会在这手这边，他们会绕过来这么打，对吧？这个我们会教你们，就是怎么用反手的方法接完所有球。"

最后一块是反攻：

> 教练原话："我会教你们怎么去反攻。也就是说呢，不管他杀高杀低或杀中间的话呢，我们怎么去挡个软球，或者是摆个对角球。"

## 二、"起完球别人一杀，你一挡软球，就立马反攻了"

这是教练在介绍里最强调的一个套路，也是他反复夸好用的：

> 教练原话："你可以看到所有顶尖球员经常用的一个套路，他们起完球别人一杀，他们一挡个软球，他们就立马反攻了，他们往前冲，对手就得起球了。所以这是最好最好用的。"

教练还专门跟女选手说了一句，语气很重：

> 教练原话："我一直在说的，女双或混双，你们女孩不要老是起球啊，别人一想，你们懂怎么摆的话，我跟你讲，立马得分。在业余界里面，你们可以立马得分的。"

**"不要老是起球"**——这句话是这门课里教练对业余女选手说的最直接的一句。他的意思不是说不要起球，而是说**起完球之后手里得有一手挡软球/摆球**，不然就一直在挨打。

## 三、教练当场示范的几个球

介绍中间教练起来打了几个，边打边解说，这里按他说的记下来：

- **反手接正手区的杀球**——他在双数区接球，示范的是：

  > 教练原话："你看他即便杀我正手，我都是用反手接球。这就是你们要学会的，因为这样子最快的。"

- **反手握法在正手区抽对角**——他说这个球：

  > 教练原话："就是很快啊，很难反应过来的。"

- **轻松打底线**，直线、对角都能打。
- **假动作抽对角球**——配合平抽用的。
- **对手杀得高的时候怎么接**：

  > 教练原话："有些人会杀的很高。即便他杀得高，我们都是有方法打回底线。"

- **最后是一个摆球**：

  > 教练原话："这个摆球呢是一个特别特别难反应过来的一个球。你打过去，很多人都会没反应过来。而且你看是用一个反手握法。"

## 四、双打的启动，和单打不一样

这一条是教练在介绍里说得最重的一句，后面第 20 节会专门讲：

> 教练原话："更重要就是我要教你们怎么做启动。听我说，双打的启动跟单打不一样。"

教练还预判了很多人会犯的错：

> 教练原话："很多很多人在学双打防守，他们都会觉得是这么启动。不是，单打双打不是怎么启动。如果是这么做的话，你是防不了的，你的节奏会错的。"

**"你的节奏会错的"**——不是慢一点、差一点的问题，是直接就防不了。

## 五、完整的课程顺序

教练在最后把整门课的学习顺序说了一遍：

1. **先学握拍**
2. **手上的挥拍动作**——起球、抽球、挡球，都先把动作学会
3. **怎么掌握空间**——

   > 教练原话："因为你要起球啊，你要发力呢？这个空间是很重要的。我会教你们怎么去产生空间。"

4. **移动**——

   > 教练原话："在双打的时候呢，你的移动越好越灵活，你的空间产生关系越好，这样子你的发力或者你的控制球就愈好。"

5. **最后是重心调整**——怎么接高球、低球

    > 教练原话："最后一点呢，我们就要学怎么去接高球低球，那就是中心的调整了。"

所以顺序是：**握拍 → 挥拍动作 → 空间 → 移动 → 重心**。

## 最后：这节总结

| 要学什么 | 教练怎么说 |
| :--- | :--- |
| 被进攻时怎么打底线、起球 | "起直线或起对角" |
| 杀高杀低怎么防 | "他都是有他的方法的" |
| 抽球 | "高中低点怎么去抽个直线，怎么去抽个对角" |
| 反手绕过来打 | "用反手的方法接完所有球" |
| 挡软球、摆对角 | "别人一杀，他们一挡个软球，他们就立马反攻了" |
| 双打启动 | "双打的启动跟单打不一样" |
| 移动 | "你的移动越好越灵活……你的发力或者你的控制球就愈好" |
