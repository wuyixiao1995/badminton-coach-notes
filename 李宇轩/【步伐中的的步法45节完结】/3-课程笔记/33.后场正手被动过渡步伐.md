# 33. 后场正手被动过渡步伐

> 📺 步伐中的步法（45 节完结）· 第 33 节 · 约 15 分钟
> 教练：李宇轩

这一节讲**前后站**下的后场正手被动（过渡）步伐。

> 教练原话："前后站的呢，往往都是你**不起球**，就是往下过渡——你往下过渡你就可以前后站。**只要对方没办法抽你、让你转身、还是杀你，你都是可以前后站。**"

> 教练原话："其实我跟你们说，先（说）反拍的步伐很简单、特别直接。**它主要难还是它的动作，还有它的发力动作而已。**"

## 一、先分高和低

> 教练原话："我们有分靠近点跟远点、高和低。高和低你们现在已经知道了——**高的话，我们就会（过球打）；低的话，就是我们刚刚好跟球一个平行线，就打。**"

过渡球也一样：

> 教练原话："过渡球也是一样，打网前的我们前后站也是一样。**如果我打个小球，我过渡的时候，如果我可以到位，我就可以（正常）过渡；如果球很靠后、我没有跑到位，我就得用一个弓箭步。**"

## 二、启动：球近就直接、要快

> 教练原话："现在区别就是，在你启动后你怎么去（接）。我们（说）前后站启动，如果这球不是很（远）、挺近的，我们就是直接 1、2、3，很直接，右腿一转（就做后交叉）。"

### ⚠️ 不是大步、要极快

> 教练原话："如果球近呢，我们不会做得很慢，**这动作很快的，特别快的。**"

> 教练原话："**不是这样子啊（大步），没有啊。因为呢它不是平行（启动），你要借很多力。这个一走、（右腿）一推，一推就（后交叉）的。**"

### 🔑 转身要快（本节第一重点）

> 教练原话："这边重要点是在你的**转身要快一点**。因为你看呢，我们在（这）球过了我们呢，**你启动、球过了你，你看不到球就完蛋了。** 所以你右腿一发力时候，赶紧（转），可以看到球。"

> 教练原话："**你的这个肩要快一点**，你右腿在前面启动。"

### ⚠️ 转身慢 = 直接放弃

> 教练原话："当然你发现（球）过你，很多人在这边，他们转得很慢，到最后他们就放弃了，**因为球已经到了你盲区，你根本就反应不过来，你身体想要反应都反应不过来的，做不到东西的。**"

> 教练原话："尤其你们这种发小（球），他推你这边。**要是如果你转身慢，你看，往往就是因为这样子你们才接不到。**"

### 正确做法

> 教练原话："发球启动，右腿一发力，**赶紧抬练手（左手），这肩一往后顶，（顶到）你这肋骨这边**，你就可以 hold 住它打。"

> 教练原话："如果你站好的时候，你启动后，你这个转身没有让球过你太多才转身的话，**你一启动就立马转，你不用抬上来，你这边往后转的话，你可以快很多，你就可以打到球了。**"

> 教练原话："即使是发完球，我在网前，他推我都无所谓，我就算往前压一点都无所谓，他打我，**只要转身转得够快就行了。**"

## 三🔑 回位的三种方法

> 教练原话："回位呢，你要知道现在我们不是起球，我们没有那么多时间，我们是过渡，基本上呢我们可能走一步才知道的。所以回位是这样子——**回位有三种方法。**"

### 方法一：并一步，用左腿启动

> 教练原话："一个是过渡并一步，然后重心（换）着这个腿启动——在**左腿启动，很小步的一个并步，然后启动**。"

### 方法二：右腿直接发力转启动

> 教练原话："第二种方法就是手多点，**右腿直接发力转启动**。"
>
> 教练原话："这种呢往往都是你一落地，你右腿就直接发力了。因为你相当高阶嘛，'啪'你就直接推了——**一塌，你一塌，你要踢出去的时候，你做手、左手进来。**"

### 方法三：重心挪到左腿再启动

> 教练原话："如果你做不了直接一（步）就直接发力右腿，你就这样子做，这是第三种方法：**直接站在这腿，重心挪过来，怎么启动就行了——左腿怎么启动，重心下左腿。**"
>
> 教练原话："他挡我的话，我可以直接前跑。"

### ⚠️ 收得太多怎么办？

教练讲了一个很实际的细节：**后交叉跨大了，收回来的时候脚会收得太小。**

> 教练原话："如果你过渡完的时候，后交叉，你过渡完的时候，你这个收的有点多，因为你开大你就要收嘛，你不可以这样子。你一定会收（多）的。"

> 教练原话："**你收得太多的话呢，你要挪回去，你必须要（挪）。**"
>
> 教练原话："往往国手他们都会这么做。因为你在移动当中的时候，你会移动得很快，你一定会收一点的。**90% 我们就会收。**"

> 教练原话："**到最后你启动的时候呢，你右腿要在前面就可以了。**"
>
> 教练原话："你足够时间的话，你过渡得慢，你可以先并一步再启动；要是你说你过渡稍微快一点，你可以直接（转）再启动。要不然你没办法直接回来，你可以先把重心挪回来，都可以。"

## 四、球很远时：加垫步

> 教练原话："那要是如果它很远呢？一样的，**只不过现在你多出一个（并步），或者是一个垫步——一推的时候垫一下，然后回来就可以了。**"

> 教练原话："**近的就是直接转后交叉，远的就是垫一下走。垫步没有垫那么远，不是很远啊，就垫那么一点就行了，垫那么一点就行了。**"

## 五、打对角：一模一样

> 教练原话："那个是打直线，那要是打对角呢？**全部一模一样，没有什么是不一样的。**"

> 教练原话："全部都是一样的，**只不过你的右腿不会朝这边——打对角，你会朝那边。**"

> 教练原话："我打直线，我是（朝前）；要不然就是我打对角，朝这边。一种（是）顶一步（并步），再来；要不然就是直接转。"
>
> 教练原话："**可以过渡，这没有太多不一样，该注意的点我都已经说了。明白过后就是一直练，练到你习惯而已，没有别的了。**"

## 六🔑 最后一个核心提醒：压低重心

> 教练原话："我重复一下，**每次你打个被动球，最关键的就是要压低重心。**"

> 教练原话："不管你（是）打个后场球，左腿压下来，或者是去打个（网前）……**除非这个球特别高**，特别高的时候有时我们就不想加速，我们就用（后交叉）。但这种就无所谓了，你要并小点或者（后交叉）都无所谓。**但如果我们在实战比较被动一点，我们一定要压低中心。**"

### 代价交换：高度换距离

> 教练原话："你压得越多，你越有空间。你也可以走得（更）远。"
>
> 教练原话："**我们说过了嘛，你要么就是有高度、牺牲距离，要不然就是你拿距离、牺牲高度，对不对？所以我要去得远，我要压低一点。**"
>
> 教练原话："而且我压低的话呢，我就离球的距离（合适），我就足够空间去引拍来打。这个我前面已经说了。"

## 七、平时的练法

> 教练原话："从发球开始，发完球，我们这么站。好，现在我们一启动了后呢，我们第一个右腿一发力，**我们这边要转快一点、转快一点啊，你不一定要抬上来，你这个往后就可以了——这边往后你就会转身。**"
>
> 教练原话："**第一个一定要先转身，转过来以后，这是重点，转过来以后你才可以找到球。** 如果球很低，（你）就会用弓箭步。"

### 到位 vs 不到位

> 教练原话："这个过渡，如果球高或者我可以跑到位的话呢、不是离我太远，**我就可以过球，最后一秒我可以过球**，切下来，这是落地。"
>
> 教练原话："但是如果球很靠后了，我来不及了，或者它离我（有）一个距离，**我就要用一个弓箭步，据说是让我可以保证到位。**"

> 教练原话："第一个先是到位的啊，我用前脚掌的。然后它（挑得）没有太平、有点高度了，我就可以这么做。"
>
> 教练原话："第二种呢是，比方说我发球，他推得就很平、过了我，而且很平、还有一点远，**（我就用）弓箭步。启动，看我重心放得很低啊。**"

## 最后：这节总结

| 情况 | 步法 |
| :--- | :--- |
| 球近 | 直接转身 + 后交叉（快！） |
| 球远 | 转身 + 垫一下（小垫步）再走 |
| 球低不到位 | **弓箭步**（压低重心） |
| 打对角 | 与直线完全一样，只是右腿朝那边 |

| 回位方法 | 做法 |
| :--- | :--- |
| 一 | 并一步 → 左腿启动 |
| 二 | 右腿直接发力转启动（高阶） |
| 三 | 重心挪到左腿 → 左腿启动 |

| 要点 | 原话抓手 |
| :--- | :--- |
| **转身要快**，否则球进盲区就没救 | "你看不到球就完蛋了" |
| 转身慢的人最后会放弃 | "身体想要反应都反应不过来" |
| 球近就不做大步，动作要极快 | "这动作很快的，特别快的" |
| 过渡后的收步，90% 都会收多 | "到最后你启动的时候，右腿要在前面就可以了" |
| 压低重心是最关键的 | "每次你打个被动球，最关键的就是要压低重心" |
| 高度换距离，或距离换高度 | "你要么就是有高度牺牲距离" |
