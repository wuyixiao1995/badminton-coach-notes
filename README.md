# 羽毛球教学笔记库

> 从教练教学视频整理出的**结构化学习笔记**与**原始语音转录文稿**。
> 每门课 = 原始语音识别（`transcripts/*.txt`）+ AI 整理的学习笔记（`*.md`），可对照溯源。

- **数据源**：`192.168.2.4:/mnt/data/羽毛球/`（服务器权威版）
- **整理流水线**：ffmpeg 抽音 → SenseVoice GPU 转录 → LLM 生成三级笔记
  （工具与流程详见仓库 [`badminton-notes-pipeline`](https://github.com/wuyixiao1995/badminton-notes-pipeline)）
- **文件总数**：2360（笔记 936 + 时间轴 469 + 转录 954）

---

## 目录结构

```
羽毛球笔记/
├── <教练/课程名>/

│   ├── NN.小节标题_时间轴概要.md    ← L3 时间索引（含时间戳，李宇轩系列有）
│   └── transcripts/
│       └── NN.小节标题.txt         ← 原始语音识别文稿（未加工）
```

## 三级笔记体系

| 层级 | 文件 | 内容 | 用途 |
|------|------|------|------|
| **L2** | `NN.标题.md` | 技术精讲、学习洞察、避坑指南、训练计划、知识关联 | 深度学习 |
| **L3** | `NN.标题_时间轴概要.md` | 知识点 → 视频时间戳映射 | 快速定位回看 |
| **原始** | `transcripts/NN.标题.txt` | SenseVoice 语音识别原文（未纠错） | 溯源核对 |

> ⚠️ 转录文稿由语音识别直接产出，含同音字错误、标点缺失，**仅供溯源**，请以 L2 笔记为准。

## 使用建议

- **想快速了解某节课** → 读 `NN.标题.md` 开头的「教练点评」与「核心要点」
- **想找某个技术点在哪一分钟** → 查 `NN.标题_时间轴概要.md`
- **怀疑笔记有出入** → 对照 `transcripts/NN.标题.txt` 原文
- **想补整理** → `刘辉轻技术` 等课仍有转录未生成笔记，可跑流水线补全
