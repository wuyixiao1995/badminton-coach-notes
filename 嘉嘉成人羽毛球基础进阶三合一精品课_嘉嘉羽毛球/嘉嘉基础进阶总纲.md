# 嘉嘉基础进阶总纲（聚合自 34 篇笔记）

## 一句话定位
面向成人初学者的"防伤+基本功"体系课：以热身拉伸打底 [1][2]、常见错误防护纠偏 [3]-[7]、单一技术逐个过关 [8]-[29]、专项素质收尾 [30]-[34]，主线是"全身协调发力链替代局部蛮力，步法与身体素质支撑一切手法"。

## 课程结构地图
- 第一章 热身与拉伸：[1] 全身热身、[2] 全身拉伸
- 第二章 常见发力错误与防护：[3] 护肩、[4] 护肘、[5] 护腕、[6] 膝/下肢、[7] 脚踝
- 第三章 单一技术：步法 [8]-[13]（启动/移动/落地/回动）、后场 [14]-[19]（发球/高远/杀/劈吊/滑拍吊/反拍吊）、双打防守与网前 [20][21]、网前与中场 [22]-[29]（勾/抽/挑/扑）
- 第四章 专项身体素质：[30] 上肢、[31] 下肢、[32] 全身原地、[33] 全身跑动、[34] 双摇跳绳

## 核心要点
1. 发力链条自下而上：蹬地/转体→腰腹→肩→以肘为轴→小臂带手腕手指鞭打，"借力打力"，忌肩肘腕单点死磕 [3][4][5][14][15][16][24][25]。
2. 放松才有爆发力：击球前手与全身放松，只在击球瞬间手指抓紧/手腕闪动，全程紧绷既无力又易伤 [20][22][23][28][29]。
3. 亮肘与提前架拍：抽球、挑球以肘为轴且手肘先"亮出来"正对击球方向；网前扑勾封都要提前举拍预判，抢占击球空间 [21][22][23][24][25][26][27][28][29]。
4. 启动步=给身体初速度：小跳落地瞬间快速蹬地，触地时间越短启动越快；来球在左由右脚蹬、在右由左脚蹬 [8][9]。
5. 移动分工：交叉步管长距离（步幅大），并步管短距离快速微调；后交叉步+小垫步专救被动远球；移动中屈膝压重心、前脚掌着地、身体不起伏 [10][11][13]。
6. 落地方式防崴脚：上网跨步小腿前踢、脚跟先落过渡到前掌、脚尖外展指向来球；后场主动左脚前掌先落传重心右脚，被动才脚跟先落 [12][7]。
7. 高远球是分水岭：转体传导+小臂鞭打，击球点在额头前上方，发力链断了就靠肩硬甩——这是肩肘痛的第一根源 [15][14]。
8. 杀球靠收腹与链式传导：屈膝蹬腿→腰腹→肩→小臂→手腕手指闪动，配合收腹压低球路，忌大臂抡打与过度压腕 [16]。
9. 吊球吃动作一致性：劈吊与滑拍吊前半程必须和杀球/高远一模一样，击球瞬间才包切/滑拍"故意打呲"；反拍吊斜线靠切击角度更小+拇指顶拍手指捻动 [17][18][19]。
10. 双打三件套：封网讲究连续扑压+握拍偏上+发力后自然回弹衔接，不求一拍打死；接杀统一反手握拍、拇指顶宽面、小幅度手指发力；扑球靠后三指突然握紧+手腕闪动，击完立即收拍高举防触网 [20][21][28][29]。
11. 勾球是"柔"的功夫：正手靠食指、反手靠拇指拨动，小臂微回拉，忌手肘手腕硬甩；线路调动大于强攻 [22][23]。
12. 身体素质是技术基石：热身5-10分钟、拉伸单动作≤30秒不追痛、无痛训练原则、每周2-3次专项力量（哑铃/水瓶/弹力带均可）[1][2][30][31][32][33][34]。

## 常见错误与避坑
- 局部关节硬发力：靠肩死甩、靠肘硬顶、靠腕死扣是肩痛/网球肘/腕痛三大根源，解法永远是回到"转体+以肘为轴+手指手腕鞭打"的发力链 [3][4][5][15][16]。
- 站太直、重心高、身体起伏大：启动无力、移动迟缓的共同原因；屈膝微前倾、前脚掌着地贯穿步法全环节 [8][9][10][13]。
- 挥拍幅度过大：接杀/封网/扑球大甩手臂只会更慢且挨追身，动作要小而爆发 [20][21][28][29]。
- 前场落地脚尖内扣、前脚掌硬着地：崴脚高发动作，务必脚跟先落+脚尖外展 [12][7]。
- 想一拍打死：封网、杀球都讲究连贯与节奏，单拍思维导致抢不到下一拍 [21][16]。
- 带痛训练、热身不足：所有素质课统一强调"痛即停"，先消除疼痛再练 [30][31][32][33]。

## 子技能难度×收益评级表
| 子技能 | 难度 | 收益 | 一句话理由 |
| :--- | :--- | :--- | :--- |
| 启动步+常规移动步 | 中 | 高 | 一切步法的地基，"步法为手法之母"，练熟全场提速 [8][9][10] |
| 高远球发力链 | 中 | 高 | 分水岭技术，向后场一切发力技术（杀/吊）输送动力模式 [15][16] |
| 步法落地方式+回动步 | 低 | 高 | 一条规则大幅降崴脚风险，回动决定下一拍衔接 [12][13] |
| 杀球 | 高 | 高 | 进攻核心，链式发力要求高但得分上限最高 [16] |
| 劈吊/滑拍吊（一致性） | 高 | 中 | 欺骗性强但极吃动作一致性，建议高远杀球稳定后再练 [17][18] |
| 网前勾球（正反手） | 中 | 中 | 手指控制细腻，易上手、调动效果好，强度上限一般 [22][23] |
| 平抽（正反手） | 中 | 高 | 中场攻防转换主力，以肘为轴一点就通 [24][25] |
| 挑球（正反手） | 低 | 高 | 被动防守保命技术，动作简单、用得最频繁 [26][27] |
| 双打封网+接杀+扑球 | 中 | 高 | 双打入门刚需，手指爆发+小动作是关键 [20][21][28][29] |
| 热身拉伸+专项力量习惯 | 低 | 高 | 零门槛高回报，决定运动寿命与动作稳定性 [1][2][30]-[34] |
