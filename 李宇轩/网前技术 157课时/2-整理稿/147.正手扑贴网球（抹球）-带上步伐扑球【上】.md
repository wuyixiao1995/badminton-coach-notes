# 正手扑贴网球（抹球）-带上步伐扑球【上】

我先示范一次给你们看，有两种：一个是直接样子往前跳的，一个是有迈腿的。我先做第一个是往前跳的。

这边我先说，我还没有扑前我要先说，因为这个网特别软，它不像正常的网，这个有点软。所以如果我跳起来、我有那么大速度的时候，我扑到的时候，你可以看到网可能会有洞，但是我是没有碰到网，我是因为打到球头，因为这个毛是插在网带，过去的时候它可能会抖，它肯定会抖，像如果这样压的话它会抖，但是你不会听到（碰网的声音）。

我先做一下那个单腿直接跳的，第一个是这样子一步直接扑。再一个（迈腿的），我愿（用）迈腿了，但是你不会体谅我。那我先教第二个就是那种迈腿，因为这个比较简单，它比较像你们平时练这些戳球、跳球，这个节奏；那个一步跳的那个是完全不一样的节奏。所以我们学比较简单的先。由于我们是在同一边，拍的话你可以看到好像过往，这我要提醒你们，其实并没有过往，要不然的话你们可以试一下，拿你们手机放在同一边，然后你们这样子放，你们看哦没有过网，但是拍出来好像是过完了。暂时没有过往的，你看我连碰球都还没有碰到，拍出来好像是过往。所以这边你们要明白，相机拍出来的东西由于角度原因看起来好像是过往。

我们做这个扑球是这样子：也是一样，启动，并这一步。一般来说我们会抬腿、脚后跟落地，然后我们才去做动作，同时做吗？因为启动你抬手，你可以收一点无所谓，你要伸直点也无所谓，但是这边一定会曲（屈），抬上来。你在进这一步的时候，你身体一定会往后，因为我们要高，我要抬得高，我才不会有这种直直的打法，我们感觉就跟上面这个 push 是一样的，我会上来。

我在上来的过程中，我的重心就会在左腿，看到吗？我会有——正在做题（蹬腿），我就可以——等会我就坐（做）条（跳）。等要是如果你身体没有往后，你会登（蹬）不出来的，因为你重心在前面，我们会往后。

我们在什么时候扑？我们不会在你落地的时候扑，我会在我左腿一蹬出去的时候，一动出去的时候，这个时候我就接进去去扑了。为什么我不可以下去说扑呢？因为我现在说我这个重量，我会很容易打到网带，我会很容易，因为我再下去，只要我左腿有蹬，我的力就可以传出去。所以我是这样子，如果不动的话，看来我们是进来往后仰，我一等我去伸手去扑，看出来吗？所以我是扑完后，当我扑了"啪"，我才落地，落地还是用脚跟落地。懂吗？所以这个动作是这样子：启动，一抬上来，现在呢我往后仰，我一蹬出去我就要很接近、就要等的那么近，同时我在等的时候要舒展了。可以吗？你别动时没有舒展别样子，然后才下舒展也是会碰完的；或者是你说我蹬出去，我一直不要手产（伸）上做，就不行了，这个你们明白啦，也是不可以。所以我是边一蹬就舒展，所以我一蹬完后，我一左脚一发完力的时候，阿里（那里）的时候我就这样子那么接球了。可以吧？随手（左手）可以往后顶一点，你就可以往后压，这样子你可以看出来吗？你可以看我一直挺胸的，我整个人是保持往后的，这种不会往下压，我也不会过往。可以吗？抬上来。可以吗？

再来，另外一个东西你也可以做，就是你把你的右腿抬高一点，抬高点，你就越不会有一个往下的重量，你越不会往下重量，你越不会去打到网，懂吧？你越干净这个动作。所以你看我，我会这样抬、抬得越高，我顺手很干净的，你只会有某些动作，你不会有一个太多过往、还是压到网带，能理解吗？

我在做最后一个，然后一会你们从前面看：一抬着手往后点，抬手，现在我抬右腿抬高一点，我说你就会往后压，我就往前舒展，就 OK 了。你们再从前面看一下，我站的时候我都不会站这边，我这边就很奇怪，我要扑这个球，我会往这边站。所以我现在去的时候，我会这样子抬上来、往后顶、旋立着往后立这样子，往后倒立侧握好我的拍，我不是这样子转那么多，这样子我转那么多，它可能这边会空间大一点，无所谓的，你这样握拍它可能会比较逆着，对吧？但如果我转多一点的时候，再保持立着，它就会有点大，大的空间是 OK 的，没问题的，可以保持放松手指，一抬往后，然后左手一往前蹬，就做型（成型）了，看到没有？一抬、左手一往前蹬，网上抹。啊再来，我再做快一点，动作那学会快一点。

好，为什么你刚看我做完后，我会有这个收腿呢？为什么呢？因为我为了要站。如果我不站门（站稳）的话，如果我不抬腿的话，我就会有一个脱腿（拖腿），我就会拖腿。但是拖腿的话，有可能我会很接近网带，我可能会碰到了；还是我一说完后，本来我说完了，但是由于我还在拖我左腿，一般我们是说为了站稳，可以拖左腿。我在拖腿的时候，我会在前面（近），但是我是你在上线（线上），所以要是如果我那么贴网去扑的话，看到吧，我就碰到网了，所以为什么我会抬我的右腿，让我整个人绷住，挺住，看到没有？我一抬上来，我这里就有一个往后立着，它就会站稳了。所以为什么有时你看我们腿会勾上来，就这个原因。如果你蹬得很快、而且很贴网的话，我一脚落地，我会抬我的桌垫（左脚/左腿），不动，我们人不可以碰网，懂吧？所以你为什么会看到很多扑球会这样子，就是因为这个原因，为什么我腿会勾起来呀？还是立上来，就是为了有一个重量在这边，我重心摆在前面，我一有这边抬上来，我这个人就会又往后倒了，能理解吗？不只是这样子，等下我们学这个单腿跳的也是会有这个现象，我们走（腿）会绷住了，懂吗？

就是这个原因，如果你们有在好奇他为什么坐（左）腿会勾起来，就这个原因，因为我们整个人是不能碰网的。当然如果你说你扑完后"啪"就落地了，你再碰网，可以吗？可以，但是这个很危险了，你要看裁判会不会这么觉得，裁判可能觉得"哦，你同时碰网"，那就再见了。

给你们从这边看，你可以看到我左腿抬起来。我们在练的时候，如果说了你换了这握拍，你还是有碰到网，就再换多点，就可以了。最安全就是把正手握成一个反手握法，但是拇指放旁边就行了，不要这样子，这是最安全的。

这边最后一点我要说，当我们在推手腕做这动作的时候，我在做这动作绕回来的时候，我手会立回来的，我不是这样子退（推）关键的转呢一定过往的。我一绕，整个就会收回来了，看到吗？我是一绕，我一绕回来，它就会收回来了，手腕汝（入）是来推、转，它就会收回来，当然我是往上收，还是立着的，不是这样子一打网带的。一定要知道，好吗？

好，那现在我们就学那个比较难的，其实也就是实战当中我们用最多，因为这是最快的方法，而且这个可以等（扑）得更加远。我们再学一下。
