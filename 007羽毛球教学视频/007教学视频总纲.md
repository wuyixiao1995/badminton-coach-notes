# 007教学视频总纲（聚合自 49 篇笔记）

## 一句话定位
拉斯姆森（Rasmus Gemke）系列单技术教学：以右手示范+讲解两版成对覆盖发球、握拍、网前、后场、反手、步法约 25 个基础技术点，核心主线是"预加载蓄力 + 全身动力链 + 动作一致性假动作"。

## 课程结构地图
- 基础与发球：握拍 [0005][0006]；反手发球 [0001][0002]；正手发球 [0003][0004]
- 后场正手：正手杀球 [0016][0017]；跳杀 [0048][0049]；正手劈吊 [0015][0019]；滑板劈吊 [0018]
- 后场被动与反手：被动防守高远球 [0013][0014]；被动底线切球 [0011][0012]；反手高远球 [0038][0042]；反手吊球 [0039][0043]；反手切球 [0040][0044]；反手杀球 [0041][0047]
- 网前：放网 [0031][0032]；中前场平推 [0021][0022]；挑球 [0027][0028]；勾对角 [0029][0030]；扑球 [0033][0034]；被动放网 [0023][0024]；被动挑球 [0025][0026]
- 中场：平抽 [0007][0008]；接杀 [0009][0010]
- 步法：启动步伐 [0020][0035]；前场步伐 [0036][0045]；后场步伐 [0037][0046]

## 核心要点
1. 握拍松紧分工是万技之基：后两指（无名指+小指）较紧固定拍柄，前两指放松便于正反手快速切换，击球最后一刻手指收紧产生鞭打式爆发（Finger Power），同时掩护出球意图 [0005][0006]。
2. 预加载（Preload）是发力通用前提：反手系通过转体拉伸背肩"像拉满的弓"储能 [0038][0040]，杀球靠开胸拉伸肩前侧 [0016][0017]，扑球靠抬肘+手腕后引 [0033]，跳杀在空中完成弯弓预载 [0049]。
3. 动力链自下而上传导：腿蹬地→髋/核心旋转→肩→肘（反手肘由朝下转朝上、正手肘由朝后转朝下）→手腕旋转→手指顶压，"仅靠手臂手腕死力抡拍"是所有发力不足的根源 [0042][0013][0049]。
4. 动作一致性是假动作的生命：劈吊/滑板吊前段必须与高远球/杀球完全一致，最后一刻才变拍面切削 [0015][0018]；正反手发平快（偷后场）前摇与发短球完全相同 [0001][0003]。
5. 球路方向由躯干朝向决定而非手腕硬拐：反手切/杀看肩部指向（直线肩对直线、斜线继续转体）[0040][0041]，正手杀球"击球瞬间腹部的朝向决定杀球方向" [0016]。
6. 被动球要换大肌肉群发力：贴网/旋转球被动挑球不能再靠手指手腕小发力，改用肩部向上拉动带肘+切击（Slice），并优先挑对角深区降低出界风险 [0025][0026]。
7. 网前稳定球靠肩部主导、锁死手腕：放网与中前场平推均"固定手腕手指，仅靠肩部肌肉微幅推动" [0031][0021]；变线勾对角靠手腕后屈成角度而非转腕 [0023][0029]。
8. 启动跳（Split Step）时机重于高度：对方击球瞬间低平微跳、双脚同时落地、重心在前脚掌；"场地中心"随攻防情境动态移动（防守后移、吊球后前压），杀上网连贯时可不做启动跳 [0020][0035]。
9. 回位的最后一步就是下一次启动跳：前场上网后脚蹬地回退、后场剪跳（Scissor Kick）落地后身体微前倾，形成移动无停顿的闭环 [0036][0037]。
10. 落地安全角度保护跟腱：后场跳杀/剪跳/侧跳落地脚脚尖必须微向外张（约1-2点方向），严禁直对球网，否则跟腱承受过大扭转应力 [0037][0046][0048]。
11. 接杀本质是借力阻挡：低重心屈膝前倾，拍头与网平行不垂头，肩肘极小幅推送，击球瞬间与前脚落地同步发生 [0009][0010]。
12. 高点击球与位置选择决定质量上限：反手杀球只在场地偏前使用（越靠后空档越大）[0041]，杀球尽量靠前、击球点在身体前上方拍面下倾 [0016]。

## 常见错误与避坑
- 全程死握拍柄：发力僵硬、无手指爆发、无法快速换握；纠正为"前两指放松、击球瞬间才抓紧" [0005][0007]。
- 转动/旋转手腕做网前变线：勾对角与被动放网"转手腕→球过高或直接挂网"；应保持拍面平行网带，靠手腕后屈角度控球 [0029][0023]。
- 提前扣肩、胸腔未打开：杀球/劈吊挥拍幅度受限、隐蔽性差；保持侧身开胸到最后一刻 [0016][0019]。
- 击球点偏后或位置太靠后：杀球变平、反手杀变成送分；尽量在身体前上方、场地偏前击球，太靠后改用高远/吊球 [0017][0041]。
- 启动跳过高或单脚先落地：对方击球时人还在空中无法变向、失去平衡；降低跳幅、练双脚同落 [0020][0035]。
- 击球后滞留观望不回动：反手杀后正手区大片空档被抓；击球与转体回中必须一气呵成 [0041][0039]。

## 子技能难度×收益评级表
| 子技能 | 难度 | 收益 | 一句话理由 |
| :--- | :--- | :--- | :--- |
| 握拍松紧与手指发力 | 低 | 高 | 所有技术的发力与换握基础，投入极小收益贯穿全场 [0005] |
| 启动跳与动态回中 | 中 | 高 | 时机对了移动速度质变，是全场步法的发动机 [0020] |
| 前后场步法系统（含跟腱保护） | 中 | 高 | 落地规范同时提升连贯与防伤，一次练习终身受益 [0036][0037] |
| 正手杀球动力链 | 中 | 高 | 开胸-蹬转-压腹链条正确后杀球质量立升 [0016] |
| 劈吊/滑板吊的动作一致性 | 中 | 高 | 与杀球共享前摇，练一次同时提升进攻与欺骗 [0015][0018] |
| 反手预加载发力链 | 高 | 中 | 被动反手是业余瓶颈，但优先级仍是能用头顶就少用反手 [0038][0042] |
| 被动挑球（肩拉+切击+斜线） | 高 | 中 | 极被动解围专用，掌握后大幅减少中场被扑 [0025] |
| 勾对角角度控制 | 中 | 中 | 欺骗性强但高风险高回报，转腕即挂网 [0029] |
| 接杀借力挡网 | 低 | 高 | 借力不发力，规则简单、防守质量立竿见影 [0009] |
| 反手发球一致性（短/偷后场） | 低 | 高 | 双打发球核心，动作极简且隐蔽性好上手 [0001] |
