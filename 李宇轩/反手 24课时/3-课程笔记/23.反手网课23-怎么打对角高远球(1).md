# 23. 反手怎么打对角高远球

> 📺 反手 24 课时 · 第 23 节 · 约 15 分钟
> 教练：李宇轩

这节讲反手对角。教练一上来就把最大的误解破掉了：

> 教练原话："如果你把直线的（技术）、基本功、扭腰、步伐学会了，打对角呢只不过是调一下位置而已。"

**反手打对角没有独特技术。** 教练说得很直接：

> 教练原话："打反手对角呢，没有什么东西是需要说很独特，都是一样的。但是我们的空间会调整，然后握法呢可能大部分时候呢，我们会用这个侧棱的握法。"

---

## 一、一句话总结：学的是"空间调整"

> 教练原话："剩余的什么扭腰、上肘、（出）小臂全部都是一模一样的，所以到了反手对角呢，我们就主要是学什么？学空间的调整，你调好空间几乎就 OK 的了。"

## 二、最重要的前提：人必须过球

这是这节讲得最重的一条，教练连着强调：

> 教练原话："关于到打对角呢，很重要，人必须、必须过球，必须的。"

**打直线可以不过球，打对角不行。**

> 教练原话："如果你打个直线，有时你没有完完全全过球，都没问题……刚刚好到位，这样打都没问题，你看这点是对的吗？就刚好在我的胸前面。"

**但如果没过球，会怎样？** 教练演示了：

> 教练原话："我再怎么往内摆啊，他就只能去直线，他没办法打对角的。"

## 三、什么是"转身球"——这里教练讲了个套路

这一段很有意思，解释了为什么双打里总有人说"打转身球"：

> 教练原话："什么叫打转身球？就是这个人这样站，你让我转身，转了身过后呢，这个球很到位（过身）……这个套路为什么那么好用？"

**关键：** 不是让对手接不到球（对手会步伐的话还是能接），而是——

> 教练原话："（关键）就在于这边，我们打个转身球呢，就是让别人没办法打对角，所以叫做打转身球。"

> 教练原话："所以为什么你会看双打球员，为什么他们封网那么快？一打，他们只要要在这边封，因为他打了这一拍是一个转身球，刚好过你，你要打的话，你只能够打个直线，所以你没办法打对角。"

**这就是为什么双打球员敢提前封直线**——因为他们知道你打不了对角。

## 四、连国际球员也会打不好对角

教练举了李梓嘉的例子：

> 教练原话："你看李梓嘉，他要做个（过渡）对角……但是为什么他会（打）出一个那么高、而且在（中路）的球？因为这球过他过得很远了。"

> 教练原话："他没有跑到位，但是他想过渡一个对角球。首先球过了你，你没办法拿对角。你真的非得要打的话，他就去中间。"

还有更进一步的：

> 教练原话："你看他打得很高，对吧？为什么？因为球过了他很多，他想做个切球，太远了吗？太远的话……我这样（切）不是这样斜着往上了，他就会往上走了。"

所以：

> 教练原话："你没有跑到位，你不只是打不了对角，这个球还会很高。"

## 五、打对角的两种空间（方法一：球离你远）

第一种情况：**球离你很远**，需要舒展着打。

这时有一个**必须的动作**：

> 教练原话："我不可以这样子往后看，这样子去打对角球。如果（转身）我可以啪（打）对角，我完全做不了。"

**正确的是**：人朝**斜后方**，人**过球**：

> 教练原话："我的人呢不可以朝后，我的人可以朝斜后方，然后我的人必须要过球，这样打。"

> 教练原话："我的确认步尽量过球，然后我在迈我右腿的时候……我就打就行了。"

所以：

> 教练原话："它还是在我的右前方，但是我现在是这样子，人会过去一点，这样打，我就可以去打对角了。"

**而且要多压左腿借力**：

> 教练原话："因为是一个很长距离，所以我会建议你们多压左腿，多压一点，我们会用那个比较（被动一点）的……我们压多一点，抬（起）我们右腿，我们借多点（力）往（外）甩。"

## 六、方法二：球离你近（比较主动）

第二种情况：**球离你比较近**。这时**握法换成侧棱**：

> 教练原话："跑得比较近呢，把你的握法换去一个侧棱的握法。"

**右腿过球要过得更多**：

> 教练原话："右腿过球过得越多越好。正常来说，我们是刚好这样子，这个呢过得多点。"

**为什么必须过得更多？** 因为侧棱握法会让球往中间去：

> 教练原话："如果你发现到你的球老是去中间，就是因为你握（在）侧棱，（而）你比较主动的情况下……除非你外翻翻得很多。"

所以主动的时候：

- 打**直线** → 用**斜棱**
- 打**对角** → 用**侧棱**，而且要**多迈一步**

> 教练原话："我的左腿再过去多一点点就行了。"

## 七、右腿的落点方向不一样

这是个很细的点：**打直线和打对角，右腿迈的方向不一样**。

> 教练原话："打直线的话，我会避开胸，这样打。打对角的话呢，我会不往这边去，我会可能会往斜着往后走多一点。"

为什么？因为**拍面方向是由身体角度决定的**：

> 教练原话："我（往）这边转，你看到吗？我拍面就越来平了。我又往这边转，拍面就越（偏），能够理解吗？"

**换句话说**：

> 教练原话："我不用做什么，我就（顺）拍就会朝着那面了。"

所以打对角不需要"扳手腕"，**是身体和腿的方向自然形成的角度**。

## 八、对手真的过你很多的话——转多一点打

还有第三种情况（很被动）：球过你很多，但你还想打对角。

> 教练原话："过得很多，那我就要转多一点。"

**这就是前面说的"转多是产生空间"**。但教练明确说了，如果球真的过你太多，**基本打不了对角**：

> 教练原话："没有（一个）国际学员可以说球过了他们很多，这样子只靠……很多人说，哦，你就换你握拍就行——做不到的。"

## 九、最后一句：全在并步和跨腿

教练收尾：

> 教练原话："全都在你的（并）步、你的确认步（要）过去，然后跨腿而已，其他的都是一模一样。"

他还要把这句话钉死：

> 教练原话："你的并步，前面的启动并步，一启动这并步要大步点，越大步越好。因为你的确认步尽量尽量想办法过球一点点。"

> 教练原话："要不然你（就）完全做不了，相信我。你说你确认步没有到位，没问题，但是你的跨腿一定要跨得很远。"

## 最后：这节总结

| | 打直线 | 打对角 |
| :--- | :--- | :--- |
| 过球 | 可以不过球 | **必须过球** |
| 握法 | 斜棱 | **侧棱**（主动时） |
| 右腿方向 | 正后 / 避开胸 | **斜着往后多一点** |
| 确认步 | 正常 | **过球更多** |
| 左腿 | 正常 | **多压借力** |
| 转身 | 可以转 | 转多就打得难 |

| 要点 | 原话抓手 |
| :--- | :--- |
| 打对角没有独特技术 | "没有什么东西是需要说很独特" |
| 学的是空间 | "我们主要就是学空间的调整" |
| 人必须过球 | "人必须、必须过球，必须的" |
| 转身球的目的是限制对角 | "让别人没办法打对角" |
| 双打封直线靠这个 | "他是打了一个转身球……你没办法打对角" |
| 打对角换侧棱 | "把你的握法换去一个侧棱的握法" |
| 全在并步和跨腿 | "全都在你的（并）步……其他的都是一模一样" |
