# 44. 双打混双后场 4 点跑位步伐：杀抽杀抽最直接

> 📺 【步伐中的的步法45节完结】 · 第 44 节 · 约 15 分钟
> 教练：李宇轩

后场特别直接。核心就一句：**杀 → 抽 → 回来 → 启动 → 再杀**，杀完就换平行启动。

## 一、基本循环

1. 杀球
2. 落地后换**平行启动**
3. 他打这边，我就做一个抽球
4. 抽完回来做启动
5. 再杀，再换平行启动去抽

> 教练原话："你杀完后你一定是直接（换平行），它打这边你就做一个抽球就可以了。然后抽完后回来做个启动，杀，然后换去一个平行启动就抽就可以了，特别特别直接。"

## 二、反拍/对角也是同一套

杀完平行启动 → 对角抽 → 回来平行启动 → 杀这边 → 换去正手抽 → 对角杀对角。去那边就并两步，杀完这边永远是要并。

## 三、中场有点高怎么办

不用并一步再做抽球，可以**直接跳起来杀**。

> 教练原话："你可以同样的，头顶区有点高，我不用那反拍，我是这样子一步跳，杀，可以吗？可以。"

## 四、吊球：很少练

> 教练原话："其实我们在练双打这个后场步伐，我们很少会去练这个吊球的方法。"

**原因**：

> 教练原话："基本上我做杀球，因为杀球的节奏是最快的，我们要把这节奏（练）快。"

**如果要做吊球**：回位时用并步或交叉走一步，再做平行启动。头顶的吊球基本和杀球一样（因为节奏快，很难吊得慢）。正手这边就"滚左腿"或者跟杀球一样平行启动。

> 教练原话："吊球你们要选择练或选择不要练，其实我觉得都无所谓。"

## 五、双打套路：杀抽上网

有人问：杀 → 抽 → 上网，这个步伐怎么做？

教练说：

> 教练原话："这个基本上你的双打水平差不多到了一定的水平了，就是你能够连续进攻了，我们才会跑这种双打的套路。这个是纯套路了。"

**两个人怎么配合**：

- 一个人站这边抽完，**往后推一点**（准备对角的抽球）
- 搭档在那边挡了网 → 他往前跑
- 你抽完准备在中间，他一上网，你就推到这边
- 他回一拍就到你了

> 教练原话："如果你是这样子抽完后，你是这么准备，他挡回来，你就这样子并就行了。那如果你是抽完后你这样准备，还是你是杀完后你这么准备，他挡回来，你是这样上去（就）行了。"

**前提**：

> 教练原话："这个是需要两个人配合着练，同时你们必须要知道你们在打什么球，你不可以乱跑了……我要能够杀这一拍，他抽回来，我要能够继续的抽、继续往下压，我的触球一定要有质量。"

## 六、练法建议

> 教练原话："我觉得最主要还是你们在这边（把）步伐练好，你们才带上球，不用那么早就带上球。"

## 最后：这节总结

| 要点 | 原话抓手 |
| :--- | :--- |
| 杀完必换平行启动 | "杀完后你一定是直接（换平行）" |
| 中场高球可直接跳杀 | "我不用那反拍，我是这样子一步跳杀，可以" |
| 双打后场少练吊球 | "因为杀球的节奏是最快的" |
| 杀抽上网是纯套路 | "到了有一定水平，我们才会跑这种套路" |
