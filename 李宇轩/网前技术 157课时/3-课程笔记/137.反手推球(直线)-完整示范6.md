# 137.反手推球(直线)-完整示范6

> 📺 网前技术 157课时 · 第 137 节 · 约 5 分钟
> 教练：李宇轩

这一节把直线推球完整示范一遍，顺带讲了一个更高级的东西：用推对角的站位骗人，实际打直线。

## 一、对角在当前，直线在旁边

> 教练原话："推对角我们会在这个点推，在这个点推压。推直线呢我会在这个点推……我会在这个点推对角在前面，直线在旁边。"

> 教练原话："这个球只会往这边去的，因为角度的原因。"

反过来说，如果站位不对，想打对角就很难：

> 教练原话："你看我打个对角对吧？就很难做了。"

## 二、脚的位置不一样

> 教练原话："你看我每次推对角时候呢，我的脚都会在差不多这边就结束了。但你看我推直线的话，我不在这边，我会往前走。把球放旁边。"

> 教练原话："转身，转腰，那么我会转过来推，放平转腰推。"

## 三、假动作：故意做出推对角的架势

这一段是本节的重点：

> 教练原话："当然专业球员可以了，我们再拉回来再做，我们会有一个再拉回来再做，再产生多一点空间，看到没有？摆在这边，我一推的话，它已经打直线嘛，但是我是要做一个假动作，我会再拉回再产生大一点空间再做。"

为什么这样能骗到人，教练说了两层：

> 教练原话："为什么呢？因为我知道对方也知道这个球，我没办法推对角。我放到这边的话，他知道哦我不可能推个对角，但是我就是特意让他觉得我不能推个对角，然后我再拉回来，再产生多一个空间再做这个手腕。"

## 四、练熟以后可以不用转腰

> 教练原话："当然你做的熟悉以后，你可以不用转腰，可以啊，你就是这样子可以啊，就好像做的更加隐蔽啊。现在本来我是推对角，我是这样推啪直接，我已经会了，我不要对方知道，我可以不转腰，我可以这样推呀，可以啊，只要我在旁边推就行了。"

## 五、怎么练

| 要点 | 原话抓手 |
| :--- | :--- |
| 对角在当前推，直线在旁边推 | "对角在前面，直线在旁边" |
| 推直线右脚要往前走 | "我推直线的话，我不在这边，我会往前走" |
| 球放左边，别放身前 | "放后面一定要放左边啊……不要放身前面" |
| 转腰产生空间 | "我一转腰，我就有一点空间，再往前推" |
| 熟练后可省掉转腰增强隐蔽 | "我不要对方知道，我可以不转腰，我可以这样推" |
| 左手要用上 | "左手要用上，不要忘记了" |
| 球过你太多就变成对角了 | "球在我后面，我拍面是斜着的" |

## 六、这一套在挑球上也能用

> 教练原话："虽然就变成一个假动作，就跟他挑球一样，对吧？挑球我们也说过了，一样动作，只是不在这边，我们上来就可以了。"

> 教练原话："如果低一点。你们不压低东西，你们去做一个挑球动作了。但是如果你们要压的话，就压低重心。就可以推了。动作是一样的。"
