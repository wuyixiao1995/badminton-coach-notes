# 14. 交叉步怎么转换重心

> 📺 反手 24 课时 · 第 14 节 · 约 3 分钟
> 教练：李宇轩

这节很短，解决一个很具体的问题：**挡网之后对方推球，什么时候用交叉步，什么时候用并步？**

教练一上来就说清楚，这一节是接上一节的——交叉步的转换重心，跟前面讲的**完全一样**。

---

## 一、交叉步的转换重心，和前面一模一样

> 教练原话："我跑了，我跑 123 是不管怎样了，到最后你跑的时候，到最后你的左腿……全部到这边一模一样了。"

意思是：**不管你用什么步法跑到位置，最后到位的那个动作是一样的**——左腿支撑、扭腰、转换重心。所以交叉步不是另一套新技术，只是**移动的方式不同**。

教练还提到，有时候身体"没有转那么多"，但**有一个重心扭过去的动作就可以了**：

> 教练原话："他可能有时候没有转那么多，但他有一个这样子的重心，就可以了。"

## 二、什么时候用交叉步

判断标准只有一个——**你能不能一边看球一边移动**。

> 教练原话："我们会用交叉步的时候，通常都是你挡了网……你抬头，他一推你的时候，你还来不及动，你是这样子往后找球的情况下……你就会用（交叉步）。"

也就是说，用交叉步的典型场景是这样的：

```
你挡网 → 对方推球 → 你来不及动 → 前面根本看不到球
     → 只能整个人转身去找球 → 用交叉步
```

> 教练原话："他推了你，你在前面直接看不到球了，你得转整个（身体）去看球了，这个时候你就会用（交叉步）。"

## 三、什么时候用并步

反过来，如果你**可以顺着球边看边动**，就用并步：

> 教练原话："我抬头我可能可以并这一步……他起球的时候或他挑球的时候呢，我可以这样子顺着球这样一冲动，诶，没有问题。"

## 四、教练特意强调：不是被动就必须用交叉步

这一点他在录音里反复说了两遍，说明是常见误解：

> 教练原话："我并没有说每一次被动的时候，别人（打过来）你就必须要用交叉步……没有啊。"

真正决定用哪个的，是**你怎么看这个球**：

| 你怎么看球 | 用什么步法 |
| :--- | :--- |
| 能边看边动 | 并步 |
| 得整个人转身去找球 | 交叉步 |

所以不是"被动 → 交叉步"，而是"**看不到球、必须转身 → 交叉步**"。

## 最后：这节总结

| 要点 | 原话抓手 |
| :--- | :--- |
| 交叉步到位后的重心转换和前面一样 | "全部到这边一模一样了" |
| 转得少也没关系，有那个重心就行 | "但他有一个这样子的重心就可以了" |
| 看不到球、要转身找球 → 交叉步 | "你得转整个是你去看球了，这个时候你就会用（交叉步）" |
| 能边看边动 → 并步 | "我可以这样子顺着球这样一冲动" |
| 不是所有被动都用交叉步 | "我并没有说每一次被动的时候，别人（打过来）你就必须要用交叉步" |
