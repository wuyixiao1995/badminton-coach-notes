# 15. 头顶劈吊直线 1

> 📺 致命吊球 · 第 15 节 · 约 20 分钟
> 教练：李宇轩

正手劈对角讲完，接下来学**头顶劈直线**。有人会问：头顶吊直线为什么是"劈"，不是滑板？教练先回答了这个问题。

## 一、为什么头顶直线也用劈

> 教练原话："我在头顶的时候，我要让你觉得我打个对角球，我怎么让你觉得我打对角呢？就是我的动作要往那边去。你想一下，如果我手是往那边去，同时我还做个滑板——就是反方向切到这边——你觉得这球会去（直线）吗？这球一定会去对角。"

> 教练原话："那唯一一个方法就是我的手臂往那边去，同时球往这边去——这就是我做个劈球动作。"

所以**劈吊 vs 滑板**的区别是：

| | 手的方向 | 球的方向 |
| :--- | :--- | :--- |
| 劈吊 | 往对角 | 往直线（隐蔽） |
| 滑板 | 往对角 | 往对角（方向一致，隐蔽性差） |

教练补充:滑板"除非做得好像打高远球、突然收下来（收吊），才有隐蔽性"。

## 二、头顶劈直线的隐蔽效果

不只是引对方去对角，**有时还能引对方去正手底线**——因为挥拍快，对手会以为你要发力打底线。

> 教练原话："凡是说到有隐蔽性又有威胁的吊球，通常都是：一是可以引他去对角，二是让他觉得你打个底线球，因为你动作可以很快……然后你击球时是一个切球方法，这球就突然减速。切球就是减速球，那正好我们甩得快，球减速，就是一个很大的节奏变化。"

## 三、关键原理：劈球方向与落点的关系

这是本节最重要的技术认知。教练用"击球点在哪"来解释球会去哪：

> 教练原话："正手我劈球的时候，球怎么才会去对角呢？球在我的右上方，我的握拍是这样子，然后它在我的右上方，我就可以劈对角。"

也就是说——**用同一个切法，球点在不同位置，落点完全不同**：

| 球的位置 | 落点 |
| :--- | :--- |
| 右上方（正确） | 对角 |
| 再往外一点 | 中间 |
| 更往外 | 直线 |
| 在身体后面 | 会往外飞 |

> 教练原话："所以你自己想一下，我站这边也是这么切，那如果把这个（点）放到这一边，他就去直线了。"

**但光知道点不够**，教练强调：

> 教练原话："如果你只是想着这个点而已，你是做不到的。因为这边区域的步伐和这边区域的步伐，这边转身角度和这边转身角度是完完全全不一样的。"

## 四、与正手劈对角的四个区别

| 区别点 | 说明 |
| :--- | :--- |
| **1. 找球的确认步** | "跟正手认的是很不一样的" |
| **2. 腰的角度** | 转换重心时腰的用法很不一样 |
| **3. 击球点** | "这是很大的" |
| **4. 转身角度** | 击完球身体的朝向完全不同 |

## 五、常见的坏球（教练都演了一遍）

1. **不会切，只会碰**（招财猫式）。
2. **只学会"要用劈吊"，直接出界**——"10 个学员来问我这个问题，10 个学员都掉出这样球"。
3. **怕出界 → 下网**。
4. **怕下网 → 又慢又高**，或者加点劲飞远但没威胁。

> 教练原话："最后他们改了切球方法，动作都变了，手是这样子去的。球又远、又不突然。"

## 六、正确站位：绝不"平着站"

> 教练原话："头顶不可以（平着站）。如果你这么做，我跟你说这个球百分百出（界）。"

两个原因：

> 教练原话："第一，你平着站的时候，这东西就好像（对）直线了。第二，我们打球一定要有转身动作，要不然我怎么回位？你想我这么站，我一做转身动作，我就这样子了，我再劈，求救，出界了。"

正确站位：

> 教练原话："我会是左脚在这边，我的右腿是这样子的（往后撤）。这样第一个最明显的原因就是我要让他觉得我打个对角球——你斜着对那边，球就会在我右眼上。"

> 教练原话："他看着我的时候，他会看到有点'背'的样子。这样子的话就很引诱，对方觉得：哎，你怎么可能打直线呢？你都看不到直线，你打个对角啊。"

## 七、腰：不往后仰，而是往斜后方压

> 教练原话："到了这边呢，我不会这样往后仰——我会往这一边（斜后方）压，所以我就会这样子。然后我会往后，往这边斜着往后仰。"

> 教练原话："也就是说我在腰这边会先感受到（扭），我这样子往后的时候，会有一点拧、顶住。"

## 八、展肩：肘不要抬太高

> 教练原话："我们的右肘不用抬那么高，你抬得越高，你越展不到这边，你只是往上。你要的是往下一点点，然后往后。"

> 教练原话："我们的右肩不是这样往后展，我是往这边（往下往后）展，我要展到我的肩胛骨。"

> 教练原话："这个球拍你看到他并没有离我很远。你越把肘离得远，你越容易下网。"

最后一条经验：这样展拍面，**从前面看很正常的**，对手看不出你要吊直线。

## 最后：这节总结

| 要点 | 原话抓手 |
| :--- | :--- |
| 头顶直线用劈不用滑板 | "滑板是反方向的，球一定会去对角" |
| 劈比滑板多一层欺骗 | "手往那边去，球往这边去" |
| 落点由击球点位置决定 | "球在右上方就是对对角，放到这一边就去直线" |
| 光知道点不够 | "这边步伐和那边步伐完全不一样" |
| 四个区别 | 确认步 / 腰角度 / 击球点 / 转身角度 |
| 不能平着站 | "你平着站，这个球百分百出界" |
| 站位要"有点背" | "让他觉得你都看不到直线，你肯定打对角" |
| 腰往斜后方压、肘别抬高 | "肘抬越高越展不到，你越容易下网" |
