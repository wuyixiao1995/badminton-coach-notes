# 02. 什么是启动、怎么做启动（启动的重要性）

> 📺 步伐中的的步法45节完结 · 第 2 节 · 约 20 分钟
> 教练：李宇轩

这节是整个步伐课的地基。教练把"为什么要学启动"和"启动该怎么做"两件事讲透了，其间还专门让陪练上来做了对比演示——有启动和没启动，差距肉眼可见。

## 一、先搞明白：为什么接不到球

很多人打球的困惑是一样的：**明明跑得动，为什么就是接不到球？**

> 教练原话："很多人打球的时候接不到球，即使我发了一个球、他打到我身边，我都接不到球。就想：不应该啊，这场地看起来不是很大，但我打起球来就觉得这个场地特别大。我打了一个高球，我跑到球下打完了，你打下一拍我就接不到了。"

教练点出这背后的真相：**场地不会变大，是你没有启动。**

> 教练原话："你们看这些国际球员，有没有发现他们接每个球都接得很轻松、很合理？他们跑的时候跑得刚刚好，接完之后还可以回来准备接下一个球。……你会发现这个场地好像很小——但他们自己下场就觉得太大了。"

同一块场地，为什么国际球员打起来显得小、我们打起来显得大？区别不在腿，在**启动**。

> 教练原话："技术很重要，但是能跑到位是必须要先做到的。你都接不到球，那你还说什么技术？你都接不到球，那你还说什么抽挡？你都接不到球，那你还说什么杀球呢？"

## 二、启动到底怎么做

教练把动作拆成了很容易记的几步，核心一句话：**脚后跟抬起来，用前脚掌撑地。**

> 教练原话："发了球、打了球，回来，脚后跟抬起来。对方一打，瞬间打开往下坐，可以感觉到大腿和屁股往下压。"

分解开就是：

1. **回位时**——脚后跟抬起来，靠前脚掌站着；
2. **对方击球的瞬间**——双脚快速打开，同时往下坐；
3. **坐下去的时候**——大腿和屁股有往下压、绷紧的感觉。

然后才是脚下那一下：

> 教练原话："我要去这边，我这个脚后跟抬起来，我就一蹬。……单单车（一脚）只做这个爆发力，我其实就出（发）去了。"

**方向怎么定**：往左边去，右脚（外侧那只）发力蹬；往右边去，左脚发力蹬。就是蹬外侧腿，把身体弹向目标方向。

## 三、几个必须避开的错

教练反复强调的几件事，都是新手最容易做错的：

| 不要这样做 | 为什么 |
|------|------|
| **用脚后跟站** | 脚踝会锁死，启动就发不出力；而且你要先换到前脚掌，等于多做一次功 |
| **站太直** | 用不上大腿的肌肉，等于没蹲 |
| **开得太大** | 打不开也站不稳，还会"启动两次"（先打开一次、再启动一次） |
| **只做样子蹲一点点** | 蹲的目的是用上大腿最大那块肌肉，蹲太浅等于没用 |

> 教练原话："你要知道，我们蹲下去是要用大腿最大的肌肉。屁股往下坐，腿是绷紧的。"

**开多大合适？** 教练给的参照是**大约过肩**——站姿本来与肩同宽，打开后的宽度比肩膀稍宽就够。开太小，打开的时间太长、会错过对手击球的时机；开太大，前脚掌反而用不上。

## 四、为什么"没有启动 = 奔向移动"

这是这节最核心的一个观念。教练打了个比方：

> 教练原话："没有启动，就是奔向移动。……我们打球的时候，我们不知道对方打哪里，我们需要有一个爆发力。你要是没有启动的话，你突然一件（球）出来，你做不到的。"

他举了田径和足球守门员的例子：

> 教练原话："你看田径的、像冲刺的，他们没有做好准备就直接跑了——因为他们知道他们的方向在哪里、知道往哪里跑。但是羽毛球不一样，我们不知道对方什么时候打、也不知道他要打哪里。所以我们必须要有一个启动。"

区别就在这：**方向已知的运动不需要启动，方向未知的运动必须有启动。** 羽毛球恰恰是后者。

## 五、教练的现场演示

为了让学员真的看懂，教练让陪练上来做了几轮对比：

- **第一轮**：教练先说好要往哪边扔，陪练知道方向 → 就算不启动也能勉强接。
- **第二轮**：教练故意站到角落、什么方向都不说 → **只要做了启动，不管站多远都能接到**。
- **第三轮**：教练什么也不说、不给启动的机会，突然扔 → 陪练**怎么都接不到**。

> 教练原话："如果做（了）启动，它不管站得再远，还是能接到，站在角落都能接到。但如果我突然扔、不让他（做）启动，即使他往前站，他都觉得很辛苦。"

教练还特别点明一个细节：

> 教练原话："这个启动看一下，（是）不是往上跳跃，我会往下发力的。"

**启动不是往上跳，是往下沉。** 很多人的误解就是把启动当成"跳动一下"，结果整个人在空中飘，反而慢。

## 最后：这节总结

| 问题 | 答案 |
|------|------|
| **为什么接不到球** | 不是场地大，是没有启动 |
| **启动怎么站** | 脚后跟抬起，用前脚掌（脚尖）撑地 |
| **启动怎么做** | 对方击球瞬间，双脚打开往下坐，大腿屁股绷紧 |
| **开多大** | 大约过肩，别太大也别太小 |
| **往哪发力** | 往左去右脚蹬，往右去左脚蹬 |
| **启动的本质** | 是往下发力弹出去，不是往上跳 |
| **没有启动会怎样** | 等于"奔向移动"，方向未知的球根本反应不过来 |

> 教练原话："（这）就是这个训练要给你们解释的：要是没有启动，你是接不到的。"
