# 03. 什么时候做启动

> **教练点评**: 启动不仅是一个跳跃动作，更是一个与对方击球节奏同步的“生理过程”。掌握单腿启动与重心压低的细节，是解决接球慢、二次启动及被骗的关键。
> **难度**: 进阶 | **适合**: 经常感觉慢半拍、有“二次启动”习惯的球友 | **时长**: ~15min | **评分**: 9.8/10

### 🎯 核心要点
*   **精准时机**: 对方引拍时离地，对方触球瞬间正好落地踏地发力。
*   **启动是一个过程**: 包含“离开地面”与“往下踏”两个阶段，而非瞬间静止。
*   **压腿预判**: 在落地瞬间通过压低重心（弯腿）来观察球向，而非落地后再看球。
*   **单腿启动习惯**: 实际对抗中 95% 的情况是利用重心腿做单腿离地启动，强行双脚并拢跳会导致卡顿。
*   **高度随球而变**: 被动防守（起高球后）绝对不能跳高；进攻上网时为借力可略微增加跳跃高度。

### 🔧 技术精讲

| 技术维度 | 动作要领 | 关键细节 |
| :--- | :--- | :--- |
| **启动时机** | 对方**引拍**（向上/后拉拍）时身体离地；对方**碰球**瞬间，脚正好踏地。 | 提前启动会导致爆发力泄掉或被假动作骗；滞后则直接接不到球。 |
| **弹簧腿（压腿）** | 在空中快落地时开始做“蹲/压”动作，落地瞬间腿部收紧（含信感）。 | 压腿不只是为了发力，更是在下压过程中看清前、后、左、右的方向。 |
| **单腿启动** | 顺着回位惯性，用重心支撑腿（单腿）离地做启动，另一条腿顺势蹬转。 | 移动中不需要完全停稳双脚起跳，单腿启动能实现步伐的连贯。 |
| **跳跃高度** | **防守时**：重心直接打开下压，不向上跳；**进攻时**：可略微跳高，利用下落重力加速。 | 防守跳高会增加腾空时间，面对快球（杀球/平抽）会完全来不及反应。 |

### 💡 学习洞察
*   **🔑 落地即预判**: 很多人接不到球是因为想等落地站稳了再看球。正确的做法是在“往下压”的这个动态过程中完成视觉扫描，脚碰地的刹那已经知道要往哪里爆发出去了。
*   **🔑 拒绝“二次启动”**: 训练中如果养成“回位-停稳-双脚跳”的习惯，实战中就会出现严重的卡顿。要学会利用回位的惯性，在移动中直接衔接单腿启动。
*   **🔑 进攻时间差**: 进攻（如吊球后上网）之所以可以跳略高，是因为对方挡网球轨迹是“向上过网再落下”，存在时间差；而防守时对方是向下击球，必须第一时间落地支撑。

### ⚠️ 避坑指南

| 错误表现 | 根本原因 | 纠正方法 |
| :--- | :--- | :--- |
| **原地蹦迪/跳太高** | 误以为启动跳得越高爆发力越强。 | 保持脚后跟微抬，防守时做“重心下沉”而非“向上起跳”。 |
| **落地后再看球** | 没有利用腾空和落地的过程进行观察。 | 练习在脚掌触地前就锁定对方球拍弹出的方向。 |
| **必须双脚并拢跳** | 受教条化基础步法影响，不知道移动中可以单腿启动。 | 练习回中步法时，尝试不完全停死，用最后一拍直接蹬离地面。 |
| **节奏僵硬（卡顿）** | 提前启动导致落地时球还没飞出来，力歇了。 | 观察对方引拍节奏，将离地动作与对方的挥拍动作对齐。 |

### 🏋️ 训练计划
*   **第1天**: 影子步法练习。重点体会“引拍离地-触球落地”的节奏，不带球，纯模拟对手节奏。
*   **第1周**: 专项单腿启动练习。模拟回位过程中的重心转换，纠正必须“站稳后再跳”的错误习惯。
*   **长期**: 弹簧腿力量训练。练习前脚掌着地的快速跳动（不落后跟），增强踝关节与小腿的爆发回弹力。
*   **器材**: 羽毛球拍、节拍器（辅助控制频率）。

### 🔗 知识地图
*   **前置知识**: 基础站姿、前脚掌着地习惯。
*   **配合技术**: 回中步法（Center Base）、重心腿切换。
*   **进阶方向**: 应对假动作的“二次启动”补偿机制。
