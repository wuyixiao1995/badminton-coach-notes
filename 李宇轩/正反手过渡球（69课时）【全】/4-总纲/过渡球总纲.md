# 过渡球总纲（正反手过渡球 69 课时）

## 一句话定位

李宇轩过渡球体系全集：被动时用"切球"把球送到后场，动作一致、重心可控，做到"我不进攻，也不让你进攻"的保险技术；课程从反手直线→转换重心→特殊球→正手→斜线→单双打战术逐层展开 [1]。

## 核心要点

1. **本质定位**："吊球是主动进攻的网前球，过渡球是被动时打的"——"即便很被动的状况，你都可以翻局" [1]。
2. **反手全是切球**："都是用切球，不是靠打"；切球带来一致性、好控角度、隐蔽性三大好处 [2、3]。
3. **反手握拍**：拇指顶在侧棱（第 6 面），"越靠侧棱越容易切球"；打斜线"从侧棱再转多一点到斜棱" [2、31、34]。
4. **引拍铁律**："拍一定是低于你的手，拍头低于手"；两种引拍路线都要练 [5]。
5. **上肘下肘**："上肘下肘是最重要的"、"你不会下肘，这个球必往那边飞，百分百" [7]。
6. **反手击球点**："击球的时候是 45 度，拍面朝上的时候击球"；时机"肯定是在中间的时候击球"，太早往上飞、太晚下网 [9]。
7. **转换重心**：确认步"左腿接近球不过球"、"永远都用脚板"（实战可全掌）；"压左腿换距离"、"想去得远，压你左腿" [11、18]。
8. **左手系统**："左手往后顶，右腿才跨得远"、"越远的球，我需要拉的越多"；低点球"球越低，左手抬得越高"、"压腰不是弯腰" [13、14、21、24]。
9. **特被动球**："放弃高度，你要注重的是你一定要跑到位"；"拍头一定是转到后面才击球" [22、23]。
10. **正手链条**：李宗伟握法"顺时针转到第四点，斜棱放肌肉上"；架拍"手不要开 90 度"；引拍"肘往外前方上弦"；出拍"只要我会绕我的肘，拍面最后都会包进来"；击球点"最好的高度是在你眼睛这高度" [38、39、41、42、43]。
11. **正手步伐**：主动前脚掌落地（球在前）vs 被动脚后跟落地弓箭步（球过你）；"后交叉是过渡球必须会用到的"；确认步"上半身先转，左腿才跟着踏" [46、47、48]。
12. **一通百通**："转换重心是个通用动作，区别只在握拍和切球技术" [51]。

## 斜线（对角）专项

- **多退一步是通用规则**："只要你想打个对角球，你一定要退的更加多，产生足够空间让你的手"；靠压手腕改不出来——"碰球那一刻，拍面是平的，球在错的点上你怎么压手腕都是直线" [60]。
- **正手主动对角**：肘"至少要到胸中间"（直线只到右肩）；"右腿迈大步 + 身体朝右前方斜着"；"只要你一过球就可以打了，脚还没落地也照打" [60、62]。
- **正手被动对角**："往上舒展着切，再往下走——平着切一定下网"；击球点"球到耳朵这边就出拍"；腿要跨到"第二条线" [61、63]。
- **反手对角**："头往哪看，球就往哪走"、"在右耳这边击球" [32-35]。
- **转身球原理**："只要我让球过了你，让你转身再打，你没有办法打对角"——这就是转身球套路的由来 [60]。

## 常见错误与避坑

1. 引拍拍头高于手、未转小臂直接兜打——球必飞 [5、7]。
2. 确认步左腿跨过球、用脚跟"踩死"——重心卡住回不来 [11、48]。
3. 被动对角平着切——拍面平着走必下网，要"往上舒展再往下切" [61]。
4. 直线跨过头——"往下切太多，一定下网"；直线刚刚好，对角才多过一点 [64]。
5. 双打过渡太轻——"前面站着人，太轻就是喂球给他扑"；要过渡稍重到白线附近 [66]。
6. 过渡重球后回位慢、不转身——"一过渡完，第一个动作就是转头转身，慢了就死了"；双打/混双过渡完必须平行站 [67、69]。

## 单打 vs 双打运用对照

| 维度 | 单打 | 双打/混双 |
| :--- | :--- | :--- |
| 过渡轻重 | 多数过渡轻的，让对方多跑；偶尔隐蔽突然的重球反攻 [68] | 不宜太轻（会被扑），过渡稍重到白线 [66] |
| 过渡后站位 | 前后启动，"过渡到哪儿，右腿就朝哪儿" [68、69] | 一定是平行站，只顾左右和身体 [67] |
| 来球重点 | 对方挡网/挑球，要顾网前 | "没有往前球"，对方必抽身体——"顾身体不顾左右" [67、69] |
| 步法节奏 | 步幅大、节奏慢，打完可转身回中 | 小步高频，打完原地连贯启动 [67] |
| 高级技术 | 慢速钓鱼球（仅特别主动时用，一场一两个） [68] | 中半场抽、勾、切变化 [67] |

## 训练方法

1. **徒手挥拍**：先 run shoe 徒手练切球，再加步法，最后才喂球 [63]。
2. **带球层层加码**：站中间一路练"直线→重的→对角→被动过你的球"，练到熟悉 [65]。
3. **上网衔接**：过渡完右腿上前再启动；教练习惯"过渡到哪儿就往哪儿走" [65]。
4. **一点控三点/四点**：一点控三点（正手直线/中场/对角），控四点加反手——"每个单打学生一定会练的" [65]。
5. **单打实战练**：跑四个点加身体球，过渡重球后平行站等抽 [69]。
6. **双打循环练**：过渡→对方压一拍→你抽→对方退→你挡软→对方再挑你 [67]。
