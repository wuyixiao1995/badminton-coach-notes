# 81. 正手被动勾球怎么完整做一遍

> 📺 网前技术 157课时 · 第 81 节 · 约 3 分钟
> 教练：李宇轩

前面手上动作都练过了，这节把正手被动勾球完整串一遍。教练反复强调两件事：**第一，站位要往后一点；第二，别那么早动。**

---

## 一、站得太近，球就过不去了

教练一开始就把错误摆出来：

> 教练原话："我不会站这边的，我站这边的话呢，首先呢我就很主动了。"

站得近为什么不行？因为你迈出去的时候球已经贴身上了：

> 教练原话："我这样迈出去的时候，哎，这球太近了。我一太近的话，你看我越近，这个球拍面就越平，它不会过往，它会直接平着去这个地面的。"

**太近就得缩着打，缩着打是不行的。**

> 教练原话："太近的话，缩着打是不可以的。我们是要先舒展，再转回来再做。"

为什么一定要"先舒展再转回来"？教练解释了这里的道理：

> 教练原话："因为这个转就是这个力量嘛。在转的过程呢，你才有这个力上来，它就全部一定要连在一起。如果少做一个动作的话，它是过不去的。"

所以要**往后站一点点**，给自己留出三样东西：

| 要留出的空间 | 用来干什么 |
| :--- | :--- |
| 迈腿 | 有一个迈腿的动作 |
| 舒展 | 有一个舒展的动作 |
| 压腰 | 压腰的时候还会更接近球 |

> 教练原话："我压腰的时候呢，我又会更接近球，对不对？所以呢我们要把这个考虑进去。我要有一个开腿，还要压腰，还要动手，这些都是剧烈的，所以我要往后站点。"

## 二、别那么早动，等球过了网再动

平时练网前技术，对手一扔我们就开始动了。但被动球不一样。

> 教练原话："在打被动的时候呢，你会等球过了网，你才开始动。为什么？什么叫被动？"

教练自己把"被动"这两个字解释了一遍：

> 教练原话："我比方说我接一个球打，他挡了网过了网，我才反应过来，我才去接。所以我们才会被动。"

**被动就是我们反应慢了半步。** 所以要故意等球过网再启动，才有后面的空间。

> 教练原话："正好呢我是掌握好这个空间，可以舒展，可以首先我要可以迈大步……同时我可以舒展。脚跟落地，我可以压腰、压腿。再打。这个空间只要算进去，才是对的。"

## 三、脚后跟先落地，跟手要一起下去

这是这节最要紧的一点。教练说得很直接：

> 教练原话："这个动作一定要同时做，你这个力量下去，你这个手就可以上来了。"

他专门点了两种错误做法：

> 教练原话："你的脚先落地，然后你身体没有跟上去，你再说也是很奇怪；还是你先压你的腰，有些人会这样子。很难做的，空间不对的。相信我。"

教练说，这个动作做对了，手上其实**不用发力**：

> 教练原话："手都不用发力，很好控制的。往后站点，压腿下去，脚跟，往外转身体，往外走。这个力量你掌握好的时候，你这个（手）呢你都不用想着做什么多余动作，这个力量下去，你只需要抬你手、转你手就够了。"

## 四、朝斜对角，不是朝前

很多人下意识往前推，教练纠正：

> 教练原话："记得我们说你不会朝前，我们朝外的，朝斜对脚。"

## 五、左手往后顶，压低才带得过去

> 教练原话："一定要把这个脚后跟先（落地），然后这个一起下去，然后左手往后顶，一定要做好这动作。"

**压得越低越好带：**

> 教练原话："压低的话压低点啊，你压得越低，球就越容易上。你越高，它就越难控制。压低（重心），它就越容易过去，越好去带过去。"

**击球的位置**在肚子到胸口之间：

> 教练原话："就是这个角度，肚子这边或胸口差不多。"

## 怎么练

| 要点 | 原话抓手 |
| :--- | :--- |
| 站位往后一点，留出迈腿、舒展、压腰的空间 | "我要有一个开腿，还要压腰，还要动手……所以我要往后站点" |
| 别那么早动，等球过了网再启动 | "你会等球过了网，你才开始动" |
| 太近缩着打不行 | "缩着打是不可以的，我们是要先舒展，再转回来再做" |
| 脚后跟先落地，力量下去手就上来 | "这个力量下去，你这个手就可以上来了" |
| 手上不用发力 | "你只需要抬你手、转你手就够了" |
| 朝斜对角，不朝前 | "你不会朝前，我们朝外的，朝斜对脚" |
| 左手往后顶 | "然后左手往后顶，一定要做好这动作" |
| 压得越低越好带 | "你压得越低，球就越容易上" |
| 击球在肚子到胸口 | "肚子这边或胸口差不多" |
