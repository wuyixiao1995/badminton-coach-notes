# 09. 正手劈吊对角 3（劈球挥拍方法）

> 📺 致命吊球 · 第 9 节 · 约 20 分钟
> 教练：李宇轩

这一节把包切的手法接到挥拍里。开头教练就说得很直接：**握排队了，就只需要"1、2、往前去"**。

## 一、挥拍：跟正常一样，只是最后直接推

> 教练原话："挥拍跟正常的一样，架拍一样，球应该在你的高点，左手先下来，到这边的时候（左脚塌）、上你的右手，然后握拍你就直接接近球、直接推就行了。"

**不用刻意把手往左边绕**——

> 教练原话："我们不用刻意往这边转，由于我们的握拍已经有这个包切动作了，我们就往前、切，就可以了。至于它包到哪里你不用太在意，只要你有这个动作就行。"

## 二、最重要的规矩：不抓紧

教练用很长的篇幅强调这一点：

> 教练原话："当我们在做这个推、把手腕往前推的时候，我们不抓紧。我们可以甩得快、挥拍可以很快，但是我们不抓紧。"

抓紧的后果有两个：

1. **球会飞很远**——"抓紧的话，它就会有多余的一份力量，这个球会很远的"，切多点"不只远，而且会出界"。
2. **时机不对会变"碰"**——"如果你提前抓紧、先抓才碰到球，这个球反而会直接下网，或者往上飞很多"。

> 教练原话："劈吊的时候千万不要去抓紧，我们没有加力量，我们只是回得快而已。手指放松，切下来就好。"
> 教练原话："（要学会）放松可以切得快，看到吗？球是直接下去的。"

教练也说了：**加力量是后面"劈杀"才学的**，现在不学。

## 三、切哪个点：球头正面的侧边

> 教练原话："你只需要架拍、左手下来，切到他的球头边就行了。不用说切到整个圆全没有，那个是整个圆全没有了。"

他专门圈定了范围：

- **不是切太薄**（切到球头最侧面）——"这个球就没有往前的力量了，可能就直接下网了"。
- **不是切正中间**（正撞）——那就不叫劈吊了。
- 正确是：**斜着切球头正面的侧边**。

## 四、击球时拍面：朝上或朝后，不能朝下

这是本节的技术核心，教练解释了两遍：

> 教练原话："我们击球的时候，球头一定会是朝上的，或者朝后一点，一定会这样切出去。"

有人会问"这样切球不是往上飞吗"？教练给了两个原因说明**球不会往上飞**：

> 教练原话："第一，你会这个（压腕的方法），你一压下来的时候手腕会下来的。第二，你切球的时候球会减速，加上地心引力，这球会下得很快。"

反过来，如果**击球那一刹拍头已经朝下**——"必下网。除非你突然抓紧、使使劲，这球会去得很远"。

> 教练原话："你不可以是这个时候（拍头朝下）推着切球，再继续切下来，一定会下网。你应该是这样子推，同时再继续压，你就做出一个包切动作。"

## 五、引拍要小：这是控制的关键

教练把这一点跟杀球对比：

> 教练原话："架的拍一样，下左手的时候，这边上肘，手腕往前推。但做劈吊的时候，肘不会抬得太高，就跟刚刚我们练碰球是一样的。你抬得太高，力度会太大，引拍会太大。"

引拍太大的后果：**切不准球头**。

> 教练原话："每个国际球员做一个劈吊，你看他们动作很快，但他们的引拍都是小的。他们在这边，但是很快，所以显得好像很大。"

## 六、击球点：右前方，不能在中间或左边

这是本节第二个核心，教练用演示把三种错误都演了：

| 击球点 | 结果 |
| :--- | :--- |
| **正中间** | "很容易下网，而且这个角度如果过网一定出界" |
| **左边** | "更不用说，直接碰地板" |
| **太靠外** | "很难到对角，会到中间" |
| **右前方**（正确） | "刚刚好" |

> 教练原话："正确的击球点会在你侧身完后转过来，在你的右肩上方，这个点是最好的。"

他还解释了为什么：这个位置拍面是"稍微朝前、斜一点朝内"的，切出去正好到对角；放中间或左边，拍面角度就不对了。

## 最后：这节总结

| 要点 | 原话抓手 |
| :--- | :--- |
| 握排队了，只要"往前去" | "1、2、往前去就可以了" |
| 不刻意绕，靠握拍自然包切 | "由于握拍有这个包切动作，我们就往前切就行" |
| 绝不抓紧 | "我们可以甩得快，但我们不抓紧" |
| 抓紧 = 出界 / 变碰球 | "提前抓紧会下网，或者往上飞很多" |
| 切球头正面的侧边 | "斜着切它的旁边，不要切太薄" |
| 击球拍面朝上或朝后 | "拍头朝下一定下网，除非突然抓紧" |
| 引拍要小 | "国际球员动作很快，但引拍都是小的" |
| 击球点在右肩前方 | "在中间会下网，在左边直接碰地板" |
