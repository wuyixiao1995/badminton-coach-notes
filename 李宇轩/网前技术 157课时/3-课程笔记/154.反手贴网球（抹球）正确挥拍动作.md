# 154.反手贴网球（抹球）正确挥拍动作

> 📺 网前技术 157课时 · 第 154 节 · 约 8 分钟
> 教练：李宇轩

反手的抹球，动作跟正手是一套，方向反过来。教练先示范了完整的样子：跳过去，不用看网，直接扑。

## 一、要求还是那几条

> 教练原话："我们要就是抹的又快又准，然后下的又快，而且不可以碰网，不可以过网。"

> 教练原话："看我跳过去我都不用看了，我不用看这边，我就直接扑。只要你握拍对，你的动作对，很简单的。"

## 二、握法还是拇指顶宽面

> 教练原话："握拍还是拇指顶在宽面这种握法。"

## 三、抬拍高度：跟网一个高度

这是本节第一个重点：

> 教练原话："现在手会在我的左肩这边，然后手的高度一样，跟网一个高度。"

> 教练原话："我们唯一可以知道什么情况下我在扑不会打网，就是我一扑了球，我往上走，因为上面是没有网的嘛，我往上走就没有事情。我只要跟网一高度，怕我已经打网。"

> 教练原话："所以我们抬上来抬到眼睛这个高度，然后我的手可以放在中间这边或左眼前面都没有问题。"

## 四、手在左眼或中间，拍斜 45 度

> 教练原话："正面的话，我们就是抬上来往这边放点，然后斜就行了，差不多在我的中间、我的眼睛这边就行了，降控拍 45 度。"

> 教练原话："这个不用伸那么直啊，甚至我往这边去的时候，它就有点屈了，它不是直的，它是有点屈的。"

## 五、手放在靠中间会先碰网

> 教练原话："正常来说我们不会在这边扑，因为我在这边扑的话，我刚要推，我跟你说，你看到吗？牌面是这样子的，我必打网。如果放的那么靠中间。"

> 教练原话："等一下我们在带上去的时候，我会给你说球放外面。如果放外面的话呢，你看，在我这子，我一刚要推一点，你看到吗？它就斜了，有点斜了，就碰到网袋了，我还没有碰球就先碰网。但是如果你看我放在外面的话，我往前推完后，这样子抹的话，都没这个动作，不会先碰，我会先碰球。"

> 教练原话："所以在反手这边呢，我们会放越靠外越好扑。"

## 六、现在练动作先放左眼这边

> 教练原话："我们现在只是在学动作。我们就把球放在我的左眼这边就行了。一会我们带上去，我会给你们说要侧身。"

## 七、保持往后立腕，往后越多要开越多

> 教练原话："我抬拍，球接近球，对吧？我拍面就对着球，所以我的手自然会往这边舒展。我在舒展的过程中，我的手腕要保持往后立着。"

> 教练原话："你要往后越多呢，这边开多点就行了。我现在这已经是极限了吗？我这边稍微开一点的话，你看还就越起，往后了。"

> 教练原话："当然我不用开那么夸张啊，就不要你们握的很紧，稍微有点放松就行了。有一点空间，就是说这个球拍呢会更靠手指这边就行了。"

## 八、推的时候要往上转着抹

这一段是反手抹球跟正手最不一样的地方：

> 教练原话："我要推的时候，按理来说我们扑球是这样子吗？一推我们抓紧吗？但如果我这样子的话，一定会打网。那怎样？我一推的时候我就得往上，看拇指，往上抬。"

> 教练原话："本来正手是往这边转吗，这边是往这边转。往这边转这样子，转上来。但是我是往前推，推，再往后拉回来的时候呢，我就转上去。"

> 教练原话："所以我是，推，我想拉回来，但是我不拉回来，我是推，我想拉手，我就往上转着拉。"

> 教练原话："碰到拉回来的时候是往上，往上绕的时候拉回来。"

## 九、小臂一起往上收

> 教练原话："在这个过程，我的手会翻了，就是正手换回来反手一模一样，就是好像去盖这个球，但是我不可以这样过球。我一推一翻的时候，我就得翻，拉回来的时候，小臂一起上去。"

> 教练原话："推翻，我要拉回来的时候，小臂上去就行了，它就有这个现象。"

## 十、抹的是侧面，不是上面

> 教练原话："当我们在抹球的时候，不管是正手或反手，球这样子，我们是抹这样子，反手我们是这样子抹，我们不是抹上面的啊，一上面的话一定过网。我们是这样子抹这样摸。"

> 教练原话："所以我是一推我一抹的时候，我一抹我就往后拉就行了。接近球我一这样子摩擦，往前上方摩擦时候，我就往后拉我的手腕。"

> 教练原话："摩我拉回来，接近球保持蓄力，接近球推的时候磨，往上磨，然后往后收回来，我手腕收回来的时候，小臂从上去就行了。"

## 十一、怎么练

| 要点 | 原话抓手 |
| :--- | :--- |
| 要求：快、准、下得快、不碰网 | "不可以碰网，不可以过网" |
| 握法拇指顶宽面 | "拇指顶在宽面这种握法" |
| 抬拍到跟网一个高度 | "跟网一个高度" |
| 手在左眼前或中间，拍斜 45 度 | "差不多在我的中间、我的眼睛这边" |
| 放中间会先碰到网 | "我还没有碰球就先碰网" |
| 球放越靠外越好扑 | "我们会放越靠外越好扑" |
| 手腕往后立，越往后手指开越多 | "你要往后越多呢，这边开多点就行了" |
| 推的时候往上转着抹 | "我就往上转着拉" |
| 小臂跟着往上收 | "拉回来的时候，小臂上去就行了" |
| 抹的是球的侧面 | "我们不是抹上面的啊" |
