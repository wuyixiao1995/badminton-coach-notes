# 03. 什么时候做启动

> 📺 步伐中的的步法45节完结 · 第 3 节 · 约 15 分钟
> 教练：李宇轩

这是启动里最容易被问、也最容易做错的一节：**到底什么时候做启动？** 教练分两层来讲，讲完了还点出了一个让人"老是卡一下"的真正原因。

## 一、第一层答案：对方击球的那一下

问题很直白——启动该在对方击球**前**、击球**时**、还是击球**后**？

> 教练原话："很明显，我们一定要在对方击球的时候做启动。"

理由也简单，因为**启动是爆发力**：

> 教练原话："我一下子一碰地，我就得'啪'地爆出去。不可以是这个样子——力就歇了。但是如果你提前启动，你要去哪里？他都还没打，你立即蹬出去，完蛋了。"

三个时机的后果：

| 时机 | 结果 |
|------|------|
| **提前启动** | 力泄了 / 跑错方向 / 被假动作骗 |
| **击球后才启动** | 跟之前小朋友的示范一样，球都落地了才启动，肯定接不到 |
| **对方击球瞬间** | ✅ 正确 |

## 二、既然都知道，为什么还是接不到球

答案人人会说，但为什么场上还是接不到？教练说了一类学员的典型反应：

> 教练原话："我有时候我提前启动，你们为什么会提前启动呢？就是因为你们本来也知道必须要在同时启动。但是因为你们老是接不到球——你们启动后还是接不到球，所以觉得'要不然就提前启动看看'，然后发现'哇又接不到'。**可怕的是，你们不知道怎么改，就养成一个习惯了。**"

这个逻辑链很关键：

```
知道要在击球瞬间启动
  → 但没做对细节，还是接不到
  → 于是想提前启动
  → 还是接不到 / 被骗
  → 习惯就坏掉了
```

所以这一节真正要讲的是**第二层答案**——那些"没做对的细节"。

## 三、第二层答案：启动是一个"过程"

> 教练原话："启动是一个过程。它是一个小跳，然后往下踏。或者更准确地讲，它是**离开地，然后往下踏**。启动不是'啪'一下就做了，它是一个过程。"

这个过程有两个节点：

1. **开始** = 离开地面（离地）
2. **结束** = 往下踏地（踏地）

**关键就在这里**：大多数人做启动，是等对方**碰到球、球都飞出来了**才离开地。等你往下踏的时候，球都快落地了。

> 教练原话："我们要把这个说清楚——什么叫'对方打的时候做启动'？也就是说，**对方架拍、刚引拍那一刹那，我们就得离地了**。等他碰球、球刚飞出来的时候，我们正好踏地。"

教练用国际比赛画面举例：

> 教练原话："穿白衣服的是滔田（陶菲克），黄衣服是钟伟（李宗伟）。滔天一刚引拍，钟伟就开始离开地了；滔天击球球开始飞出来了，刚好钟伟踏地，他就知道要往哪里跑了。"

也就是：**对方引拍 = 我离地；对方触球 = 我踏地。** 这才叫"击球瞬间启动"。

## 四、压腿（弹簧腿）——不只是发力，更是在看球

为什么要在落地的过程中弯腿？因为它有**两个作用**：

> 教练原话："当我要碰地的这一刹那，我会往下坐，然后腿稍微收起来一点。刚好我一碰地、腿一紧的时候，我就可以看出来球是飞哪里了。"

- **作用一**：帮你能发力（往左去、往右去的那条腿蹬地）；
- **作用二**（更重要）：**在下压的过程中看清球往哪飞**。脚一碰地，你就该知道用哪条腿发力了。

**一定要避免的误解**：

> 教练原话："我是在空中快落地的时候就做（下压），不是碰地的时候才做。如果碰地的时候才要压低重心，那就又多出一个过程了。我碰地的时候，按理来说我就应该知道我要往哪里发力了。"

这就是"弹簧腿"的由来：

> 教练原话："很多人问我弹簧腿怎么练——你把启动做好，把往下压、腿绷紧的感觉做好，就有这个弹性了。"

## 五、最最最重要的一点：99% 是单腿启动

这是整节课的核心，也是最多人踩的坑。

> 教练原话："你们学启动是不是都这样子？压下去，两个腿，然后两个腿一起跳，然后再发力……打球的时候，90%、95%，或者99%大部分时间，你是**没有办法两个腿一起做这个启动的**。"

**为什么？因为你在移动中。**

> 教练原话："当你打起球来的时候，你在移动——你就没办法做这个动作了。对方就打了，他没有给你这个时间停在这边。"

如果只会"两个腿一起跳"这一种启动，实战中必然变成：

```
打完球 → 对方打了 → 先停下来站好 → 再做启动
```

> 教练原话："他打了，你为了做这个动作要先停……你要做（启动）时球都要掉了，启动就没有了。"

**结果就是"二次启动"（启动两次）** ——也就是很多人抱怨的"老是卡一下、不知道为什么"。

> 教练原话："你们是做对的时间做启动，但为什么会有两次启动？为什么你不赶紧做启动？很多关于启动时间做不对的问题，你们一直不知道哪里出了问题。"

正确的做法是：**打完球回位，直接顺着惯性用一条"中心腿"离地启动。**

> 教练原话："你看如果我打完球回来，他一准备打，我不会站着启动，我会直接用这个推。刚好我一落地，我蹲下去，正好可以（知道往哪跑）。"

教练也演示了一个容易误判的画面：

> 教练原话："有时你会看到我好像两条腿一起动——我跟你们说，我们都不是两个腿一起跳起来再往下发力。刚才那个动作，其实我是用左腿的。"

## 六、什么时候可以"两条腿一起"？

不是百分百不行，但**条件很窄**：

| 可以双腿启动的情况 | 说明 |
|------|------|
| **双打发球时站在后面** | 站着不动，可以由双腿启动 |
| **正手发高远球** | 同上，静止状态 |
| **网前挑球挑得特别高** | 有足够时间停下来再启动 |

> 教练原话："换句话说，**只要你是可以站着不动、重心中间没有在动，你是可以用两个腿一起离开地的**。大部分时间我们不会这样子。"

> 教练原话："后场球打得高可以吗？不可以。除了挑球（挑得特别高），你是没办法做的。"

**底层规律**：一旦有了来回、人一直在动，就必须用单腿启动。否则一定慢——**因为你压根没对上球的时间**。

> 教练原话："球是一直在动的，他没有说打过来停一下让你停、再做一个启动，没有。打球是一直连贯的。"

## 七、⚠️ 一个危险的训练习惯

教练特别提醒：**有些教练教启动的方式，会让人无意中养成"两次启动"。**

> 教练原话："有些教练会说'启动去，回来，跳，我（喊）第二个，再回来，跳'——你发现我做两个跳嘛。他们觉得启动是一个开始、回来是一个结束……但如果你这样子做，无意当中你就会做两次启动。"

更可怕的是那种"回来停下来再做"的练法：

> 教练原话："第二个更可怕的是——如果教练让你回来做这个跳，是让你**停下来**，这样子：启动、回来、停、再来启动、回来、停。**这就是我们一直说不要做的**，打完球不可以这样子停下来再动。"

> 教练原话："如果你们是这么练——不要再这么练了，不是这么练的。"

## 八、那"看起来像并步"是怎么回事

有人会说："我不启动可以吗？我看你直接并步就跑了。"

> 教练原话："如果你们这样认为、这么学就错了。虽然看上去好像是并步，但那个并步**其实是一个启动**。它在的感觉好像是并步，但里面是连着一个启动的。"

## 九、启动要不要跳高？

这是个常见疑问。答案是：**起球（防守）时不跳高；往下打（进攻）时可以稍微跳高。**

> 教练原话："基本上，我们只要一起球，都不会跳高。我们会碰就直接打开，直接防守的启动，直接站好、打开，我就可以发力了。"

**为什么进攻时可以跳高？** 关键在球过网的时间差：

> 教练原话："如果我起球，他（对方）一打就是直接下来、直接飞。但如果我往下打，我打过去，他挡——球会**上来、过网、再下来**。所以他有这个时间。**有这个时间差，我就可以跳高一点，落地再跑。**"

> 教练原话："如果你跳得太高，在空中太久，他一碰球球就出来了，你没办法发力。**起球的话，球下来的太快，没有一个'往上再往下'的过程。**"

所以：

| 情况 | 跳不跳高 |
|------|------|
| 起高球 / 被动防守 | 不跳高，直接打开下压 |
| 往下打（进攻）后上网 | 可以稍微跳高，借下落力量加快启动 |

教练最后也补了一句：

> 教练原话："如果我不这么跳也可以——我自己打球也不是跳那么高，我就站着，立马就跑了。"

## 最后：这节总结

| 问题 | 答案 |
|------|------|
| **什么时候启动** | 对方**引拍**时离地，对方**触球**瞬间踏地 |
| **为什么提前/滞后都不行** | 提前会泄力、跑错、被骗；滞后球都掉了 |
| **启动是什么** | 一个"离地 → 往下踏"的过程，不是瞬间动作 |
| **压腿为什么重要** | 既帮你发力，也帮你**在落地过程中看清球向** |
| **99% 怎么做** | 用**单腿（中心腿）**顺着惯性启动，不是双腿跳 |
| **什么时候能双腿** | 只有站着不动时（双打发球、正手发高远、挑球挑特别高） |
| **起球能跳高吗** | 不能，球太快；进攻往下打时可以稍跳 |
| **警惕什么** | 别练"回来停住再启动"，那会养成二次启动 |
