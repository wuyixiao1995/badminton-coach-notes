# 32. 反手（普通挡网技术）手指带动手腕动作

> 📺 网前技术157课时 · 第 32 节 · 约 3 分钟
> 教练：李宇轩

这一节很短，就讲一件事：所谓"拇指推"，推的不是拇指，是拇指带动手腕往前。两种握法教练都拆了一遍。

## 第一种握法：拇指一推，手腕跟着走

拇指正面顶宽面的握法。

推的时候，不是只动拇指，不是这样单独戳一下。

> 教练原话："不是只动拇指，不是这样子，不是啊，是握着推的时候带动你手腕，推、推、推。"

而且推之前一定要先拉。先把手往后放，拉开空间，然后才能推。整个过程是"拉—推"。

> 教练原话："当我们要做推之前呢，我们一定要先拉，要放成这样子了。我要先往后拉，我才可以推。"

## 第二种握法：往后是斜后方，不能绕圈

换成李宗伟那种握法，引拍的方向不一样了。

手腕是往斜后方倒的，不是往下压。往下压的话拍面就不对了；往斜后方倒，拍面还是朝前的。

> 教练原话："我握拍是这样握的吧，我弯的时候，你看，我会这样子斜着往后。我不是这样子，我是这样斜着的，斜后方往后。因为它不是往下，它不是往这样子，它是斜后方。"

推的时候，用拇指那个侧边——不是正中间，稍微斜一点的位置——往前去，带动手腕。

> 教练原话："我推的时候，我会用拇指这边，这边不是正中间，稍微斜一点，这样子去推，带动我的手腕。推、推。"

这里教练专门点了一个错误：有人握了第二种握法之后，会绕回来再推、绕回来再推，画一个圈。

> 教练原话："有些人会觉得是这样——本来是这样握拍，我这样子直接推行了，他们会绕回来再推。没有啊，你是这样，拇指侧边就这样子往前推，带动手腕就行了。"

拍面就是正的往前，不是绕，不是转。

## 两种握法对比

| | 第一种（拇指正面顶宽面） | 第二种（拇指侧边顶，类李宗伟） |
| :--- | :--- | :--- |
| 引拍方向 | 往后拉 | 往斜后方倒手腕 |
| 拍面 | 拉的时候拍面变化不大 | 拉的时候拍面还是朝前 |
| 发力 | 拇指正面往前顶，带动手腕 | 拇指侧边往前顶，带动手腕 |
| 忌讳 | 只动拇指不带动手腕 | 绕回来再推、画圈 |

共同点只有一个：先拉，再推；拇指只是启动的那一下，真正出去的是手腕。
