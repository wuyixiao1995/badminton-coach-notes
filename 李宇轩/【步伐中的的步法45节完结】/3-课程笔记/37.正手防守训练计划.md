# 37. 正手防守训练计划：先练并步，再练一步

> 📺 【步伐中的的步法45节完结】 · 第 37 节 · 约 9 分钟
> 教练：李宇轩

这一节讲怎么练。前面正手、反拍的防守原理都讲完了，这里给出一套从基础到实战的练法。

## 一、基础训练：两边跑动

左右两边来回跑，**带上手**，手要碰到白线的位置，不要垂下去。

握拍随时切换：去正手用正手握法，去反拍拇指过来用斜棱。

> 教练原话："练这个，其实当你单练这个呢，你已经练到很多东西了。你可以练到你的手，你可以让你的腿部力量（上来）。"

教练强调这是**最基础的，一定要先这么练**（打比赛时挡网后回前后站，也是从这个练起）。

### 三个必须做对的点

**1. 重心腿要站对**

防这边 → 回来 → 重心在这边站好 → 打开启动 → 发力 → 再做。回来站好，打开，右腿发力，伸手。

> 教练原话："一定一定要做对，千万不要带过。你要把这启动练得很熟，往下压一点，练你大腿。"

**2. 左手出去要会往后顶**

> 教练原话："你的左手出去（的时候），要会往后顶……这样子的话你就可以站得稳。要是如果你不会往后顶的话，我给你下手球，全部下手球，你只要是往下（走），这左手一定要往后顶。不会往后顶的话，我跟你讲你会站不稳的，你重心这边锁不住的。"

**3. 并步要小**

> 教练原话："记得去正手我们并步，千万别给我那么大，小一点……你去（够到）就足够到边线了。"

教练说：这个练会了，**防守步伐你已经退了百分之七八十**了——腿部力量、重心调整、手上动作，都搞定了。

## 二、进阶：把正手调成"一步"

基础熟了之后，慢慢把正手这边改成一步防守。

> 教练原话："小孩子的话，你们不要这么学，你们要用并步也可以……在业余圈里面是没有问题的。只有你遇到很强的对手，杀得很快，你才需要直接伸手、直接迈腿。"

## 三、让训练有"喘气"，别站着等

教练在这节反复打断：喂球的人要**发快点**。

> 教练原话："你要发快点，我一挡完你就直接发了……发远点，直接发远点，平一点无所谓，使劲点发，发到位。"

意思就是别让你的搭档站着等球落下来——真实比赛里不会给你这个时间。教练自己示范的时候一直在"抱怨"：

> 教练原话："我都还没有回位呢，这球在往上飞……在这等太久了。"

这一点的用意很清楚：**训练的时候就要把节奏拉起来**，否则练出来的防守是"等来的"，不是"抢来的"。

## 四、什么时候能并步，什么时候只能一步

这是这节最有价值的一个判断，教练解释得很细：

- **挑得高、站得稳**：回中间站稳了，等他杀，这时候**来得及做并步**
- **还在退的过程中他就杀了**：这时候**只来得及做一步**

> 教练原话："如果你挑完，我在退的过程中，突然间他杀了……我一做一个启动，我基本上只能做一步了。你们可以试一下，你们就明白我在说什么了。"

教练给的建议：

- **直线防守（边线那边）基本不做并步，都用一步**——因为时间不允许
- **在中间的位置可以用一步**——对手球太快、球又近，打开就碰到了
- **想练并步**：挑高一点 → 回到中间 → 站稳一点 → 再启动 → 做并步

> 教练原话："练的时候你可以两个都一起练，但是你大概会了，你会一步了，就用一步了。"

## 五、带上前后场的完整练习

最后教练做了一组完整示范：挡网 → 回前后站 → 上网挑球 → 回来防守。并步版和一步版各做一次。

教练还试了带后场的版本，说他做得"有点别扭"，所以**直接上一步**——因为真实情况下，直线挑完再想并步，"时间就不允许你怎么做"。

## 最后：这节总结

| 要点 | 原话抓手 |
| :--- | :--- |
| 先练两边跑动（最基础） | "练这个其实你已经练到很多东西了" |
| 左手要往后顶 | "不会往后顶的话……你重心这边锁不住的" |
| 并步要小 | "千万别给我那么大，小一点" |
| 喂球发快点，别站着等 | "在这等太久了" |
| 退的过程中被杀只能一步 | "基本上我只能做一步了" |
| 直线用一步，中间也可一步 | "你大概会了，你会一步了，就用一步了" |
