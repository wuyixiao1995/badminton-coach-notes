# 146.正手扑贴网球（抹球）-握拍的调整

> 📺 网前技术 157课时 · 第 146 节 · 约 8 分钟
> 教练：李宇轩

上一节讲了要往上收小臂，但还是会打网带。这一节给答案：改握拍。

## 一、为什么会先碰到网

> 教练原话："我们用正常握法，当我们在做手腕往后倒接近球时候，很多人一要推的时候呢，一定会先推到这边，一定会的。每一次你们扑球，你们碰到，一定是先碰到这边才会碰到球。因为为什么？我们的球拍是从外面往内走的。"

> 教练原话："如果是反手的话，我们是从左边去右边。那就是说我们如果用反手，我们去扑球的话，很多人一碰都会先碰到这边。所以这个是肯定的，这是全世界人遇到的问题都是一样的。"

## 二、解决办法就是把拍转过来

> 教练原话："我只要可以把这个球拍改成这边先不碰网线，先碰到球就行了。一样的位置，我只需要把这球拍这样子转，他就不会碰到了。所以他上来的时候是这样子上。"

## 三、从正常握法一路转到类似反手握法

> 教练原话："正常握法，现在呢我把它换去一个塔普费克握法，就是往这边转，然后再往这边转一点点，就类似于你的拇指好像放在这个侧棱这边这样子，就很夸张的塔普费克握法。"

> 教练原话："本来是这样子吗？现在我在一样的位置，我只需要转这球拍，转转转转转，就这样子了。所以我每次接近球的时候，我只要手腕往后立，我不会先碰到网，我这边是已经离开了，我变成是这边先碰到球了。"

> 教练原话："要是如果我把这个球拍再往这边转多点，他就不会碰到这边，他也不会碰上去，他会先碰到这边。"

> 教练原话："我们不会这样握拍啊，所以我们是正常握法改成一个塔普费克握法，可能还是有一点会碰到，我再转多一点是最安全的，这个是最好的。"

## 四、转成什么样：像反手握法但拇指换位置

> 教练原话："转一点点这是塔普费克握法，我再往这边再转多一点点，这个按理说应该是一个反手握法，但是我的拇指不放这边，我拇指放这边。就变成，拇指放在这边，是在侧棱这边形的。"

> 教练原话："有点好像反手握法，只不过拇指不放这边，拇指放这边。有点这样子，拇指不放上面，放这边。"

## 五、抬拍高度不能低

> 教练原话："动作最多人做错在哪里？就是手没有抬上来，每个很喜欢放下面，只想在抹球。这个是做不到的，即便你这样是伸直，也是不行的。因为你一打头你就会打到网带了。"

> 教练原话："我们第一个动作一定要保证，就是我抬手的时候呢，是跟网带一个高度，而且是往外伸。这样子我可以舒展着打，同时我可以往上收拍。"

## 六、不是靠翻小臂去过网

教练解释了为什么有人一再被判过网击球：

> 教练原话："如果你这样做的话呢，你刚要碰到球了，你的拍已经过网了。比起你往后立正，这样子变拍，你可以立着手腕，没有过网的情况下先碰球头。"

> 教练原话："如果你是这样子的话，这样子先碰球，你就得翻你小臂，你翻小臂，你看你要拍就这样子就已经过网了。所以为什么很多人在练扑球的时候呢，每次过网，很多人会这么练。"

## 七、改好之后就不用纠结了

> 教练原话："我要怎么做的很干净，同时可以快，而且更重要是我可以不用想。就是我看到球，我直接抹过去就行了。"

> 教练原话："最好的扑球方法就是，我看到球差不多这个高度，我握好了拍，保证我这样子甩过去，只要碰了球，他就可以很干净的过我。我都不用想，我看上去我直接往上跳立起来。网没有动了，没有听到声音的，我直接都不用看了。我握法改过来，我不用那么纠结。"

## 八、怎么练

| 要点 | 原话抓手 |
| :--- | :--- |
| 先承认一定会先碰到网 | "一定是先碰到这边才会碰到球" |
| 关键动作就是把拍转过来 | "我只需要把这球拍这样子转，他就不会碰到了" |
| 先转成塔普费克握法 | "往这边转，然后再往这边转一点点" |
| 最安全再转多一点点 | "再转多一点是最安全的，这个是最好的" |
| 转了以后像反手握法但拇指换到侧棱 | "我的拇指不放这边，我拇指放这边" |
| 手要抬到网带高度 | "我抬手的时候呢，是跟网带一个高度" |
| 不要靠翻小臂去过网 | "你翻小臂，你要拍就已经过网了" |
| 改好握拍就不碰网了 | "网没有动了，没有听到声音的" |

## 九、相机拍出来是过网，其实没有

> 教练原话："从侧面看，你一定会感觉到好像我的拍过网，即便我这样子。但是如果是平着，其实是没有过网的。如果把这个相机往这边放点，看出来是没有过网的，这是平的。"

> 教练原话："所以相机角度你们也是要考虑一下。"
