# 14. 正手劈对角（不转身劈吊）

> 📺 致命吊球 · 第 14 节 · 约 20 分钟
> 教练：李宇轩

这一节专门讲不转身劈吊。教练开头就说：**方法完全一样，唯一区别就是不转身，以及击球点的位置。**

## 一、为什么会有不转身的打法

> 教练原话："不转身动作通常都是因为球太靠边，我们采用不转身动作。"

## 二、第一个要点：击球点位置完全不同

这是本节最核心的内容，教练用对比讲得很透：

- **转身动作**：左腿往后、还有转身动作，所以球"刚好过去就行了"，击球点可以离身近一点。
- **不转身**：没有这个转身，"要拉开一点"，球会在——**"差不多在我的左腿这边"**。

> 教练原话："差不多是如果我这样架拍，他刚好在我左手可能离我左腿一点点，就对了。"

**关键：不能为了隐蔽硬把球放在身边。**

> 教练原话："很多人觉得为了隐蔽性，我就让他在我旁边——没有人可以这样做的。没有一个人可以这样子跳起来在这边击球的。不可能。如果你这么做，第一这个球会飘，因为你的切点在这边，是往上切的。第二这个球没有往前去，你是往上切的。"

而且一旦你"放身边切"，动作就变形了——"你的动作就错了，你就没有这个上肘动作，肘可能要往后了，一看就是错的挥拍动作"。

## 三、只能"稍微转一点点"

不转身不等于完全不动：

> 教练原话："我不可能是你一点都不转，不可能，这多奇怪。我一定是左这边会转一点点，然后我走上前，这么吊。"

但转的幅度有上限——**大概 45 度**："我说转一点，我没有说转那么多。不可能转那么多，这样子我都变成转身动作了。"

## 四、引拍一定要小

> 教练原话："跟转身动作一样，它不会引拍太大。一定是架起来、这边倒、劈。你不会是这样子引拍那么夸张，不可能的，你翻那么大，球就过你，你会错过切球的最好时机。"

## 五、第三个要点：球不能在最高点

这是本节另一个关键技术点：

> 教练原话："这个球不会在最高点。你不可能把手伸得那么直，不可能。为什么呢？不转身动作通常都是因为球太靠边……如果你能够（打最高点），那么（高），你就可以转身了。"

> 教练原话："基本上我伸得越高，它就越（靠边）……如果这种球，我就可以转身了。"

所以不转身的击球点**永远在右前方一点**，"已经够高了，再高一点就很奇怪，这是不可能发生的"。

## 六、切法：手不能"往下"，也不能倒太多

> 教练原话："当我们在切的时候，我们的手不可以是这样子（从上面往下）的时候切。不转身也是一样，最多可能（平一点）还可以接受，再下就接受不了了，会下网。"

> 教练原话："尤其是如果你想加速的话，你不会这样子架拍，你一定会是这样击球——不可以。我们击球一定要稍微这样子击球就正好。而且球是一个减速球，所以我一抬上来就直接接近球，什么都不用倒那么多，放松、直接唱就可以。"

**手腕不要倒太多，放松手指。**

## 七、步法：跳起来"摆平身体"，左脚点地推回来

教练把落地细节讲得极细，因为他预判有人会问：

> 教练原话："跳起来摆平身体，这个（左脚）会进来的时候（先）碰到，但这不是说有力量的，它是带过，然后再退回来。"

> 教练原话："它是好像这边跳，然后这个一落地再推回来，有一个'推再推回来'。不是我跳起来特意去往后发力再发力，不是这样。就是跳起来好像带过一样，到时候这个腿碰到，然后再退回来，因为到时候我要回来就要用这个右腿发力。"

所以**重心不往前**，"跳起来、搭搭、跑回来"。

## 八、还会失误的原因

教练最后收了一遍：

| 表现 | 原因 |
| :--- | :--- |
| 出界 | 引拍太大，或者抓紧了 |
| 下网 | 球放得太接近身体 |
| 掉中间（不到边线） | 球放得太靠外 |
| 球重 / 远 / 下网 | 腰往前压了（跳起来还往前压） |

> 教练原话："你的腰顶住、空间对就行了。"

## 最后：这节总结

| 要点 | 原话抓手 |
| :--- | :--- |
| 为什么不转身 | "通常都是因为球太靠边" |
| 击球点在左腿外侧一点 | "刚好在我左手可能离我左腿一点点" |
| 不能硬放身边求隐蔽 | "没有一个人可以跳起来在这边击球，球会飘" |
| 只能转约 45 度 | "我一定是稍微转一点点，就劈了" |
| 引拍要小 | "翻那么大，球就过你，你会错过切球最好时机" |
| 球不能在最高点 | "你能打最高点，就可以转身了" |
| 切时手不能往下 | "手不可以这样切，再下就接受不了，会下网" |
| 落地是"带过 + 推回" | "跳起来好像带过，然后退回来" |
| 腰要顶住不往前压 | "你的腰顶住、空间对就行了" |
