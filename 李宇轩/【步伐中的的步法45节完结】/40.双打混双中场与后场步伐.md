# 40. 双打混双中场与后场步伐：杀完立刻换平行启动

> 📺 【步伐中的的步法45节完结】 · 第 40 节 · 约 20 分钟
> 教练：李宇轩

上一节讲网前那个人，这一节讲**后场那个人**。他管的范围是：**中场两边 + 后场两边**。

## 一、中场两边（平抽）

跑法和网前那个人一模一样，手上做平抽的动作。

**手**：往前伸一点，不要往外伸，拇指往前推。

**脚（慢节奏）**：启动 → 重心压下来推一步 → 收腿 → 并一步 → 重心推 → 打开压腿 → 再推。

这里又把"重心压下来"这个规律说了一遍：

> 教练原话："你越压得低，你就有距离；你站得越直，你就有高度（却）牺牲距离。"

**快节奏**：抽完直接启动，嗒嗒嗒再来。

### 为什么反拍抽完要用左腿当重心腿

教练这里解释得很细：

> 教练原话："为什么我的左腿是重心腿呢？因为我在右腿往后挪的时候，哪一个（腿）最靠近中间？因为我现在要往回、要往中间跑。"

答案：往后挪的时候**左腿在后面**，所以左腿是重心腿，用它启动。

### 挡网的情况

如果我不是抽，是**挡网**，那就肯定有时间回位了——因为前后站的时候，对方挡网他们两个人也要往前跑，都有跑的时间，我们足够时间去回位。

## 二、后场：吊球

吊球不管是吊直线、吊中间、吊对角，**回位方法都是一样的**，只是吊之前的位置可能有点差异。

**步法**：平行启动 → 并 → 确认步 → 打（和单打一样）。

教练说双打后场的吊球会发现**简单很多**：

> 教练原话："单打你会站这边吗？双打你站后面的话，你可以往后站一点，所以他的位置就离你很近啊。"

**回位**：吊完之后**不要并步，要交叉走**，然后平行启动。

> 教练原话："单打我们吊完后，我们会是进一步准备往前跑……我们会怎么回位呢？我们不会做并一步，我们会交叉走。"

这个和单打打高远球的回位是一样的。

## 三、后场：杀球——这一节的重点

吊球和杀球的**打法一样**（正手就并 + 转身杀或不转身杀），**唯一不一样就是回位**。

### 为什么杀球回位要"立刻"换平行启动

> 教练原话："杀球是一个快速球。我一旦杀完，基本上他就要打回来了。"

他可能抽我搭档（搭档封网），也可能抽对角（那就是我的）。所以你**落地后要立刻换成一个平行启动**。

具体怎么做：

> 教练原话："我杀完后，我一落地，我重心挪到（左）腿，然后我会做一个……也就是一个原地启动嘛，或者就是落地后推，就直接启动。"

顺序：**杀 → 落地 → 重心挪过去 → 原地平行启动**。

对比吊球：

- **吊球慢**：对方没那么快打，你可以"进一步再启动"
- **吊球快 / 对方抢得快**：那就和杀球一样，**打完直接平行启动**
- **点杀**：比吊球还快，更不用说，直接平行启动

> 教练原话："因为到最后就是在于他什么时候打。我掉完后，他没有第一时间可以打，我可以先进一步……这就是要对准他打球的时间。"

### 为什么杀完要平行启动（核心逻辑）

> 教练原话："我们平行启动就是为了他挡网不关我的事，都是我搭档的。他也不敢打我，他一定会抽。那我打完后，我就是要能够平行启动，万一他打这边我还能继续进攻。"

也就是说：**平行站是为了让你能横着动**，接住对方的抽球，保持连续进攻。

> 教练原话："往往你们每次在这边杀完后，他抽对角，很难接，对吧？因为你们打完后就是（原地站着那）这个情况，没有启动。"

这正好回答了那个常见的困惑：杀完球该用什么启动？——**平行启动**。

### 头顶杀球也是一样

打完重心挪到左腿，做一个平行启动。

### 杀完被抽到底线怎么办

如果是对方抽得很低、你没法再杀，那只能用**反拍**去处理了。教练说这属于更高级的内容，后面会单独讲。

## 最后：这节总结

| 要点 | 原话抓手 |
| :--- | :--- |
| 后场管中场两边+后场两边 | "中长两边和后长两边" |
| 压得越低，距离越远 | "你站得越直，你就有高度（却）牺牲距离" |
| 反拍抽完左腿是重心腿 | "我左腿在后面，这个将会是我（的重心腿）" |
| 吊球回位用交叉走 | "我们不会做并一步，我们会交叉走" |
| 杀球落地立刻平行启动 | "杀球是一个快速球，我一落地，它基本上就打回来" |
| 平行启动就是为了能横着动 | "万一他打这边，我还能继续进攻" |
