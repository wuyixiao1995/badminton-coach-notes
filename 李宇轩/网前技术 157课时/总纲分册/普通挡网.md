# 普通挡网（正手+反手）

## 一句话定位
网前所有软球技术的"根"：别人吊球/放网过来时，借跑动的速度轻轻把球碰回去，主动时抢点控节奏、被动时救球摆脱困境；这个动作学对了，后面搓球、勾球、推球才学得会 [2][4][28]。

## 核心要点
1. **拍面45度、靠手指手腕，不靠小臂**：正手是食指带动手腕往外翻45度碰球，小臂只是被动跟随 [4]；反手是拇指带动手腕往前推，"先拉再推"，拇指只是启动那一下 [32]。所有握法里拇指和食指都不能在同一方向，否则没有推挡功能 [3]。
2. **挡网不用发力，力量来自脚下**：跑动自带速度和惯性，手上"感觉好像没有在推"就够了；前提是你在移动，原地站着反而推不过网 [9][30][33]。
3. **拍子放在球的左边，等球掉下来**：不要抬着拍追球，到位时拍在球的左下方，球掉到该打的高度刚好翻腕碰上 [5]。
4. **击球高度在肚子范围，最高到肩**：国际球员挡网基本都在肚子高度；抢到特别高点可以直接搓或扑，不需要硬挡 [4][8]。
5. **球离你多远，手就调多少**：贴网远的翻少点拍面摆平些；离你近的往后拉多一点保持45度；手始终保持一个固定形状 [5][8]。
6. **低点换握法**：正手"膝盖以下我都会用李宗伟握法"，拍面才摆得平 [7][9]；反手低过膝盖快碰地的球，前两种握法都不行，必须换第四种（拇指顶侧棱）抬手腕 [35][36]。反手第二、三种握法覆盖面最广，"膝盖以上全部都可以" [29][31]。
7. **步伐与手同步**：左手往后顶到肩胛骨（"这个动作是所有网前球最重要的一点"），重心一直在左腿直到落地；右脚脚跟一落地的同时碰球，"千万不要碰了球才落地" [6][8][33]。
8. **越松越有弹性**：后三指/小拇指绝不能握紧，"你握的越紧，它好像一个石头一样"；全程放松，碰完顺着带回来 [9][34][38]。

## 常见错误与避坑
1. **竖着手碰球——"很多人是被碰球教坏的"**：很多教练在步伐课里教"伸上去碰就行"，这个动作僵、控不了球、抢不了高点，还会卡住后面所有技术的学习 [2][4]。
2. **后三指一握紧，整个手就死了**：小拇指一抓紧手腕就锁死，最后只能用小臂推，球飞很高还控不住；这个坏习惯多来自错误的竖握教学 [4][8][9][33]。
3. **抬拍太高去抢高点**：拍比球还高追着走，球掉下来就"来不及"了；个子矮更没道理抬那么高，那么高的球该做搓球 [4][5][8]。
4. **节奏错：先碰球后落地 / 脚没到位就打**：碰完才落地，人回不来，别人一推就完蛋；"不可以脚没有到位就打"，被动球全靠节奏借力 [6][34][36]。
5. **反手拿正手握法硬打**：低点拍面直接朝地，手腕怎么掰都掰不回来，"真的很多人受伤，因为不知道怎么改握法" [28][35]；左手不用（不往后顶）则站不稳、跨不远、回不了位 [6][9][36]。

## 训练方法
1. **原地空挥**：先练"翻、碰、回来"三拍节奏，很松不发力；注意是斜着往外翻，不是竖着倒手腕 [9]。
2. **握法切换**（反手）：不拿球，四种握法来回切换练到熟，至少掌握第一、第二、第四种 [28][37]。
3. **搭档抛球固定点**：正手练肚子高度、反手抛到眼前/左肩位置，各约100次；站位前后左右都留距离，身体正对球 [9][37][38]。
4. **加一步**：迈一步，脚跟落地和碰球同时；"千万不要碰了球才落地" [9][37]。
5. **家里自练**：吊球或吊绳子，练迈步-翻腕-碰的时机，翻的幅度要小 [9]。
6. **被动球专项**：换李宗伟/第四种握法，重心压低、腿要会弯，边塌边抬手腕；拍面抬起来与地面平行就对了 [9][37][38]。
7. **挡远网变体**：同样的动作，手腕往后多翻一点、拍面斜15度、使劲往下推就行 [8][9]。

## 子技能难度×收益评级表
| 子技能 | 难度 | 收益 | 一句话理由 |
| :--- | :--- | :--- | :--- |
| 正手三握法与推挡结构 | 低 | 高 | 纯认知不费力，"拇指食指不同向"一条就值回票价，是所有网前技术的底座 [3] |
| 放松握拍（后三指不抓紧） | 中 | 高 | 说来简单但坏习惯最顽固，改掉它整个手腕才活，控球立竿见影 [4][9] |
| 翻腕碰球（手指带动手腕） | 中 | 高 | 挡网的核心动作，练对后正反手通吃，也是学搓球勾球的前提 [4][32] |
| 击球点判断（拍等球） | 中 | 高 | 决定控球稳定性的分水岭，改掉"抬拍追球"后球质立刻变稳 [5] |
| 步伐配合（左手后顶+落地同时碰） | 中 | 高 | "所有网前球最重要的一点"，站不稳一切免谈，且挑球也靠它发力 [6][33] |
| 低点换握法（李宗伟/第四种） | 中 | 中 | 被动救球的关键开关，用得频率不算高但救一次就赚一次 [7][35] |
| 反手第二/三种握法普及 | 中 | 高 | 反手膝盖以上全靠它，还让正反手换拍变快，教练说"一定要学会" [29][34] |
| 挡远网加力变体 | 低 | 中 | 同动作微调（斜15度+推），上手极快，实战偶尔用 [9] |
