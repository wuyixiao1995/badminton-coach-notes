# 13. 正手劈对角 7（不同握拍怎么劈）

> 📺 致命吊球 · 第 13 节 · 约 8 分钟
> 教练：李宇轩

前面推荐的是李宗伟握法，这一节讲**不用李宗伟握法**怎么办。教练给了两种选择。

## 一、方案一（推荐）：引拍时"变拍"

> 教练原话："你在引拍的时候，可以引、让它转就可以了，这拍转点行了。"

具体做法有两种说法，本质一样：

- **靠手腕压转**："压你手腕的时候，这球拍会转，然后就这样子出来。"
- **靠手指放松转**："我就压这边手腕，我压的时候，小拇指这边放开一点，让它转一下就可以了。"

教练用正常握法和陶菲克握法都演示了一遍：

> 教练原话："正常握法架拍，我在引拍的时候，就压这边手腕，我压的时候小拇指这边放开一点，让它转一下。或者你可以刻意在引拍的时候转一下再劈，剩余的都一样。"

**这一步的关键是"边引拍边变拍"**——不露痕迹。

## 二、方案二：不转拍，直接硬切

如果不换拍，就按原来的握法（正常或陶菲克）硬切。教练描述了这套动作：

> 教练原话："还是能够劈出来，但是就没有什么隐蔽性。你的动作就是要往那边打，你会是这样：切你的肘会先上前……而且不可以太（大开），必须要往后，手腕一直保持往后，它就变成手腕保持往后这样切。你手腕不可以动得太多，就动那么一点点。"

- **手肘不能抬太高**——"太高的话你就会下网"。
- **手腕一直保持立着**。
- **必须是"从外面斜着切进来"**，动作最后像"往前提推"。
- 陶菲克握法还要"放在更中间"。

> 教练原话："（硬切）没有隐蔽性，但是还能够做出来。……而且你看我得提前转过来，要是不转过来，就很难做这个动作，如果是这样切就下网了。"

## 三、结论：最好还是"换拍"

教练最后的建议很干脆：

> 教练原话："所以最好就是：一，你直接换这种握法（李宗伟式）；二，你用陶菲克握法或正常握法，直接引拍换拍。同样直接换拍，你就可以大胆地切了。"

而"换拍"其实不用做得很刻意：

> 教练原话："当然这是为了给你们看，我架拍、我变拍成引拍。按理来说我们架拍、边引拍的时候就边变拍，就可以了，看不出来的。"

## 最后：这节总结

| 方案 | 做法 | 效果 |
| :--- | :--- | :--- |
| 方案一（推荐） | 引拍时压手腕 / 放松小指让拍转 | 有隐蔽性，可以大胆切 |
| 方案二（备选） | 不换拍，肘不高、腕立住、从外面斜切 | 能劈出来，但没隐蔽性 |
| 最佳解 | 直接改握法，或引拍时换拍 | "变拍融进引拍，看不出来的" |

| 要点 | 原话抓手 |
| :--- | :--- |
| 变拍靠手指放松 | "小拇指这边放开一点，让它转一下" |
| 边引拍边变拍 | "边引拍的时候就边变拍，看不出来的" |
| 硬切肘不能高 | "太高的话你就会下网" |
| 硬切要"从外面斜着切进来" | "动作最后类似于往前提推、带过来" |
| 硬切要提前转过来 | "要是不转过来，就下网了" |
