## 本节要点速览

### 一、握拍

| 要点 | 说明 |
|------|------|
| **食指的工作** | 往下推 + 往下压 + 扣住，**不是捏紧** |
| **握紧靠谁** | 靠**四个手指**（尤其小拇指），小拇指扣不住球拍就会动 |
| **拍柄靠哪** | 靠**手指第一节**；正常握法=斜棱、李宗伟=宽面、陶菲克=侧棱 |
| **为什么** | 拍柄靠手指（不是手掌），发力时有个"小肌肉"卡住 → 球拍锁死不动，力全送拍头 |
| **捏鸡蛋** | 握在掌心像捏鸡蛋中段使不上力；靠手指才能把力送出去 |
| **⚠️ 拳握法（诠释握法）** | 杀直线**绝不能换**；只有李宗伟/陶菲克握法、头顶球稍过你要往内打、球很靠外要突击时可以用 |

### 二、内旋与"肘朝外"的因果关系

| 要点 | 说明 |
|------|------|
| **为什么直着打发不了力** | 直着硬撑下来本身带切球 |
| **正确做法** | 食指前推下压 → **肘自然朝外** → 内旋摆正 |
| **⚠️ 误解** | 不是"肘先刻意朝外"（那是用小臂转），是食指压完肘才朝外 |
| **击球拍面** | 碰球时是**正的**，送力时才带一点斜；抬起来看是斜的 |

### 三、连贯动作

| 要点 | 说明 |
|------|------|
| **⚠️ 最大的错** | **左脚先落地再挥拍** |
| **正确** | 左脚尖碰地的瞬间 = 挥拍击球，**同时发生** |
| **连贯时左腿** | 膝只收一点点，左腿**不要过右腿**（过了必提前压腰） |
| **⚠️ 左脚先落地的后果** | 转身动作停了、重心转换卡住，只能靠手"抠"；重心突然停 → 右腿往外顶、站不稳 |
| **连贯时不能用分解的做法** | 不要把动作"做全"、不要顶到位置才出拍 |

### 四、顶住腰怎么发力

| 要点 | 说明 |
|------|------|
| **顺序** | 拉下来 → 一收（转）的时候就甩，右腿同时跳 |
| **腰什么时候压** | **右腿一碰地的时候**腰才下来 |
| **⚠️ 腰难受的原因** | ①转换没做足就甩；②做完了才甩；③左脚先落地。**不是"顶腰"本身的问题** |
| **为什么会压腰** | 累了。国际球员也压腰（桃田很少），**那是体能问题，别模仿** |
| **练习法** | 顶住腰只要顶一点点，一收就甩；做快时肉眼看像"一次过发生" |

### 五、头顶转不过来

| 要点 | 说明 |
|------|------|
| **两个方案** | ①启动时右肩往后快拉；②（更常见）其实是你**启动慢了** |
| **慢了的打法** | **半侧身**、像突击杀球但高一点，靠**手指**、动作做得很短 |
| **脚下** | 右腿往后、顶住腰、**能看到球就能打** |

---

## 一句话记住

**拍柄靠手指、小拇指扣住、食指只管推压；杀球绝不换拳握；连贯时左脚尖碰地=击球（别先落地）；顶腰是为了空间，顺着重心转换甩出去。**
