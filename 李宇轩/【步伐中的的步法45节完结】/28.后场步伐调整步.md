# 28. 后场步伐调整步

> 📺 步伐中的步法（45 节完结）· 第 28 节 · 约 25 分钟
> 教练：李宇轩

这一节讲一个非常实用的细节：**球挑得特别高的时候，怎么退。**

教练先抛出一个具体困境：

> 教练原话："关于如果你挡了网、搓了高点，你推头顶和推正手……**如果在这边搓球的话，这个人挑得很高了，我不会这么退的。**"
>
> 教练原话："你想一下，如果我这样挡网，他挑往这边挑，到这个点，你看我从一转身过，我就看不到球了。我一转身，球就是在这边了，我就找不到球了，**它一直在我的盲区。**"

## 一、三个不同场景，三种不同退法

| 场景 | 退法 |
| :--- | :--- |
| 球挑得极高，落到**头顶** | **后交叉**（因为转身就看不到球） |
| 球挑得极高，落到**正手** | **并步 + 小调整步**（等球下落） |
| 球挑得高又远，落到**底线** | **并步 + 后交叉**组合 |

> 教练原话："基本上别人挑得很高的时候呢，我们后续的时候，我们会用后交叉。比方说这样子：启动，我会找球，我才做一个确认步。"

> 教练原话："**如果是搓球，他挑得特别高，因为球一直在往上飞，你不知道它会在哪里降落。**"

## 二、正手：并步 + 小调整步

这是本节第一个核心动作。

> 教练原话："我们并到后场的时候，我们有一个**调整步**。"

### 什么时候用？

> 教练原话："通常都是我们去右边的时候，我们才会并步，然后做小调整步，再做确认步。"

**两种情况：**

> 教练原话："一就是你在接发的时候，他发得很高，你到位了，球还没有掉。"
>
> 教练原话："另外一种就是……如果你出一个很好球，他挑得很高，但是他挑个半场球。"

### 为什么要调整步？

> 教练原话："我退一步，他一挑，我不知道他会挑哪里，但是我（先）退。我要退，我要这样看找球。"
>
> 教练原话："我一到球（附近）的时候，球头还没有往下掉，还在往上飞，但是它到这边，'啪'它就不再往上后飞了，它从这边要开始往下掉了。**但是我到位的时候呢，球还没有掉。**"

**这时候不能直接打：**

> 教练原话："因为我不可以这样子吗？我不可以加速然后（打）……不可以啊，你看我站不稳啊。对不对？你看我打完球后，我不可以（倒着）这样子啊。"

### 动作：本来是做确认步，改成"右-左"

> 教练原话："平时我是搓了做一个启动，然后我转，我推开，我站这腿，我就直接推开做一个确认步——平时我们就这个样子，并、确认步。"

> 教练原话："**现在因为球太高，我不做确认步。** 球还在空中、还没掉下来，我会……他回来，再踏回来，才做确认步。"

用重心概念说清楚：

> 教练原话："就是我本来从左腿应该要做个确认步，我发现到球还没掉下来，我就（换）——**再往回，再做确认步。就是把重心从左腿（要落脚的地方）换去右腿，再挪回来，然后才做确认步。**"

> 教练原话："我（右腿）挪回来的时候呢，正好球开始往下掉了，那个时候我就可以做我的确认步了。"

口令：

> 教练原话："并，右、左，再做（确认步）。"
>
> 教练原话："平时我们是：并，左、右打（直接确认步）。"

### ⚠️ 为什么球不会往后飞

教练解释了物理原因：

> 教练原话："为什么这球不会往后飞？**因为你出了球、球很贴网，他一定要往上挑。** 他往前这样挑的话，他凭（平着）这样挑的话，球就打完了不会过。"

> 教练原话："他往上挑的时候，这个球只会往上飞，到了一个距离它就开始往下掉了。"

### ⚠️ 两个前提条件

> 教练原话："很多人可能会做这个小调整步，但是他们后面还是达不到，因为有两个原因。"

**1. 时机**：

> 教练原话："**只有你到了位，球没有再往后飞了，但球头还没有掉、球还在往上飞，可以。** 如果你到位了，球还是往下掉，你就没有时间了。"

**2. 必须把重心换掉**：

> 教练原话："更重要的是什么？他们做这个小叠步，**他们不知道怎么去把重心挪这边，然后换去一个确认步。这个永远都是一定要做的。**"
>
> 教练原话："你打球一定（要）有（这个），一定要有的。不管是球很远，你要做大一点，还是球很近，你（小）抬也行，不一定抬腿也行，也可以，就把重心挪下来、压下来就可以了。**一定要做到。**"

**⚠️ 动作幅度**：

> 教练原话："你要注意啊，当我们在做这个小调整步时呢，**没有做得那么慢的，没有人这样做的。**"

## 三、头顶：后交叉

> 教练原话："**这个永远都是去正手的时候才会发生**（指调整步）。那如果球在正中间或头顶，我们会怎么做？"

困境是：

> 教练原话："我站这边的时候，他一挑球立马已经过我了——一定的。因为我站（网前）离（网）那么近，你看比方说这是往前，我出了球，我一启动它一挑，这个距离太短，它一挑就过了，它就已经在后面了。"
>
> 教练原话："所以如果球在我左边的话，我去转身的话，那**这球打不了了**。"

所以：

> 教练原话："**我们去头顶，我们就不可以（转身），我们就得后跑。**"

### 正确的头顶退法

> 教练原话："我挡网，他一挑就在边，我就要这样子**后跑**，去到球这边，我就做一个侧身。"
>
> 教练原话："球在我一边呢，我就可以打了——打直线、打对角都行。"

### ⚠️ 眼睛要一直看着球

> 教练原话："他挑这边我就会（跑）……我的眼睛会找球嘛。**我一定要一直看着球。**"
>
> 教练原话："如果一没看出（球）了……（不行）。"

### 到位后的处理

> 教练原话："我到了球底下，我后跑的时候，我发现到球到了、开始要掉了，那时候我就（停）……踏去我左腿，然后做这个确认步。"

### 分寸感

> 教练原话："如果不转身的话呢，我挡网我启动，我挡网我向下跳，我就（跑）。他一挑，我的眼睛会找球。"

> 教练原话："**如果调得很高，我到位了，球还没有掉，我就可以这样子用（调整步）；或者是我到位了，我已经到位了，我就可以这样子的，再做一个确认步；如果我到位了，球直接掉了，就直接做一个确认步就可以了。**"

### 为什么国手去头顶像在用后交叉

> 教练原话："你会看为什么国际球员，你会说哎为什么我发现他们去头顶好像在做后交叉？**就是这个原因。**"

> 教练原话："头顶只要呢，我们启动时候，我站前面，他是起球——不是（平球）啊。他平球的话，我们一定一就是用反拍，就是我启动，我直接转，我就直接打，因为球（快）掉了。**但如果球很高的话，基本上（是）往前挑球啊之类的，基本上我们都会将退（后交叉）。**"

## 四、还是可以用并步的情况（别误会）

> 教练原话："我没有说这个（转身并步）不行啊。**只要你是搓了球、你启动，它调时候，它没有直接调去（边线），它调还是往这样子上，你还可以看到球，可以啊。**"

## 五、从前场退到底线：并步 + 后交叉

> 教练原话："在实战当中呢，我们可能还会遇到一个问题……**但是就是如果你（挡网）他挑不是很（半场），（球）挺高啊，到底线，我们怎么退？**"

不能这样：

> 教练原话："我们不可能这样子吗？对吧？太多步了，怎么做？"

**答案：边并步边后交叉**

> 教练原话："我们会……我打完这球，他挑，挺快的一个球，我还是并。"
>
> 教练原话："**并到这边的时候呢，我不会这样子（正着）并，我会是（斜着）这样子。你看我在并的时候，它一直在往这边去，看到没？我是（侧着），算是侧着后交叉。**"

### 组合方式

> 教练原话："你可以先转身并一步，再做这个后交叉。转身，并一步，再做这个后交叉，再做确认步——**这个是往往我们从前场退到底线这边会做的。**"

> 教练原话："打完第一步，我们会转身，先并一步，然后下一步就是一个后交叉，然后做确认步。"

### 为什么不能一直并步

> 教练原话："**如果我只是一直做并（步）的话呢，我可能很难跑到这个点。** 如果冲对角的话，我可能会跑到这个点比较合理；但如果球在这边呢，我还是找不到。"

> 教练原话："他越靠外，我这样（正着）一次并，你看我的身体，**我是朝这边的**。如果我不会用这个方法（后交叉），但是如果不做后交叉，我用并步，我就会是这样子……那我转多点，我就会这个情况：**我已经对这边了，我真的打不了了。**"

> 教练原话："**所以我们为什么挡了网、别人调得很高，我们去找球，我们会用后交叉，就是这个原因。**"

### 看球的高度决定节奏

> 教练原话："**如果是球很高的话，你可以多（并）几（步），因为那个也算是调整步嘛。但（如果是）这球你到了、球差不多掉了，你就立马一转身的时候（就做后交叉）。**"
>
> 教练原话："如果这球我挡的比较远，他一挑就挑到底线了，我就会（转身）在后交叉。"
>
> 教练原话："诶，因为球很高，我到了，我就有一个（停），再（做）确认步。"

### 简化版

> 教练原话："或者是这个球它不是挑得很高，你差不多到这边你就要做一个确认步了，那怎么办？**我们打完转的时候，我们在并这一步的时候，我们就可以做这个后交叉，直接做一个确认步。** 我们就不用说并一步再做这一个才做——我们是直接转就直接后交叉了。"

## 六、怎么练

> 教练原话："因为我们是站中间……我们是这么挡网，我们先练这边的：挡网、启动、然后并、确认步、打就可以了。"

> 教练原话："小步的动的时候呢，如果球在这边的话，你也是可以这样子的：（并）往前，'咚'，再（做确认步）。"

> 教练原话："**只要球没有再往后飞了，球（飞）到一半，它还在往后飞，球还没有掉下来，你就可以这么做。**"

> 教练原话："你（可）做 20 个吧，随便你。主要还是为了要练这个动作而已。"

头顶版：

> 教练原话："头顶一样的，启动，记得头（要抬）这样看啊，然后你一直这样子看着球。退，然后做确认步，抬左手，就可以了。"

### 结合已有的训练

> 教练原话："这个（后交叉）方法你要怎么练呢？平时你可以用在我们刚才练的那个——掉直线上直线然后推对角。然后掉完上（直线）时再推（对角），你可以这么做。"

> 教练原话："并一步，我转，我就做一个后交叉就可以了。"

> 教练原话："**你们就是一直这样子，不由（自主）习惯了，打比赛的时候根据球（的高度），肯定做得出来的。**"

## 最后：这节总结

| 场景 | 退法 | 何时做确认步 |
| :--- | :--- | :--- |
| 正手 · 球极高还没掉 | 并步 + **右-左小调整步** | 球头开始往下掉时 |
| 头顶 · 球极高 | **后交叉**（保持能看到球） | 到位 + 球要掉时 |
| 前场 → 底线（又高又远） | **并步 + 后交叉**（斜着并） | 到位后 |
| 球快到、高度一般 | 直接转身 + 后交叉 + 确认步 | 立刻 |
| 正手 · 准备双腿跳杀 | 可以后交叉 | — |

| 要点 | 原话抓手 |
| :--- | :--- |
| 转身看不到球 → 别转身，用后交叉 | "它一直在我的盲区" |
| 正手球太高 → 右-左调整步 | "右、左，再做确认步" |
| 调整步的灵魂是把重心换掉 | "不管球很远还是很近，一定要做到" |
| 调整步幅度不能慢 | "没有做得那么慢的，没有人这样做的" |
| 球为什么不会往后飞 | "你出了球、球很贴网，他一定要往上挑" |
| 眼睛要一直看着球 | "我一定要一直看着球" |
| 越靠外越要用后交叉 | "我已经对这边了，我真的打不了了" |
