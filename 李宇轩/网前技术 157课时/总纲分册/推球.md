# 推球（正手/反手 × 对角/直线）

## 一句话定位
网前平快进攻技术：抬拍像搓球保持隐蔽，出其不意平推两角底线，核心卖点是"抬上来好像一个搓球……然后推" [123]，正手推对角先学（更简单），直线靠位置和转腰变出来 [124][129]。

## 核心要点
1. **先从大动作学**：一上来学小动作"百分百接不上力"，从大动作学会借力，再缩到快、短、小 [124][126]。
2. **正手动作链**：往右前 45 度打开 → 翻小臂倒手腕（像搓球）→ 肘先进来带小臂舒展、"像切菜/扇巴掌往左切不是往前送" → 到胸前/右肩前仍保持倒手腕 → "边推边翻小臂"，推完继续送再稍微抓紧 [124]。
3. **隐蔽性的物理秘密**：拍和球之间留一段前后距离（到拍柄位置），不放球正下方——"球拍跟球有这个距离，在前面是看不到的"，既骗人又接得上力 [125][126]。
4. **一致性要早卖**：启动/并第一步就打开抬拍摆平，"早点打开，并的时候打开产生足够空间"，到最后一秒才抬就骗不了人 [127][125][128]。
5. **击球点与高度**：击球点在胸口正前方（身体正中间），太靠外"百分百去不了对角" [125]；最佳高度胸口（肚子到肩），太低变挑球、太高变扑球 [126][128]。球低就压低重心往下再往上推 [128][135]。
6. **跑得越快动作越小**：跑动自带速度，借力即可，"不要去推那么多"——这条也是防出界的钥匙 [124][131]。
7. **反手推球三关键**：①握法=拇指压在斜棱和宽面之间的棱上，"一定要有空间"握死就转不过来 [132]；②最佳高度在眼睛（比正手高），像"开摩托车"绕腕只绕 45 度 [132]；③"不是绕完再推，是边推边绕"，推完顺势往下压，最后内旋收拍防网球肘 [132][133][135]。
8. **碰到球那一下才抓紧**，之前手指放松，"就稍微抓下，只要球拍不会飞走就 OK" [127][132]。

## 常见错误与避坑
- 像扑球抬到头顶推、或大动作直接推——前者只有高球能用，后者"没有隐蔽性，谁不知道你要推" [123]。
- 摆平了但放球正下方——僵硬没速度接不上力；正解是往外放留前后距离 [123][125]。
- **推球总出界** [131]：因为跑起来有速度。解法=照跑但动作做小、少推一点；球慢可靠近打大动作，球快"离球远一点、转快一点、早一点抓紧，把动作做短"——本质是"对上球的速度"。
- 反手固定大臂平甩——"很容易得网球肘"，再使劲也只能去中路；正解是边推边绕+推完内旋 [132][134]。
- 球太贴网还硬推——"一推必下网，只能往上打"；太低改挑球 [130][138]。等球到了才抬手也不行，要提前"卖这个点" [125][134]。

## 对角推 vs 直线推
| | 推对角 | 推直线 |
| --- | --- | --- |
| 脚往哪并 | 往外并、可过球，人往外压 [127][134][135] | **往前并**，右脚跟球一条线 [129][136][137] |
| 身体角度 | 约 45 度 | 接近 90 度（转腰）[129] |
| 球的位置 | 身体正前方、留前后距离 | **身体旁边**："让球过我（的腿），再推" [130] |
| 手腕 | 往后倒 | 更要往后倒 [129] |
| 击球点 | 胸口正前正中间 [125] | 胸口旁边，别在正前（"球在拍前面必去中间"）[129][130] |
| 手上动作 | 打开-往前-翻，完全一样，只是位置/角度调整 [129][136] | 同左；熟练后可不转腰增强隐蔽 [137] |
| 反手差异 | 人往外压、重心在后腿 [134][135] | 转腰把球放旁边，球过我太多就变对角了 [136] |

## 训练方法
- 搭档从下往上抛慢球（千万别从上往下砸），拇指食指捏球两侧、球不转；落点在网和白线中间（直线练球到接近白线 2/3 处）[125][130][133]。
- 对镜分解大动作，练熟逐步减小；练动作时"不用加速，不用发力"——发力是过程不是抓一个点 [126][139]。
- 先练对角再练直线；先原地点定，再带上步伐，推和落地同时把力传出去 [124][139]。
- 进阶喂球：慢球→向下扔重球，练习离球远一点、动作做短 [131]。
- 带步伐节奏：启动即打开抬拍 → 并步 → 脚后跟边塌边前压 → 落地同时推；左手打开后顶（推球不用顶像挑球那么多）[127][134][135]。

## 子技能难度×收益评级
| 子技能 | 难度 | 收益 | 理由 |
| --- | --- | --- | --- |
| 正手推对角（打开-翻-切） | 中 | 高 | 教练说比直线简单，"怎么使劲都不会出去"[124] |
| 拍球距离感（前后空间隐蔽） | 中 | 高 | 隐蔽性和接上力的共同根源，一次练对两处受益 [125][126] |
| 一致性/提前抬拍 | 中 | 高 | 让推、搓、勾共用一套假动作，双打价值极大 [127][128] |
| 正手推直线（转腰+球放旁边） | 高 | 高 | 最易推去中间，练会直接多一路进攻 [129][130] |
| 反手推对角（绕腕45度边推边绕） | 高 | 高 | 反手位主要反击手段，但动作细节多易网球肘 [132][133] |
| 跑动借力与动作大小调整（防出界） | 中 | 高 | 解决"一推就出界"的通病，通用到其他技术 [131] |
| 反手推直线 | 高 | 中 | 靠角度变线，熟练后收益好但使用频率低于对角 [136][137] |
| 追身球换握推（苍蝇拍/拇指顶宽面） | 中 | 中 | 特殊场景专用技，会了就不怕杀上网贴身球 [138] |
