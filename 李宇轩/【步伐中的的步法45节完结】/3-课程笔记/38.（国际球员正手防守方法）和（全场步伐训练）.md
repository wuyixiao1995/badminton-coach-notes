# 38. 国际球员的正手防守方法 + 全场步伐训练

> 📺 【步伐中的的步法45节完结】 · 第 38 节 · 约 17 分钟
> 教练：李宇轩

这一节讲两件事：一个是那个"看起来很帅但你学不会"的国际球员正手防守（大跨步拖腿），一个是全场步伐怎么练。

## 一、那个"跳出去"的动作，到底是怎么来的

教练先说了现象：你经常看国际球员、专业球员防守，他们打开、伸手打球，打完之后好像**拖着腿一样跳出去**。

> 教练原话："很多人觉得是因为跳出去，所以很多人做了一个很奇怪的动作。"

教练让大家先停下来自己试一次，录下来看——你会发现大多数人做出来就是那种"很奇怪的动作"。学不会的原因只有一个：**不知道重心是怎么调的**。

### 先纠正一个误解：那不是"抬手"

有人看李宗伟防守，觉得他有一个"手往上抬"的动作。教练解释：

> 教练原话："其实没有你们想象中的那样，他还是有推手指的。只不过他推的方法他不是竖的上来，他是拍面有点斜，食指带上来的时候把手腕带上来，这个感觉。"

因为球下来得很快，你在下面等球，一带上来拍面自然会翻——**那只是一个连贯动作而已**。

## 二、为什么要开大：为了够到边线

先说站姿。教练说，如果你起了球，你**一定会开那么大**：

> 教练原话："你看我发了球，他（对方）跳起来准备杀，我一定会开那么大。因为要是如果他吊球，我可以……这边我就可以去调了；那如果他打这边，我一定要开那么大，我才可以（并）才可以去。"

但开大有开大的讲究：

- **反手没问题**：开大一点也没事，正好往下坐、用脚后跟蹬转
- **正手就有问题**：开太大，你**做不了那个推**（没有空间）

> 教练原话："我开太大，你看，就推不了了，明白吗？"

而且开大有个底线：

> 教练原话："只要我不是开到没办法用脚尖（前脚掌）……我开大蹲下去（可以），但是我开大到只能用脚后跟，那就不好。"

教练补充：看国际球员防守，他们每次都开大一点——因为**你开得越大，覆盖范围越大**，但前提是你还能用前脚掌。

## 三、正确做法：先伸手，重心自然压下去

> 教练原话："我会先伸手，一伸手的时候，你会从重心从中间——你一伸手的时候，你整个人会挪过来。"

链条是这样的：

1. 启动 → 打开往下压
2. **手先伸出去**（我会提前到，因为要够球）
3. 人往那边挪，重心自然压下来 → **好像原地做了一个弓步**
4. 碰到球
5. 这时你已经站不稳了 → **拖左腿、跳一下，把重心挪回来**

教练特别强调弓步的标准：**膝盖不会超过脚尖**。

### 两种常见错误

教练说他教过的球员——包括专业的——刚学这个动作时，几乎每个人都做错，就两种错法：

**错误 1：跳完落地才打**

> 教练原话："他是跳完落地才打，他不是先打。他是跳完（再）打。这就完完全全错了。"

**错误 2：碰完球人不回来**

打完人还留在右边，重心锁死在右腿上。

> 教练原话："我碰完后呢，我说你会往（前）挪回来……我不会是（一直留在）这样子。"

正确是：**碰完后往内拖回来**——伸手出去的时候身体一定会往那边去，打完就要把它拉回来。

至于球的远近：球不远、你能一直朝前，那很好；但一般来说，因为你要伸那么远，身体一定会跟过去，所以打完后必须拉回来。所以**左手往后顶**这件事，还是那句话——不顶就站不稳。

## 四、居家专项训练：拉杆

教练给了一个很有针对性的训练，专门解决"重心挪不回来"：

> 教练原话："太多人，我教了……就算是打的很好的那种、专业队的，他们刚开始学这动作的时候，他们一直学不好，他们到最后每一个就算打的再好，他们都会这样子的（挪不回来）。"

**怎么做**（用球包带/弹力带，或者一根固定的杆，再加一颗球当目标）：

1. 启动
2. 右手伸出去，握住杆/带（想象握住球）
3. **一拉**——同时把左腿拖过来
4. 拖的同时继续拉，拉到最后，**跳一下**（跳过杆或跳到杆前面）
5. 跳的时候身体转过来，落地

> 教练原话："由于我在往这边拉，我的身体就会被拉来这边……这就帮助你把身体挪回来的。"

**三个细节**：

- 拉的时候腿要**放开**，不要绷着——一拉这个就赶紧松开、收进来
- 跳的时候，结束尽量是**往外**跳（不要留在原地）
- 训练时人会往那边多一点点，无所谓；实战中不用那么夸张

## 五、带上脚看一遍完整动作

教练最后从后面演示：打开 → 往下压 → 伸手 → 握住一拉 → 腿放开、一直往下、收回来、跳。

> 教练原话："一伸手，你（要）碰到的时候，其实就开始在拖我左腿了……基本上我要碰到球的时候，我就开始拖了。"

所以节奏是：**伸手 → 快碰到球就开始拖腿 → 碰到 → 拖 → 跳 → 并开回来**。

教练说的核心概念只有一个：**转换重心**。

> 教练原话："打完了转重心很重要，学会这个，你们就可以做（出来）了。"

## 六、全场步伐训练：三种练法

前面网前、中场、后场、防守都讲完了，所以全场步伐其实不用再单独讲——教练直接给了一套更有针对性的练法。

### 练法 1：按"你要去哪里"选启动（不平行、不前后）

> 教练原话："我会直接这样子去……我要去这边，我就会做一个平行（方向）的启动。"

具体说：

- 要去哪边，就用朝那边方向的启动
- 打完手上的球随意（推也行），因为你在练**脚下**
- **目的有两个**：①让你习惯跑不同方向；②这其实是**主动步伐**

什么叫主动步伐：

> 教练原话："比方说我打完一个球打回来，按理来说我应该是平行启动，对不对？但是刚好我看到他打我的正手了……我回来，我看到、我觉得他打我这，懂吗？"

也就是：你**预判到了**，就可以提前用朝那个方向的启动。

> 教练原话："每一次我们要去，比方说我要去这边，我就会先（做）怎么样的启动……你们就按照这个方法去跑，然后手上动作你要做对就行了。"

### 练法 2：平行启动 / 前后启动

- **平行**：所有球都是起球（对方杀），发球 → 回中间平行站 → 防守 → 起球 → 回中间平行站……就这么敲
- **前后**：所有球都是**往下打**的——杀上网、吊上网、过渡上网。因为不会有人吊完球再平行启动

### 练法 3：带上脑子的混合练习

这一层要带上**思想**：

> 教练原话："你要大概幻想：哦，我打什么球，我会怎么站……你也要大概想一下对方打什么球。"

因为**你打什么球，决定你用什么步伐**（朝这边还是朝那边）。

教练给了一串连贯套路当例子（自己念出来）：

> 发短 → 跳直线 → 过渡直线 → 站好 → 反拍 → 站好 → 挑直线 → 回来防守 → 防大斜 → 好推 → 勾挑对角 → 回来防守 → 防直线 → 吊球搓挑 → 挡网跳 → 防守 → 杀对角

> 教练原话："你们就带着这个球路去练就可以了。"

**总结下来三种练法**：

1. 提前做方向启动（去这边就用这边的启动），3 组 × 20 个
2. 全平行启动（全起球），3 组 × 20 个
3. 前后启动（全往下打：杀上网、吊上网、过渡上网），3 组 × 20 个
4. 混合练习：平行、前后都有，看球路选，但要带脑子

## 七、关于鱼跃

教练最后说：鱼跃他决定晚点再教。

> 教练原话："我很怕我教了，有些人就直接上来（用）。你们基本还没做好，你们去（用）鱼跃，我怕你们受伤。"

意思很明确：**基础没打好，别急着学鱼跃**。
