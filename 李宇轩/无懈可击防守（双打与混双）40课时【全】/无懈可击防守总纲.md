# 无懈可击防守总纲（双打与混双 · 40课时）

> **一句话定位**：李宇轩教练的双打防守体系课——从反手握拍、四步挥拍、击球点理论，到转换重心、步子启动、双数区/单数区各技术，最后落到"挡网反攻"与主动抽球，核心主张是"防守不是挨打，挡网就是反攻的开始"。

## 核心要点

1. **握拍是防守的地基**：拇指顶在拍柄宽面上，防守时握拍要"往中间、往上握"，缩短力臂、加快出手；球快或贴身就再往前握一点 [第2节]（正手抽球同规则："主要是看球来的速度……往前握一点，就跟那防守是一模一样的道理" [39]）。
2. **四步挥拍动作**：降拍 → 翻小臂 + 倒手腕 + 绕肘 → 舒展蓄力 → 拇指推。反手发力靠拇指顶推，不是甩大臂 [第3-5节]。
3. **五个击球点理论**：以人（身体）为标准分五个点，**第3点（胃到胸口）是起底线球的最佳击球点**；不同技术用不同击球点，这是全课的理论主轴 [第6-9节]。
4. **三大技术一句话区分**："起底线球看击球点（第3点）、平抽看结束点、挡网看击球点（肩到肚子之间）" [第6-8、10节]。
5. **转换重心（挪重心）**：重心从左挪到右再发力，左手往后顶/拉是关键；打底线、抽球各有专门的发力转换方法 [第12-14节]（反手主动抽球同理："左手往后拉"如拉弓，迈右腿往后躺，落地与出拍同一刹那 [36-37]）。
6. **防守启动**：双打防守启动是原地挪重心，重心不能留在中间，左脚先落地蹬出 [第20节]。
7. **挡网是双打防守第一选择**：肩到肚子之间的球优先挡网，是反攻最好用的技术 [第18、28-29节]。
8. **"谁挡网谁先上"**：挡网质量好就跟进上网，形成杀、挡、上的反攻套路 [第28-29、33节]。
9. **对角线球的秘密在左手**：打对角底线不是转腰，而是拉左手顶住肩胛骨，用身体结构产生方向 [第25-26节]。
10. **双数区与单数区站法不同**：接杀站位、出球线路随左右区调整，各有独特技术（双数区抽球、挡网对角等）[第24-30节]。
11. **主动抽球三要素**：重心后留（拉弓产生空间）、憋住靠腿不靠手（"你们是靠手，我们是憋住、靠腿" [38]）、抬手要早（"稍微慢一点抬手，球接近我才抬手，再见了" [38]）。
12. **正手抽球要点**：转右45度、肘永远不能走到身体后面（"他不可能是在后面" ×2 [39]）、"舒展快要完的时候才推"，先推出去再抓紧 [第39-40节]；启动先抬拍再并步，左手往后顶让重心留在左边 [40]。

## 常见错误与避坑

| 错误 | 教练怎么说 | 出处 |
| :--- | :--- | :--- |
| 提前抓紧、不推完手腕 | "你们是出去抓紧，我们是进来倒手腕，然后一推" | [39] |
| 翻拍太夸张 | "翻拍翻得多，这个球会飘的……还没来得及摆正就已经击球了" | [39-40] |
| 重心提前压下去 | "我要懂得收住我重心，不可以提前压，要不然力量传不出去" | [38、40] |
| 肘走到身体后面 | "他不可能是在后面。他不可能是在后面" | [39] |
| 启动直接扑、不抬拍 | "我不是一上来直接往前压重心，那个没有空间" | [38、40] |
| 动作丑/僵 | "为什么动作那么丑、那么僵？就是因为动作不对" | [40] |

## 训练方法

- **定点带球**：先分解后连贯，一人喂球练单一技术 [第11节]。
- **绳子辅助**：用绳子限定挥拍轨迹和击球点位置 [第9、14节]。
- **搭档扔球法**（主动抽球）：扔在左前方"刚刚好"的位置——"不要扔得太紧……或者太远"；先憋住分解，再连贯；脚踝绷住落地不重 [第38节]。
- **步子混合练**：移动中打不同技术，底线/抽球/挡网混合 [第15-19、22-23节]。
- **反攻套路**：杀、挡、上——"谁挡网谁先上" [第33节]；对抽 + 不同防守球套路 [第34节]。
- **抽墙 + 家里训练**：无场地也能巩固挥拍和转换重心 [第35节]。
- **完整训练计划**：31-32节给出按周组织的巩固计划；38节是主动抽球的扔球训练计划。
