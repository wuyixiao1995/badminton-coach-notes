# 19.头顶滑板吊对角1

> 📺 致命吊球 · 第 19 节 · 约 8 分钟
> 教练：李宇轩

从这一节开始换新的技术——头顶滑板吊对角。前面正手劈吊对角、头顶劈吊直线都已经知道了怎么掉、怎么切、怎么调整，现在轮到头顶这条边的对角球。开场教练先把道理讲透：这个球为什么不能用碰的，也不能用"往那边切"的方式来切。

## 一、为什么不能用碰球

头顶吊对角，教练一句话定性：**它不是靠碰的，是靠切的**。碰球有四个问题，他一条条数出来：

1. 球很慢。
2. 球很高。
3. 要它快一点，球就很远，要不就出界。
4. 最重要的一点——没有隐蔽性。别人都知道你要打这边，提前往那边跑，"那你就类似于是准备输这一分了"。

## 二、也不能用常规那种切法

那切球怎么切？先用正手劈吊对角那套切法行不行？教练说不行：那样切球会去那边（对角线），如果你改成"往那边切"，你的手又很明显地往那边去，对手一样看得出来你要打那边。

所以也不是这么写、这么切——"这样肯定下网"。

## 三、头顶滑板的切法：拍面翻过来切

正解是**拍面翻过来切**，方向跟常规切球是反的。这个动作细节很多，跟其他技术一样，握拍、击球点、腰，每个环节都有要调整的地方。

## 四、先看一眼反面教材，知道会掉出什么球

教练说得很直接："你们一定调不出来。" 然后他把大家最容易掉出来的球一个一个示范给你看，让你知道错在哪里：

- **第一个，也是最常见的：下网，而且下得很夸张。** "他会很夸张的下网。"
- **第二个：怕下网就往后仰一点、手不那么夸张，结果球去中间。** 再收一点，还是去中线。
- **第三个：想着"我压紧手腕"让它过去，结果变成了打。** "它就变成一个大仔（打）了"——本来要切，变成了硬打。
- **第四个：切得太薄。** 跳起来切得很薄，还是下网。
- **还有更离谱的：只想着切，忘了动作结构，变成"招财猫"那样打。** 教练说这种动作已经没有隐蔽性了，不再像要打高远球的动作，"全部错了"。

一句总结这些错球的共同原因：**切球点不对**，或者切得太薄。

## 最后：这节总结

| 要点 | 原话抓手 |
| :--- | :--- |
| 头顶吊对角靠切不靠碰 | "它不是靠碰的，它是靠切" |
| 碰球没有隐蔽性 | "别人都知道你要打这边，他提前往那边跑" |
| 不能用常规那套切法 | "如果你是往那边切的话，也是很明显让你的手往那边去" |
| 正解是拍面翻过来切 | "他的切法是，牌面会这样子翻过来切" |
| 最常见的错球是夸张下网 | "他会很夸张的下网" |
| 怕下网往后仰→去中间；压手腕→变打 | "它就变成一个大（打）了" |
| 错球根因：切球点不对、切太薄 | "为什么去中间，就是因为你切球的点不对" |
