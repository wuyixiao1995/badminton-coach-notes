# 反手扑贴网球（抹球）-握法调整&步伐

给你们看到，我们现在用拇指顶在宽面这种握法，我一这样打，看到吗？我们一推，我就碰到外面了，我一定会碰外面。那我这样，我要它这样子，很简单，我把这拍往这边转。当然我手腕是往后立着，立着，往后立着往这边转，这样子。也就是说本来是这样子握拍，拇指顶在宽面，现在我会往这边转点，所以变成你的拇指握在斜棱。本来是正宽面，我会往这边转点，拇指会握在这个斜的，但是这边还是一样，这边还是靠外面，本来是这样子，在我一转的时候还是靠在外面，还是靠在这个线这边，一样的方法转，这样子握拍就行了。

现在你一往后立的时候，你会看，你往后立的时候，拍面本来是比较平的，现在如果你改了握法，你往后立的时候，拍面会更加往后，然后有点斜的，我可以就这样子。然后你这样子保持往后——看，保持往后立的情况下，你往正前去，你看到吗？你就会先碰到球了。可以了。

当然像我说的，我们在做扑球反手的时候，尤其是反手，我们不一样（要）正对着对手，这样子就算你并步的时候还是会碰到网。你侧在外面就不用想了，一啪就是了。

所以改握法是这样子：从这样子往这边、左边这边转，就是你的拍，你在抬上来的时候在你左耳这边呢，你往这边转也行了。改成这样，你往后立的时候它就有点斜了。然后其他的动作都是一样的就可以了。

## 不用转那么多

但是我要跟你们说，如果你把球放外面的时候呢，你本身就已经很稳的了，所以你不用握得那么宽的，你不用把它正面稍微往这边挪一点点也够了，你不用挪那么多，也是不用挪到侧棱，从这边稍微挪这边就 OK 了，一点点就好了，就足够了。然后这边要保持一个空间。

我再示范一下给你看：本来是这样子握拍，我一推，还是会碰到。现在握拍转一下，进，这些没有碰网。当然我做快一点的话，舒展一点，再快一点的话，抬上来快一点。手腕尽量往后倒得越多越好，你别推那么多，你尽量少点推，一推点就往上抹就行了。因为我手臂还在上去的话，你一有摩擦到它就有速度了。

手指要放松，不要握紧，你越握紧，你这个就越容易卡住，你就很容易打网的。你握得越紧越容易打网，放松，越松越好。拍拍放松，改一下握法，球放外面，侧（身），（重心）放低，做就可以了。

从另外角度看一下：转，往这边转一点点，手腕往后立着越多越好，放外面，抬上来往后立，抬上来，感觉好像是这样子的。看来你们从这个角度还是这样子，好像是这样子摩擦上去，好像是这样子刷上去的就可以了，有这个感觉。

所以只要你拍面不是正、不是这样平，稍微斜一点点，往上抹上就行，抬、抬、放松。再来，改一下握法，改一下握法就可以了，这样子抹。

## 抬高拍，一碰球就拉回来

抬着，他扔这个手臂上来，抹上来，切球，往上切就可以了。

你要是如果前面感觉要一直打网，可以夸张点这边，转多点，再转多点无所谓，太夸张也无所谓。但是手指也要放松，你越放松你的手腕越灵活，它就（越顺）。

我拍挪一下，抬上来就可以了。我拍挪一下，抬上来，接近球，抬那么高，抹就可以了，看到吗？你抬那么高抹不用怕，一碰到球就赶紧往上拉回来就 OK 了。那就有几个（球），抬那么高，先赶紧拉，看到吗？走的时候抬高一点，但你别放那么低。改握法，抬拍，接近球，改握法，放外面，抬拍，抬那么高，拉手腕，接近球，抹。特别特别直接。所以你会看到关键点在：抬拍要抬高。

当然如果你抬得很高，它可能会有点平，无所谓的。你这样改一下步伐，这样抹就行了。

## 带上步伐

那现在我们就带上步伐，跟那边一样。我们会有两种，一个是这样子：抬，重心往后，我一往前一踢，我就要有这个（动作）去发力。我不可以（等）到（落）地。抬上来，我一往前一踢，我就舒展。我跟你说我是打完脚再落地，我不是（先落地）。我是抬上来，一抹，再落地。所以如果是这种步伐一定是这样子。

所以启动，并步来，抬那么高往后，抬拍，现在我一往前，左腿一发力，右腿一往前踢，我就伸出去。

只要你把球放稍微左边一点，稍微侧着一点，然后拍手就抬那么高，几乎都很稳的。

很多人会打网，就是差不多这边高，但是不是很高，他们就即便（改）了拍，他们都会碰到网，就是因为本来做对了，但是因为你要收拍的时候，又老是碰到网，抬高一点就可以了。你只要抬高整个手，不是拍抬高而是整个手也放（高），整个手抬高点，很稳的。一往前一踢，就是左腿一发力就可以了。
