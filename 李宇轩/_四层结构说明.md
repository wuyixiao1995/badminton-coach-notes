# 李宇轩系列四层结构说明

每门课目录下有四个子目录，一层套一层，越往上越精炼。

```
李宇轩/<课程名>/
├── 1-原始转录/     ← 语音识别直出文本
├── 2-整理稿/       ← 校正后的全文本
├── 3-课程笔记/     ← 按节课整理的结构化笔记
├── 4-总纲/         ← 全课核心要点提炼
├── _v1_backup/     ← 旧版笔记归档
└── _reorg/         ← 改组过程工单（可忽略）
```

## 各层定义

### 1-原始转录

语音识别直出的原始文本，有错字、无结构，作为可追溯底稿保存，一般不直接读。

### 2-整理稿

在原始转录基础上校正错字（如"不乏"→"步伐"、"切磋球"→"切搓球"）、去掉口癖、顺句分段后的全文本，**忠实原意不缩写**。想看教练原话细节读这层。

### 3-课程笔记

按每节课做的整理笔记（含 `_时间轴概要`），结构化、带要点，日常复习读这层。

### 4-总纲

每门课/每项技术的核心要点提炼 + 难度×收益矩阵，先看这层再决定练什么。

## 用法三句话

1. 想练什么 → 先看 `4-总纲`，用难度×收益矩阵挑优先级。
2. 要复习某节课 → 读 `3-课程笔记`，要定位到第几分钟就查 `_时间轴概要`。
3. 笔记跟记忆对不上 → 往下翻 `2-整理稿` 看教练原话，还不确定再翻 `1-原始转录` 核对。

## 备注

- `_v1_backup` 是更早版本的笔记归档，保留不删。
- `_reorg` 是四层结构改组过程中的工单记录，可以忽略。
