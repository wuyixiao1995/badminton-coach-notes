# 双打前三拍总纲（聚合自本课程全部课节笔记）

## 一句话定位
双打前三拍 = 第一拍发球 + 第二拍接发 + 第三拍封网，"80% 是套路，不是意识"——通过发/打特定点逼对方只能回你预设的方向，"谁能够把前三拍打得越好，这一分基本上就是归你" [2][7]。

## 核心要点
1. 前提先过关：学前三拍前必须先会封网、启动与左右步伐、发球（会发过网下沉球和内外角/后场）、接发，以及被偷后场时的正确退法 [2]。
2. 发内角：对方必须转腰，"只要你发个内角小球，95% 都会回到正手"；发完立马抬拍、右腿往右撤半步，大胆提前往正手位跑 [2]。
3. 发外角：对方正手接、基本打直线；发球要有隐蔽性，发完左腿上前启动，用反手挡/压封直线；"反手封网又安全又好用"，不必用头顶强行封外角牺牲半场 [2]。
4. 发中间（身体球）**必须发重**："发轻一点……只要他有某些技术，他是可以变方向的"；发重逼他转腰，方向就固定。发到右腿前一点（单数区发对方左肩/左腿），之后看握拍定：反拍→挡直线，正手→打对角 [3]。
5. 单数区发身体球是"几乎百分百"：球贴身他只能换反拍挡网/挡腰/对角，且"你一定要一发完就走一步了，他一碰你就直接拍了"，不能等他打了才启动 [3]。
6. 接发/挡网后**打完退一步到白线**，别站白线前：站太靠网或架拍太大是"抓到了但老漏"的两大原因；选择搓贴网才上前（风险高），挡网就退（容错高） [4][7]。
7. 发力球铁律：**脚和球必须同时落地**，不往前飞——"千万不要碰到球了再落地"，压低重心站稳打，打完才有下一拍 [4][6]。
8. 追身球：球贴身+有速度，对方来不及想只能按你要的方向回——打前场人中间/偏右他回反手方向，打正手前一点点他回另一侧，打左肩快速球他必侧身回右边 [5]。
9. 转身球：让球**过他身体**再下坠他只能打直线（勾球需要"球在你前面还有一点距离"）；打后场人推过身就"百分百"直线；但别打太软（能勾）也别太贴身（能抽） [5][6]。
10. 轮转原则："打哪里，封哪里"——你封自己回球那侧直线，搭档顾另一边，打完退一步抬拍形成"双压"；打对角就并步（非交叉步）往对角跑 [4][7]。

## 常见错误与避坑
- 发完球站着等："他们发完了，对方打了他们才启动，然后球已经下来了"——知道对方要打哪就更该提前动 [3]。
- 接发往前冲抢网：往前冲球就到身体左侧打不了，"压低重心就好，不用往前冲得那么着急"，往外伸着打 [4]。
- 站太靠网或架拍太大："为什么我站网前我好像抓到了但我老是漏？"就这两个原因 [4]。
- 往下打太尖时傻等直线：他看不到你只能勾对角，"可以直接跑对角，90%~95% 他会勾对角" [6][7]。
- 对方发球质量高还硬往后场发力："我越使劲，球就越高"，被上手压死；改打刚过前场人、带一点弧度离后场人一点距离的球 [6]。
- 被发 2 号球+对方冲扑时勉强推：只可放/挡，挡不着急、越快球越重；他会用反拍平抹回来，"你不用怕，你是能够接到的，抬拍就行" [7]。

## 发球点位 × 对方回球 × 第三拍对照表
| 发/打哪 | 对方大概回哪 | 你发完做什么 |
| :--- | :--- | :--- |
| 内角（双数） | 95% 回你正手 | 抬拍→右腿右撤→启动拦 |
| 外角（双数） | 直线 | 抬拍→左腿上前启动→反手挡/压 |
| 中间（双数，发重） | 反拍→直线 / 正手→对角 | 侧身抬拍拦或压 |
| 身体（单数，发重到左腿/左肩） | 挡网/挡腰/对角 | 立刻往前走一步抬拍扑，搭档补后 |
| 内角后场 | 杀对角或中间（杀不尖） | 退一步抬拍重心低，挡 |
| 外角后场 | 吊球或发力 | 原地不动即可 |

## 训练方法
- 四人实战法：两对只打前三拍 4~5 拍就停，专练分球与抓球套路 [7]。
- 在家扔球体会"贴身逼方向"：让朋友朝你身体快速扔球，你第一反应的方向就是你被打时的回球方向；他能变向就说明你扔慢了 [5][7]。

## 子技能难度×收益评级表
| 子技能 | 难度 | 收益 | 一句话理由 |
| :--- | :--- | :--- | :--- |
| 发内角+提前撤步抓正手 | 低 | 高 | 套路最简单、95% 可预判回球，前三拍性价比之王 [2] |
| 身体球发重+发完就走 | 中 | 高 | "必须发重"一改，方向立刻固定，单数区近乎百分百 [3] |
| 打完退一步到白线+抬拍 | 低 | 高 | 一条习惯同时解决"老漏"和回位，立竿见影 [4] |
| 脚和球同时落地 | 中 | 高 | 是能封第三拍的前提，所有发力球通用 [4][6] |
| 追身球（前/后场人） | 中 | 高 | 球贴身+有速度即可逼方向，平抽对抗通用 [5] |
| 转身球（过身+下坠） | 中 | 高 | 逼直线的进阶手段，但力度/弧度/距离的"度"要练 [6] |
| 反手封网与打完抬拍习惯 | 低 | 高 | 封网基础动作，安全好用，避免牺牲半场 [2] |
| 对高质量发球的应对球 | 高 | 中 | 需精确控制"刚过前场人、离后场人一点"的弧度球 [6] |
