# 21. 特别被动的球怎么打

> 📺 反手 24 课时 · 第 21 节 · 约 20 分钟
> 教练：李宇轩

前面讲的都是"正常能打得到"的球，这节专门讲**特别被动、特别低的球**——那种球已经快到你身边、你必须整个人沉下去才能碰到的球。

教练开头说：

> 教练原话："其实基本上都是一样啊，但是还没有教你怎么压腿、怎么去迈腿等等的，就是一些小小的调整。"

**动作还是那一套，只是多了两个调整：重心压低、出拍方向改成横着。**

---

## 一、手上动作：不往上，而是"往外"

这是这节最重要的技术点。教练先讲清前提：

> 教练原话："球那么低呢，我们肯定是要压低重心的，我不可以这样子练啊。"

然后讲正常球和被动球的区别：

> 教练原话："正常来说呢，我们是下来、上来、出发嘛。这个我们是下来，然后我们不上去，我们是往外。"

也就是说：

| | 出拍方向 |
| :--- | :--- |
| 正常反手 | 下来 → **往上**上走 → 出拍 |
| 特别被动 | 下来 → **往外（平着）** → 出拍 |

但手腕还是**立着**的：

> 教练原话："我们不上，我们是往外，往外的时候保持立着你的手腕，然后舒展小臂，这边我们不立上来，我们还是一样，还是做这个外翻动作，只不过我们现在是不上去，我们是平着动作外翻。"

**架拍高度**：腰和肚子之间。

> 教练原话："你看我这在架拍的时候很低的，差不多也低……就到你的腰和肚子这边吧。然后触小臂比较平行一点。"

**击球点**：比球低，不高于球。

> 教练原话："我没有说高过球，也没有说跟球一个平行……但我不在这边打，我打这个（低的）点。"

## 二、为什么要压低？低了才能把球打上去

这是这节反复出现的核心原理：

> 教练原话："你压低重心……我一翻的时候，球才会往上走。如果说平（着翻），翻盘它变成什么？一个平抽。"

教练进一步总结：

> 教练原话："我打时我会尽量低过球啊，要不球不会往上走了。"

所以**"低过球"是被动的关键动作**。

**如果击球点太高，横着打会变成什么？**

> 教练原话："如果说（击球点）高（了），翻（着打）它变成一个劈（吊）。"

> 教练原话："平抽怎么做？都说一样，只不过我不会那么低，我会抬高点，这样压它就变成一个劈（吊）。"

**所以：**
- 低过球 + 外翻 = 球往上走（高远/过渡）
- 跟球平行 + 外翻 = 平抽
- 高过球 + 下压 = 劈吊

## 三、打完手会往下掉，这很正常

这个细节很多人会纠结：

> 教练原话："你看即便是我打完后，我这样子往下翻……我击球的时候是这个（位置），啪，球已经飞走了。这个（下翻）不是连贯的力量。"

> 教练原话："难道我连贯力量要上去吗？上去的话，等于我这个轨迹已经不对了，我就没有力量了，我这个要顺着把这力发出去。所以它会往下，无所谓，但是我击球时候是这样子击的。"

**击球那一下是对的，打完手掉下来是自然的收势。**

## 四、手要打开，越大越好

> 教练原话："你越开越大，你空间越好，你到最后你抓的时候呢，它就有一个多余的这个力量……我们这就用上手指力量，它又是另外一个变数，一个爆发力。"

**打开 → 放松 → 推的刹那抓紧。**

## 五、加上扭腰和迈腿

手上的动作熟了，就可以加移动：

> 教练原话："加上一个扭腰动作，我们就立马站在左腿去扭腰，可以吗？"

**站位**：左腿往后斜着站。

> 教练原话："我左腿可以往后站，斜着往后，然后我扭腰。"

**不要过球太多**：

> 教练原话："你不要过球太多啊，你过球太多，你根本看不到球了。差不多你扭完腰后，他在你旁边就行了。"

**为什么要往外站？**

> 教练原话："你不可以站那么近……因为我们这样子的话，它就有点平，所以我就更加要往外站了。所以就是说为什么被动时我们会这么打，因为球很远啊。"

## 六、"打完转回来"不是腰在动

这一段是这节的技术核心，讲的是很多人会误解的地方：

> 教练原话："你会看到呢，我一落地的时候……由于我是顶我的肘往后顶，我肘是往后，然后舒展，你会发现我的这个好像有个往后这样转回来的一点点。但是并不是因为我在动我的腰啊。"

**那是什么？**

> 教练原话："是因为你在（转）你的这个肘，还有你的肩，他才会有一个往这边带，只不过你上半身，你的腰是比较被动的。"

教练专门否掉了两种错误理解：

- **不是腰在同步动**——"我并没有说一同动，很多人会觉得是一同动，你的脚在这边落地就同步了"
- **不是靠腰去转**——"也不是说，噢，脚对，然后靠你的腰去，不是啊"

**是肘和肩的速度带动上半身转回来**。

## 七、特别注意：挺胸，不要缩肩

> 教练原话："压下来，但是我是挺着胸的，我不是这样子缩肩啊。只要你有顶住（就对了）。"

## 八、为什么特别被动时右腿要抬得更高

> 教练原话："这个如果这球更加远，我会抬得更加高。为什么呢？因为像我不只是为了要扭腰，我还要有一个发力蹬出去，所以我会抬得更加高，让我这边压得更加多。"

所以逻辑是：**抬腿 → 重心压更低 → 蹬得更远**。

教练还讲了一个观察："静态动作很奇怪，好像打功夫一样，但连贯起来看不出来。"

> 教练原话："但是如果我一突然做慢下来，你看出来，哇，这个太夸张了，太连贯起来并没有。"

## 九、球真的过头了，左腿要抬起来借力

这是这节最后的一个高级细节：

> 教练原话："如果这球是靠后一点的话，我们还会抬我们左腿……后面的话我就会抬我的左腿，因为我借力。"

> 教练原话："一旦（球）过我，我的（左）腿就要抬起来，要不然很难借力。"

而且抬起来之后：

> 教练原话："我一抬起来的时候，我就（往）前走一点。"

**但打完一定要收回来**：

> 教练原话："这个球打完后左腿一定要收。"

而且**收腿不能同步做**：

> 教练原话："打完后……我不要你们一同做，不要这样子，一同做它就变成同步发力。它不可以这样子。"

## 十、左腿要收，但不能和击球同步

这一点和前面讲的"不要同步发力"是一回事：

> 教练原话："即便我扭回去啊，但是我的腿没有扭回去，我没有同步，我是扭，我往前踏，啪，我扭回来是无所谓的，因为那是一个反弹力量。"

**扭回来（上半身）可以，但腿不能同步跟着动。**

## 十一、特别特别远：启动就压低

教练最后讲了一个场景——**离你特别远的平球**：

> 教练原话："他发过来的球呢，我永远一定会（压）过去。本来他发得很高，我就可以正常能动，但现在这个球比较平。那我不可以站得那么平。"

**关键在启动的一下**：

> 教练原话："即使我反应过来的时候，这个球的高度比我头高，但是我站那么平是不可以的。因为当我再进这一步的时候，到了这边的话，球体（已经）那么低了……所以我还会在启动的时候，我们就会直接压低重心，保证我还是往上这样子看就很好，到这边的时候就正好了。"

**所以特别远的平球，要在启动的那一刻就压低重心**，而不是等跑过去再压。

## 十二、右腿一定要过球

这句教练说得非常重：

> 教练原话："这个被动球呢必须一定要过球，你的右腿一定要过球。你没有过去的话，再见了。"

不过球会怎样？

> 教练原话："你可能可以挡个直线，没有问题；你可能可以去做过渡，过渡倒是没有问题，因为还是后面切是没有问题，但你要打个底线很难的。"

所以：

> 教练原话："尽量右腿过球，可以过球就要过球。"

即使没完全过，也要"稍微跟球一个距离"。

## 最后：这节总结

| | 正常反手 | 特别被动球 |
| :--- | :--- | :--- |
| 重心 | 站直 | **压低，低于球** |
| 出拍方向 | 往上 | **往外（平着）** |
| 手腕 | 立腕 | 一样立腕 |
| 架拍高度 | 较高 | 腰、肚子之间 |
| 右腿 | 迈一点 | **抬更高、必须过球** |
| 左腿 | 支撑 | 极被动时**抬起来借力**（打完收） |
| 扭腰 | 适度 | 扭得更多 |

| 要点 | 原话抓手 |
| :--- | :--- |
| 球低必须压重心 | "球那么低呢，我们肯定是要压低重心的" |
| 不往上，要往外 | "我们不上去，我们是往外" |
| 低过球才能打上去 | "我打时我会尽量低过球啊，要不球不会往上走了" |
| 打完手往下掉是自然 | "那是一个反弹力量"（不是击球的力量） |
| 打完转回来不是腰在动 | "并不是因为我在动我的腰" |
| 特别远要启动就压 | "我们就会直接压低重心" |
| 右腿必须过球 | "你没有过去的话，再见了" |
