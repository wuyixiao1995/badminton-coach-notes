# 87. 反手主动勾球的手指动作（重点）

> 📺 网前技术 157课时 · 第 87 节 · 约 1 分钟
> 教练：李宇轩

这节很短，但教练说这是**最重要的一个点**，专门给第一视角拍的。

> 教练原话："这个手呢，勾这个动作啊，太重要了。"

## 一、错的转法

> 教练原话："有些人我看他们是这样做的，他们做这个动作，他们是这样转的，不是这样转的。你看你的手腕这样子不对啊。"

**平推更不行：**

> 教练原话："当然了，你也不可以是（这样）握着，我转过来，然后你们是这样平推，是更加不行。"

## 二、对的：夹着压、转

握好之后，**拇指侧边顶在侧棱**：

> 教练原话："他这个动作是握好来，对吧？拇指侧边顶在侧棱，然后你看我这个动作，看到没有？"

**核心动作：**

> 教练原话："是这边夹着，这样子压。给你们从这个角度看——压、转，压、转，抬上来。"

> 教练原话："这个动作夹着，这个动作。一定要有这个动作好吗？"

**注意——不是用拇指这样转：**

> 教练原话："不是拇指这样子，转不是啊，是夹好来，这样子，这样子带过来。"

> 教练原话："当然我们不会是这样子的，我们会是有点（斜）。"

## 怎么练

| 要点 | 原话抓手 |
| :--- | :--- |
| 手腕那样转不对 | "你看你的手腕这样子不对啊" |
| 平推更不行 | "你们是这样平推，是更加不行" |
| 拇指侧边顶在侧棱 | "拇指侧边顶在侧棱" |
| 夹着压、转 | "这边夹着，这样子压……压、转，压、转" |
| 不是拇指这样转 | "不是拇指这样子，转不是啊" |
| 多练 | "这个太重要了，多练这个动作" |
