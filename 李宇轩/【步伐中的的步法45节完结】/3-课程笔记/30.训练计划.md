# 30. 训练计划（四点连贯）

> 📺 步伐中的步法（45 节完结）· 第 30 节 · 约 15 分钟
> 教练：李宇轩

主动球（平行启动 + 前后站启动，正手 + 头顶，高远球 + 吊球 + 杀球）全部学完了。这一节是**学被动/防守之前的一个过渡训练计划**。

> 教练原话："在我们还没有学被动步伐、反拍步伐和防守步伐的时候呢，**我们先做一个四个点的训练，这个你们可以开始先练了。**"

## 一、四个点是什么

> 教练原话："我们先做平行启动，你看往前我们也会，对吧？所以现在我们就做这 4 个点的——往前我们都学过了：这平行启动我去（搓）球，对不对？回来，然后平行（启动）再去（搓）球，然后回来，然后我们这样子（挑球）……主动的高远球平行站。"

也就是：

| 点 | 打法 |
| :--- | :--- |
| 网前 | 搓球 / 挡网 |
| 网前 | 挑球 |
| 后场 | 高远球 |
| 后场 | 吊球 |

> 教练原话："**这个我们先练所有都是起高远球的。**"（先不起被动球）

## 二、第一组：提前预判启动

这是本节的独门方法。

> 教练原话："平时我们是这样子启动嘛，对吧？现在呢我们第一组呢，我们可以这样子练：**每次我们去这边的时候呢，我们可以是不管你是回来右腿在前面还是左腿在前面无所谓。我们去这边的时候，就像我们那训练一样，我们会是这样子（斜着）启动去这边。**"

具体说：

> 教练原话："比方说我打完这球，我去挑完球，回来，怎么启动？……我可以提前。**预判我要去这边，我就怎么启动；去这边，我就什么启动。**"

> 教练原话："就是我不是回来平行启动的。我可以先提前预判我要去这边，我就（朝那边）启动。"

网前也一样：

> 教练原话："比方说我去这边，我可以先这样子（朝那边）……比方说我去那边，我可以这样子。"

> 教练原话："第一组我们可以是这样子，**我们就是把这个移动的惯性先练起来。**"

### ⚠️ 这样练对不对？

教练主动回答了：

> 教练原话："我要先说，这样子的话对吗还是错？**这样子的话呢，它是没有错的。** 因为我在前面已经说了，平时我练球的时候呢，我有时也是会这样子。"
>
> 教练原话："比方说如果我打个球，实战的时候我打我会（回来），突然间他打回来这边呢，我反应过来了，我可以不这样子启动的。"

> 教练原话："如果我能够反应过来。所以一样照练。**你练多了，在实战的时候，你看到球出来的时候，你会觉得你的脚自动会动。**"

> 教练原话："像我在（网）前的时候，我说要是如果你可以（预判）他（打）这边，你这样子去，你可以（跑得）很好的。**只不过是我们很难做到，因为我们来不及。**"

**为什么会有用？**

> 教练原话："所以在练步法的时候练这两种：一种就是先（预判）往这边去的。练完了一组，然后你就（回）平行启动了。你这样交叉、交叉练，很好的。"

## 三、第二组：平行启动

> 教练原话："然后呢我们就可以练平行启动了，这样子：'啪' 1、2 启动。"

> 教练原话："平时启动跑 4 个点，你会觉得有点别扭。但是像我说的，如果你刚开始这样的时候，觉得哇这启动有点别扭，无所谓……**像刚才我给你那个训练计划就行了：去这边你就这样子启动，去这边你就这么启动。** 这样子的话，你发觉跑起来也是挺舒服的。"

## 四、杀/吊上网的连贯复习

> 教练原话："刚才我们已经做了，对吧？不管是吊球上网、两边吊球上网，或者是杀球上网，你们都学会了。"

### 吊球的多种回法

> 教练原话："记得啊，你这个吊球的时候呢，**你有好几种回法**：一个是并一步再来启动；另外一个是直接重心挪过来，直接启动（小并）。"

> 教练原话："你吊完球时，你这个并不可以并小步点，然后再来（换）用左腿。"

### 杀球上网的两种

> 教练原话："杀，直接跑。" 如果远的话可以加垫步。
>
> 教练原话："或者是有这种一杀完直接挪、直接跑的——**先把重心挪来这边，然后（跑），这也是靠左腿的。**"

> 教练原话："这个还是要练到你的腿有力啊，重心可以放低一点。"

## 五、混合练：按球的类型选回位方式

> 教练原话："现在呢比方说如果我挡网，我挡网的话，我退的方法就不一样；我（搓）球，我学（会了）；平行启动后场也是一样，我打高远球，我就回来，我就平行启动；我要是如果掉（吊）球的话，我就直接前后站，准备往前跑。"

示范顺序：

> 教练原话："发球，（挑）后场，挡网，（挑）直线回来，吊球并（步），挡网，（挑）最（高）给来，挡网，高远球，要对角，吊球，挑球。"

## 六🔑 每球前先想好自己打什么

这是本节重要的意识训练：

> 教练原话："**每次你在练这四个点的时候呢，每一次都要先想好你要打什么，或者是（想好）他要打什么。**"
>
> 教练原话："至少你知道——我起完球，我现在要起球（了），我要平行启动。"

## 七🔑 前脚掌还是脚后跟？

这是教练在最后补充的一个很实际的问题：

> 教练原话："有些人肯定会问，要是我们打完一个高远球，我们回位的时候，**为什么有时我们会看到别人用前脚掌，为什么有时会看到别人用脚后跟？然后才换去一个启动。到底哪个是对，哪个是错？**"

**答案：两个都可以。区别是速度和步幅。**

> 教练原话："如果是我挑球，我退得慢，我肯定会用到脚后跟（再）启动。你要稍微快一点，然后我一定会用前脚掌的。"

> 教练原话："**每次我们说这个'快'字呢，都是因为（步）小，你才可以用前脚掌。**"

对比：

> 教练原话："我调完后我要（用）前脚掌，对吧？我不可以（大）这样子的——不可以，我就用到脚后跟了，看到没有，我的左脚我就用脚后跟了。"
>
> 教练原话："如果我是要用前脚掌的话，同样只是小步，这样子就很快。快同时也是小（步）。"

后场也是一样：

> 教练原话："比方说我打完高远球后，我并（步）回位……如果我回位得很慢，我一定会用脚后跟的。但是如果是我回得很快，小步，懂吗？**只有小步的时候，你想要加速、你想要快，你才可以用前脚掌。**"
>
> 教练原话："只要你打一个高远球，你稍微要走慢一点，还是走大步一点的，**一旦一大步，你不可能这样走啊，你一定会用脚后跟的。**"
>
> 教练原话："只是到这边你要启动的时候，再换去前脚掌再启动，是 OK 的。**因为你打（得）够高，你足够时间去做这些动作。**"

**教练的观察总结：**

> 教练原话："有时你们看他们打比赛，他们有时退的时候全部都用前脚掌；有时候他们退的时候会用到脚后跟。后场打个球也是一样，打完球回位、回中间的时候，好像都可以用到脚后跟的——**因为他们回得很慢，因为他们打得很高。**"
>
> 教练原话："**只要是大步、或者慢，你都会用到脚后跟的。** 你不能用前脚掌慢慢走，很奇怪，我一定会用脚后跟。直到他要打的时候，我才换去一个（前脚掌）这样启动，就 OK 了。"

## 最后：这节总结

| 训练组 | 内容 | 目的 |
| :--- | :--- | :--- |
| 第一组 | **提前预判启动**（不回中，直接朝目标方向启动） | 建立移动惯性 |
| 第二组 | **平行启动**（回中后 1、2 启动） | 实战标准节奏 |
| 第三组 | 吊球上网 / 杀球上网 | 复习 + 重心挪左腿 |
| 混合 | 四点连贯（网前搓/挑 + 后场高远/吊） | 实战循环 |

| 要点 | 原话抓手 |
| :--- | :--- |
| 提前预判启动没错 | "这样子的话它是没有错的" |
| 两组交叉练效果最好 | "你这样交叉、交叉练，很好的" |
| 每球前先想好要打什么 | "每一次都要先想好你要打什么" |
| 慢/大步 → 脚后跟；快/小步 → 前脚掌 | "只要是大步、或者慢，你都会用到脚后跟" |
| 启动那一刻一定要换到前脚掌 | "直到他要打的时候，我才换去前脚掌启动" |

教练交代下一步：

> 教练原话："练到你熟悉了，然后我们再来学**被动的和防守的**。"
>
> 教练原话："我要先说，要是我们在练步法的时候，**很少人会练被动的步法训练**。有，但是我们很少会把它放在我们的训练计划里面，但是还是一定要教的。"
