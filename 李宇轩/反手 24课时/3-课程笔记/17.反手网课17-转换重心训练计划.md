# 17. 转换重心训练计划（在家怎么练）

> 📺 反手 24 课时 · 第 17 节 · 约 15 分钟
> 教练：李宇轩

前面把原理都讲完了，这节开始讲**在家怎么练**。教练开头就说了：

> 教练原话："我觉得更加重要是这个扭腰，你会了扭腰，然后你再练并步、再接这个节奏，都无所谓。"

所以这节的训练顺序是：**先练扭腰，再加并步。**

---

## 一、准备：放一个球在地上

教练给的方法很土但很好用：

> 教练原话："你可以放一个球在这边……差不多离球差不多一个球拍的距离。"

**为什么是一个球拍的距离？** 因为你要有空间做舒展，但又不能太远够不到。教练反复强调：

> 教练原话："不要过球。"

站的姿势也有要求：

> 教练原话："保证脚是这样子的，不是这样子。"（即**斜着站**，不是正面对着球）

然后就是**重复这个动作**：

> 教练原话："每次做你确认步的时候……转腰、抬左手、扭，这样子就行了。"

## 二、第一个重点：左臀不能动

这是这节讲得最细的地方。教练说：

> 教练原话："你的这个左臀呢还是保持这个位置……就是你这个脚是一个轴的话，它不会再动。"

教练还演示了"动"和"不动"的区别：

> 教练原话："他不会塌的时候（你再转的时候，他）桶**痛**不会（动）……一站好就是站好了，我这个没有在动了。"

翻译过来就是：**左脚和左臀是一个固定的轴**，转腰的时候这个轴不能左右晃、不能塌下去。如果需要，可以**主动做夸张一点**，先让肌肉知道自己在做什么：

> 教练原话："可以做夸张一点，我们先把这个动作做夸张一点，让你把这个肌肉练会，让你知道哪一个肌肉在做什么。"

## 三、怎么自检站不稳

教练给了三个非常好用的自检信号：

| 现象 | 原因 |
| :--- | :--- |
| 往**后**倒 | 重心太靠后了 → 往前压一点 |
| 往**前**倒 | 往前加太多了 |
| 往**右**倒 | 左边拉得不够、转得不够 |

> 教练原话："如果你发现到你要往后倒，你就说你这个太靠后了，可以往前压一点。如果你往前倒的话，也就是说你往前加太多了，或者是你往右边倒的话，也就是说你这边拉得不够、我这边转得不够。"

教练还提醒：**如果站不稳，一般两个原因**——

> 教练原话："没有站稳的话，就是说你可能甩太快，要不然就是你哪一个动作没有做得完整。"

## 四、第二个重点：上肘和右腿踏地必须同时

这个前面几节讲过，这里落到练习方法上：

> 教练原话："上走（肘）、伸右腿，可以只要想着上肘伸右腿就行了，自然会（伸）直。"

**关键：不要提前做。**

> 教练原话："你不可以提前做，你一提前做，你就会有这个现象。因为为了要站稳，然后才上手，就完蛋了，你的腰已经绷住了才出，不可以了。所以一定要同时做。"

教练还解释了一个很形象的现象——为什么一定要"上肘"：

> 教练原话："如果你一发力对吧，你还没有上肘，你一定会这样子的……你可以跌倒了。"

意思是：**上肘这个动作本身就是在帮你稳住身体**。

## 五、第三个重点：慢！不要用腰

教练在示范时发现自己做得急了，当场就纠正：

> 教练原话："刚才那个我做得有点着急啊，我就顶它太多了，千万不要。"

然后给出练习节奏：

> 教练原话："不用那么快啊，你越快你越会用到你的腰。先慢。"

以及最重要的提醒：

> 教练原话："记得我们这个腰呢是被动的，不是主动去顶啊。"

教练还说了一句很实在的话，解释为什么他让大家先慢：

> 教练原话："因为我真的很怕你们去顶腰啊。"

## 六、左腿可以先不用

教练给了个"降级版本"，方便大家先把动作做对：

> 教练原话："你可以先不用用你左腿吧，我觉得……你们就去上你们的肘，然后（右腿）碰地行啊。"

等动作熟了再加左腿，这样不会一上来就把腰搞绷住。

## 七、左手要一直"顶住"

这个细节教练强调了多次：

> 教练原话："这个往下顶啊，往后拉住，这个上来的时候，这个要继续的往下顶啊，不要放开。"

而且教练形容了那种"被拉住"的感觉：

> 教练原话："好像有一个人在拉住我左边，让我很好去发力。"

关于左手的位置，教练解释了一个之前可能没想明白的问题——**为什么架拍时手要放左边一点**：

> 教练原话："为什么我们手会放左边一点呢？就是因为我在拉左肩，我就放这，只有我再拉出去，他就动了。"

## 八、被动的时候：左手往外舒展

> 教练原话："很被动的时候，你们发现你们左手可能要往外舒展点……舒展点可以站稳点，因为你重心压很多，要不平衡不了。"

还有一处很重要：**很被动的时候，你只会感觉到胸在舒展，感觉不到腰**：

> 教练原话："到了很被动，你只会感觉到你舒展你的胸，你不会感觉你的腰。"

如果感觉不到腰、只感觉到胸，说明动作做对了。如果腰很紧、很酸，就是做脱节了。

## 九、最后一个自检细节：左脚和右脚的角度

教练在录像里专门放慢给大家看：

> 教练原话："我的左脚是这样子的……我的脚是朝这样子的，我的右脚是朝这边，但我左脚呢不朝这边，它是朝这边的。"

也就是说：**两只脚不是朝同一个方向的**，落地时身体还是有点斜、有点扭腰的感觉。教练说这个角度"有一点点就好"。

> 教练原话："保证你落地的时候还是有点扭腰就行了……我一扭，我就往这边走，也是可以。"

## 十、练到最后会怎样

教练描述了这个动作练熟之后的感觉：

> 教练原话："当你们（练得）熟悉的时候，你们不会感受到那么（分解）……这个动作不会感觉到那么夸张，你不会感觉到这个那么长（的时间）。你一上来基本上你就觉得落地。"

也就是说：**分解练的时候是一步一步，连贯起来就是"上肘、落地"几乎同一瞬间**。

还有一个小细节，教练说**打完可以回来一点点**：

> 教练原话："我可能可以回来一点点，就回来那么一点点，无所谓。但是我打完了，你看到吗，我身体其实他并没有回到这边，因为我扭得很多嘛。"

## 最后：这节总结

| 步骤 | 怎么练 |
| :--- | :--- |
| 1. 准备 | 地上放一个球，离球约一个球拍距离，斜着站 |
| 2. 定轴 | 左脚 + 左臀是固定轴，转的时候不能晃、不能塌 |
| 3. 转腰 | 转腰 + 抬左手 + 往后顶，可以夸张一点练 |
| 4. 上肘 + 右腿 | 两个同时做，不能提前 |
| 5. 慢 | 越慢越好，不要用腰去顶 |
| 6. 加左腿 | 先不用左腿，熟了再加 |
| 7. 加并步 | 最后才加并步和节奏 |

| 要点 | 原话抓手 |
| :--- | :--- |
| 先练扭腰再加并步 | "你会了扭腰，然后你再练并步" |
| 左臀是轴，不能动 | "我这个没有在动了" |
| 上肘和踏地必须同时 | "一定要同时做" |
| 慢，别用腰 | "你越快你越会用到你的腰。先慢" |
| 腰是被动的 | "记得我们这个腰呢是被动的，不是主动去顶" |
| 很被动时只感觉胸、不感觉腰 | "你不会感觉你的腰" |
