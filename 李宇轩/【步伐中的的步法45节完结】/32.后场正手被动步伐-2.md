# 32. 后场正手被动步伐（2）：弓箭步

> 📺 步伐中的步法（45 节完结）· 第 32 节 · 约 10 分钟
> 教练：李宇轩

上一节讲的是**上手打法的被动球**。这一节讲第二种情况——**球已经非常低了**。

> 教练原话："另外一种就是球很低了，你反应过来的时候球已经很低了。**我反应过来的时候呢，球已经过了我，甚至它已经很低了，我没办法在上手打球了。**"
>
> 教练原话："因为球很低的话，我不可能这样打，不可能，对吧？那我要这样——我后面这第二种方法，就是我要用一个**弓箭步**了。"

## 一、两种被动的分界

| 情况 | 打法 |
| :--- | :--- |
| 反应过来时球**还挺高**，还能过球 | **上手打**（后交叉 + 前脚掌） |
| 反应过来时球**已经很低**，过不了球 | **弓箭步**（压低下打） |

> 教练原话："**第一种打法是我反应过来的时候球很高，我还可以过球、在上面打。这个是球很低……我就会被骗了，我就会刚好（把它）过、压低，我就这么大（跨）。**"

## 二、什么时候用弓箭步？

> 教练原话："如果我后交叉后球挺高的，然后球不是离我特别远、球离我比较近，这样子的话，我就可以右腿过球过多一点点，我打——我打的时候我会用（前脚掌）的。"
>
> 教练原话："**如果我后交叉后球离我很远，我就得立马用一个弓箭步，因为弓箭步它也去得远。然后刚好跟球一个距离，我就这样打。**"

## 三、动作

### 起步一样，只是最后一步变了

> 教练原话："其实还是一样的，只不过你打完的时候，你是用一个弓箭步而已。"

> 教练原话："球要是如果不是很边，它在这边的话，但是球位已经很低了，我们就是会打开，直接做个后交叉，我们就直接扭腰。然后呢，现在因为球已经很低了，**我没办法上手打球，我也没办法过去了，我就只能够（跨步）。**"

### 关键：压低左腿

> 教练原话："比方说球在这边，'啪'，它这边掉了，已经差不多这高度了，我就只可以做一个弓箭步，刚刚好一过去我就打。"

> 教练原话："**重心放低，弓箭步你们应该会啦，就跟往前一样的，压低左腿，这样子，然后就收腿，一模一样。**"

> 教练原话："**你压低左腿，压得越低**，你左腿的高度跟球是一个平行高度，那你（就）好打。"

### 击球点：刚好过球

> 教练原话："球如果在白线，我稍微更好过球，我就打。**我一打的时候，立马收左腿，然后我就可以转回来了**，让我（回位）。"

## 四🔑 回位：直接并回来，不要转身

这是本节最重要的提醒。

> 教练原话："我想说，要是用弓箭步的话，你可能会比较难做这个动作，为什么呢？**因为首先你为什么做个弓箭步呢？因为你已经很慢了，你已经来不及了，你才会做一个弓箭步，因为球低了吗。**"

> 教练原话："你都已经那么低了，打完后呢，你觉得你可以（转）那么多、转身再走？不可以的。**你一手你可以站好，你就立马并回来了。你一收，你可以并回来的。**"
>
> 教练原话："因为你首先你已经被动了、已经慢了，**你不可以再花那么多时间去做这个动作，再转太慢了，做不到的。**"
>
> 教练原话："**而且你最合理的方法就是立马并回来，就可以了。**"

对比上手球：

> 教练原话："因为上手本身你是在前面打的，你（比较主动），你也是 OK 的。但这个太被动了，这球太低了，很难做。**所以要是用弓箭步的话呢，我们就立马并回来。**"

### 球远时：加一个并步

> 教练原话："那如果球远呢？一样的东西，只不过是加一个并步。"

## 五⚠️ 这个动作的门槛很高

教练说得很实在：

> 教练原话："**这种弓步（打回底线）呢，你的水平要稍微高一点，因为基本（功）要很强才可以。** 因为即使是我带的学生，他们有些做不到。"
>
> 教练原话："比较高的（第一种）就很简单，因为这一个跟这种是一样的道理，只不过我是重心压低做，而且我不是跳，我是后交叉做，就这么简单。**这个被动弓步打（回底线）会比较难。**"

### 打不动怎么办？——碰网

> 教练原话："如果你们刚开始学的话，或者你们打了一段时间水平还不是很高的话，没事，**你们就这样碰网也行**。"
>
> 教练原话："碰完了，当然我们会（因为）不是平行启动了，我们是前后站，等下我们就学了。"

## 六、被动球步伐总结

> 教练原话："我要跟你们说，被动球呢，它的步伐有两种：**启动一样，一就是（球）够（高），你做这个动作再做一个后交叉。第二种就是直接不是很（远），接近你，就直接做一个后交叉。**"

**为什么做后交叉？**

> 教练原话："**我们做后交叉的目的，就是因为当我反应过来的时候，球已经过了我，我并步的话我还在原地，我第一步还在原地；我后交叉的话呢，我就开始在动了，那样我可以找到球，我可以跟球一个平行线了，我就可以去击球了。**"

## 七🔑 压低重心：本节反复强调的一句话

> 教练原话："到最后呢，你做事一定要压低（重心），主动的也是一样，也是要压低的。"

> 教练原话："刚才我已经说了，其实**你压得越低呢，你越好（发）力，而且呢，你越多时间去打球、越多时间去做你的动作。**"
>
> 教练原话："（因为）我们就是要产生空间，让我们去做（动作）。"

> 教练原话："球已经够低了，我建议你再压低一点重心，不只做一个弓箭步，**但是一定要压低重心。怎么压低重心？你是要压你的左腿，先压下来再走。**"

## 最后：这节总结

| 情况 | 打法 | 回位 |
| :--- | :--- | :--- |
| 球还挺高，能过球 | 上手打（后交叉 + 前脚掌） | 正常回位 |
| 球很低，过不了球 | **弓箭步**（压左腿、跨大步） | **立马并步回来**，不要转身 |
| 球很低且远 | 弓箭步前加一个并步 | 同上 |
| 力量不够顶回底线 | **碰网**过渡 | — |

| 要点 | 原话抓手 |
| :--- | :--- |
| 分界线：还能不能过球 | "我没办法在上手打球了" |
| 弓箭步专门解决"远 + 低" | "弓箭步它也去得远" |
| 压低左腿是关键 | "压得越低，你越有空间" |
| 被动后不要转身回位 | "再转太慢了，做不到的" |
| 弓箭步顶底线门槛高 | "即使是我带的学生，他们有些做不到" |
| 顶不动就碰网 | "你们就这样碰网也行" |
