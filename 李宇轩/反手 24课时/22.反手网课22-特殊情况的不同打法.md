# 22. 一种特殊情况的不同打法

> 📺 反手 24 课时 · 第 22 节 · 约 8 分钟
> 教练：李宇轩

这节解答一个很具体的疑惑——**为什么有人一启动就转身，脚还没落地就把球打出去了？**

教练的原话：

> 教练原话："为什么有时你会看到有些球员呢？他们一启动完就直接转身，脚还没有落地，他们就打（了），会有这个现象。为什么？"

---

## 一、前提：基本功全都要会

教练先说清这节不是"捷径"：

> 教练原话："首先你一定要会你的挥拍，甚至你可以做得很快了，然后你这个外翻动作没有问题，你会扭腰了，这些就是基本功你全部都会了。"

**这是"进阶选项"，不是"绕过基本功"。**

## 二、什么时候可以用

三个条件同时满足：

| 条件 | 说明 |
| :--- | :--- |
| 球**不是很高** | 球是平着走的，不是往下掉的 |
| 球**不是很远** | 基本是半场球，在你够得着的范围 |
| 球**稍微过了你** | 你已经来不及做标准并步了 |

教练的原话：

> 教练原话："这个球不是很高，首先这一点，这个球不是很远……我反应过来的时候，球稍微过了我。"

## 三、为什么来不及？因为再走一步球就低了

这是这节的关键推理：

> 教练原话："如果我不直接打呢，我就去（并步），我刚转第一步球就很低了，你知道吗？其实特别低了，我来不及的。"

所以选择是：

> 教练原话："我可以在很低点接，而且是我选择在这个点打。"

**选择在低点接 vs 选择直接转身打**，后者更好。

## 四、为什么直接转身就能打到底线

两个原因，缺一不可：

> 教练原话："为什么我现在直接（打）可以到位呢？因为本身呢，他打这个球呢就有速度，这是第一点。第二点呢，这个球没有离你很远。"

**球有速度** = 可以借力；**球不太远** = 你转过去够得着。这就是"半场球"的特征。

**如果是高球呢？就不行了**：

> 教练原话："太高的话，你做不了，因为太高的话，这球不是平着走，太高的话（是）往下走，而且他到底线了。"

## 五、怎么做：扭够腰，转到球在你身后

动作要领：

> 教练原话："我们保证我们扭腰扭够，扭够我的时候呢，只要我过球，我这样甩一下手腕就到位了。"

注意教练对"在身后"的解释——**不是真的在你身体背后**：

> 教练原话："我扭过球，我不是这样站着对着球，我是扭过球在我的后面。但我说后面的意思是什么？并不是说在我们身体背后啊。"

正确的位置是**右肩旁边**：

> 教练原话："如果球在我的前面，我这么打是打不了的，最好点在……在我的右边。"

> 教练原话："如果球在这边，我不这样打，我也得这样，我转多一点，看到吗？他就在我的右肩这边了。"

## 六、为什么这个"右肩旁边"的点最好发力

教练把原因讲得很透彻：

> 教练原话："这个点呢是允许你发力的……你可以用到你的肩，你可以用到你的肘，你可以用你的手腕，可以用你的手指。"

**而如果在身体正前方**：

> 教练原话："在这边你没有办法的，你没办法做你的上（肘）啊，你上（肘）就往这边放啊，你要怎么上？这样子么？不可能。"

所以：

> 教练原话："为什么我们会转多一点，就是这个原因……转多一点，其实不只是为了扭腰，更重要是产生足够空间。"

**转多的目的是产生空间**——这是这节最核心的一句。

## 七、如果球真的很中间，就身体歪一点

> 教练原话："我们打球点在那里还是一样的……他怎么样都好，都会在你的（右肩）上面，就是你们现在看的，（对右手球员是）11 点（或）我的一点……如果在真的很中间，我就歪一点就行了。"

> 教练原话："反正我是要起球嘛，我起球那就无所谓了。"

## 八、想杀球的话，要转得更多

> 教练原话："如果你要做个杀球的话，那你可能会转得更多。"

而且教练点了一句很关键的东西：

> 教练原话："为什么我们会往后？就是因为我（要）跳过去，同时我在跳的过程中，我要保证我的扭腰，所以我会借这个空间。"

**"往后"不是乱动，是为了在跳的过程中保住扭腰、保住空间。**

教练还提到这就是"李梓嘉那种转身杀"的来源：

> 教练原话："如果（想）转更多产生更加多空间的话，你可以做一个杀球，也就是李梓嘉那种。"

## 九、总结：知道就好，打多了自然会出来

> 教练原话："这个呢其实你们知道就好，你们慢慢你们会打的时候呢，几乎这个自然会出来的。"

条件还是那一句：

> 教练原话："前提是这个球不是很高、刚好过你，你可以一（转身）就直接打的一个情况……如果很高，那就没有必要。"

## 最后：这节总结

| | 标准并步打法 | 直接转身打法（本节） |
| :--- | :--- | :--- |
| 球的高度 | 高 | **不高（平的）** |
| 球的距离 | 远 | **不太远（半场）** |
| 时间 | 够 | **来不及** |
| 动作 | 并步 + 确认步 + 击球 | **启动就转身**，脚没落地就打 |
| 发力来源 | 完整步法 | 借球速 + 扭腰 + 外翻 |
| 击球点 | 右肩前上方 | 一样，**右肩旁边** |

| 要点 | 原话抓手 |
| :--- | :--- |
| 前提是球不高、不太远 | "这个球不是很高，同时球有速度" |
| 再走一步球就低了 | "我刚转第一步球就很低了，我来不及的" |
| 借球速才能打到底线 | "因为本身他这个球就有速度" |
| 不是打在背后，是右肩旁边 | "他就在我的右肩这边了" |
| 转多的目的是产生空间 | "更重要是产生足够空间" |
| 高球不适用 | "太高的话，你做不了" |
