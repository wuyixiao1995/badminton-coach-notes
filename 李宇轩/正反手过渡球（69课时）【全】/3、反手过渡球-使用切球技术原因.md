# 3. 为什么用切球，不用打

> 📺 正反手过渡球 · 第 3 节 · 约 2 分钟
> 教练：李宇轩

这节很短，但把整个过渡球的"打法选择"讲明白了：为什么我们不用打，而是用切或者小球。教练说，它就**跟吊球一样**。

## 一、打正面的话，球控制不住

> 教练原话："要是如果你是要打一个网前球，但是你是打正面打的话呢，他很难控制。你要打一个很好的球的话呢，你得减速了，对吧？我们不要有这种情况。"

**减速就是暴露**——你慢下来，对手一看就知道你要打网前了。

## 二、切球不用减速，动作还有一致性

> 教练原话："如果用一个切球技术的话呢，也就是说我是架拍，我可以甩的很快。他不用减速，他这个动作也有一致性。为什么？他很像去发力，他就很像样打底线。"

> 教练原话："我这样架拍，你可能会觉得这个人要发力，他引拍那么大，他会那么快，他可能要发力。正好我用一个切球技术，这个球会减速。"

对比一下打正面：

> 教练原话："如果我做一个过渡球，我是碰的话，他就要这样子了，慢下来了，就很明显的。因为要是如果做快的话，球就很远，甚至很高。"

## 三、第二个原因：切球更好控制角度、可以贴网过

这是这节最要紧的一段，讲的是反手为什么天生适合切：

> 教练原话："为什么我用一个小球呢？原因就是更加好控制，就可以贴网过。"

> 教练原话："因为我们在打反手的时候呢，往往都是过了我们。那过了我们的球，我们拍面很自然就会朝上。你还打的话呢，球就要往上走。"

> 教练原话："但是如果在这边的球，我用一个切球的技术呢，他刚离开出拍的时候，他会往上走。但由于是一个切球技术，他开始飞的时候呢，他就会渐渐下来了。"

**所以切球的两个目的**：

> 教练原话："我们用一个小球的目的就是为了一致性，还有更加好控制球的角度。"

## 四、球越远，动作越大，这就是隐蔽性

> 教练原话："你看我切的话，我可以很大胆的做切球，很胆的说啊，引拍很大，这动作就有点好像打高远球，我也可以做一个切球。所以这就是他的隐蔽性。"

> 教练原话："当然了，如果球更加远的话，那我就要引得更加大，我就要做这很大动作，因为我要借力。我才可以打出一个很好球，甚至我可以落点很好，我可以回位很好。如果靠打那么远，达不到的。"

> 教练原话："如果我真的使劲的话，就上来了，被扑了。"

## 最后：为什么做切球

| 要点 | 原话抓手 |
| :--- | :--- |
| 打正面就得减速 | "你得减速了，我们不要有这种情况" |
| 切球可以全速挥 | "我可以甩的很快，他不用减速" |
| 动作像打底线 | "他就很像样打底线" |
| 过我们的球拍面朝上 | "往往都是过了我们，拍面很自然就会朝上" |
| 切球先上后下 | "刚离开出拍的时候他会往上走，但开始飞的时候他就会渐渐下来了" |
| 球远就引大动作 | "球更加远的话，那我就要引得更加大" |
