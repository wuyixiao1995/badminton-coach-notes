# 106.正手挑球-手上正确动作(下)

> **教练点评**: 本集详细拆解了正手挑球中手上动作的完整路径，从基础分拍引拍到连贯出球的过程层层递进。重点强调了击球空间、肘与小臂的旋转配合以及不同连贯程度下的发力变化，是打好挑球基本功的必看教学。
> **难度**: 进阶 | **适合**: 有一定羽毛球基础、挑球发力不顺畅或击球点掌握不佳的击球者 | **时长**: ~5min | **评分**: 9.0/10

### 🎯 核心要点
* **保持充足击球空间**：击球点必须在身体前方并保持与身体的距离，切忌站位太贴近球而缩着手臂挑球。
* **手腕后倒与出肘引拍**：引拍时手腕向外后方舒展倒下，出球时由肘部带动大臂向前伸出。
* **小臂收缩与旋转发力**：小臂向上抬起的同时配合推手指与小臂内旋（转小臂），动作一气呵成。
* **击球点始终在胸前**：不论连贯速度多快，最终的推转发力点和击球位置始终保持在胸口/肚子前方。

### 🔧 技术精讲

#### 1. 基础分拍动作分解（1-2-3-4节奏）
* **要领步骤**：
  1. **1（舒展倒手腕）**：手臂向后下方舒展，手腕向外后方充分倒下。
  2. **2（伸臂出肘）**：肘部和大臂向前伸出，保持球拍在身体前方下方，与身体拉开空间。
  3. **3（抬小臂收缩）**：向上抬起小臂，同时保持手腕持续向后倒。
  4. **4（推指转小臂）**：向上推送手指，同时配合小臂内旋转动，顺势带出拍头。
* **关键细节**：不可直接向侧面转动拍面，否则球会直接飞向侧边；拍面应向前上方推转。

#### 2. 不同连贯程度的技术演进

| 连贯程度 | 动作要领 | 适用场景 |
| :--- | :--- | :--- |
| **基础分解** | 完整做足下垂舒展、倒手腕、出肘、抬小臂、推指转小臂。幅度大，感受轨迹。 | 初学练习、体会肌肉记忆与空间距离感。 |
| **完整连贯** | 顺畅连贯：向下舒展倒手腕直接出肘 $\rightarrow$ 带动小臂向上收 $\rightarrow$ 推手指转小臂转肘。 | 场地到位、主动挑球时。 |
| **极速连贯** | 无需向后下方大幅舒展，直接在身体前方稍向外倒手腕 $\rightarrow$ 快速出肘收小臂转小臂。 | 被动快速衔接或节奏极快的场景。 |

### 💡 学习洞察

* 🔑 **保持胸前空间距离**
  * **解释**：大臂与身体不能粘连或太贴身，站位需与球保持一段自然伸展的距离。
  * **应用场景**：在正手网前上网挑球时，通过步法控制好落脚点，确保手腕与小臂有足够的挥拍空间。

* 🔑 **肘部引领与手指推转结合**
  * **解释**：挑球不是纯粹靠大臂抡甩，而是“出肘 $\rightarrow$ 收小臂 $\rightarrow$ 推手指转小臂”的链条式发力。
  * **应用场景**：网前主动挑高远球，利用手指推转的爆发力将球挑至对方后场底线。

### ⚠️ 避坑指南

| 错误表现 | 根本原因 | 纠正方法 |
| :--- | :--- | :--- |
| **缩着手臂挑球** | 站位离球太近，大臂贴身导致无法舒展 | 保持身体与球的距离，站位往后站一点，让手臂向前伸展。 |
| **球直接挑向侧面** | 引拍后直接向侧边旋转拍面 | 沿胸前轨迹向上抬小臂，在推的瞬间同步进行小臂旋转。 |
| **挑球发力不顺畅/没有飞远** | 只有大臂挥动，缺少小臂收缩与推指转小臂 | 强调小臂向上收缩（收小臂）和手指推转的连贯配合。 |

### 🏋️ 训练计划
* **第1天**: 徒手进行1-2-3-4分解动作练习，重点体会手腕后倒与胸前空间的保持（每组20次，共5组）。
* **第1周**: 持拍结合连贯发力练习，从大幅度舒展连贯过渡到前场快速倒手腕推转（每日100次）。
* **器材**: 羽毛球拍、网前练习用球。

### 🔗 知识地图
* **前置技术**: 正手握拍与握拍变换、网前正手上网步法
* **配合技术**: 网前正手搓球、正手勾对角（同引拍伪装）
* **进阶技术**: 正手假动作挑球、结合步法与击球节奏的完整网前综合挑球
