# 07. 正手劈吊对角 1（劈球落点）

> 📺 致命吊球 · 第 7 节 · 约 10 分钟
> 教练：李宇轩

基本功学完，从这一节开始学"**又有隐蔽性、又有威胁力的吊球**"——先学正手劈对角。

## 一、什么叫"有隐蔽性又有威胁"

教练给了两个含义：

1. **引对方去错的方向**——"我要打这边，我可以引他去那边。"
2. **挥拍可以甩得特别快**——"好像要发力、好像打底线球、好像在杀球，但这个球突然会减速去网前。"

## 二、最厉害的技术：打坏别人的节奏

这是教练本节反复强调的核心理念：

> 教练原话："最厉害的技术就是你可以打坏别人的节奏，就这么简单。"

他解释为什么慢的碰球容易被接：

> 教练原话："为什么这种简单的碰球别人会觉得轻松？因为你的挥拍很慢，让我看出来你是一个慢挥拍，让我提前预判你打软球。我就可以对上你节奏了，你再怎么碰，我跟着你的手，节奏全部对得上。"

但如果你挥拍很快——

> 教练原话："你让我觉得你应该是要发力、还是打后场，我就会往后。所以我一启动的时候，人也会往后一点。突然这个球……一个很轻的球，短一个，这就是一个很大的节奏差。"

> 教练原话："只要我能够对上你的节奏，我什么球都能接到。但你每一个球都让我节奏错——一是我提前启动，二是我来不及启动，我就一定会很难接。"

## 三、好吊球靠"切"，不靠碰也不靠打

教练直接点破：

> 教练原话："这种球到底是怎么做的？是靠打吗？是靠拍面正着打吗？肯定不是，如果这么打，球就会去底线了，要不就变成杀球。那是靠什么？是靠切。切球球就会减速，那正好我可以甩得很快，但这球突然减速。"

切球切哪里？**切球头（球托）的边**，不是切球毛，也不是像切菜那样砍。

> 教练原话："劈吊，就像劈柴一样，球这样来，你就劈这个球。"

## 四、动作：不做内旋，直接切

- **高远球/杀球**：引拍后做**内旋摆平**，"做得越准、引拍都做好了，球就很有力量，会飞得远"。
- **劈吊**：**不做内旋摆平**，"既然我们这么引拍，就直接切过去就行"。教练强调："不用变拍，就这样引拍、往前切。"

带上转身动作后：拉左手、撤左腿、转腰抬上手，"**不做摆平，直接切**"，然后抬右腿转换重心。

## 五、粗糙地做会掉出四种坏球

教练把只改动作、细节没掌握的后果演示了一遍：

1. 掉到隔壁场地（角度太大）。
2. 下网下得很离谱（切太厚或太陡）。
3. 掉到很怪的位置。
4. 好像没碰到球（切得太薄）。

还有一种：一直下网后改成"加拍补推"——"因为他们不知道切球的目的，就听'切球就是很快'，其实这样切就没有那个目的了"。

## 六、落点的客观规律（本节重点结论）

教练花了很大篇幅讲这个"鱼与熊掌"的问题：

> 教练原话："一个又快又尖的球，落点至少都会到白线，甚至过白线一点点。有些人说'这不是太远了吗'？没有——如果你做一个很快的吊球，他再怎么尖，至少都会到白线……因为角度的问题，而且网是有高度的。"

> 教练原话："你要吊一个很贴网的球，那你就得把速度减少一点。这个球没办法加速的，它不可能说'加速突然这样掉下来'。它是慢慢地掉下来，有点弧度。"

所以结论是：

| 你想要 | 代价 |
| :--- | :--- |
| 又快又尖 | 落点至少到白线，甚至过白线 |
| 很贴网 | 速度必须慢下来 |
| 又快又贴网 | 从后场基本做不到 |

教练补充：国际球员吊得快的时候"有时都会过白线，甚至会更远一些"；"如果做一个更重的劈杀，它就会更远一些"。

## 最后：这节总结

| 要点 | 原话抓手 |
| :--- | :--- |
| 打坏节奏是最高级的技术 | "最厉害的技术就是你可以打坏别人的节奏" |
| 慢挥拍会被预判 | "让我看出来你是慢挥拍，我就可以对上你节奏" |
| 好吊球靠切 | "不是靠碰或打，是靠切，球就会减速" |
| 劈吊不做内旋，直接切 | "既然这么引拍，就直接切过去就行" |
| 做粗糙会掉四种坏球 | 出界 / 离谱下网 / 怪位置 / 切太薄 |
| 快吊必然到白线 | "再怎么尖，至少都会到白线" |
| 贴网必须减速 | "这个球没办法加速的，它是慢慢掉下来的" |
