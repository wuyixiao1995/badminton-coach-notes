# 挑球（正手+反手）

## 一句话定位
网前起球技术：被动时把球挑高挑到位转入防守（挑得够高对方"先打到球毛，再打到球头，很难杀得很快" [104]），主动时也能压对方底线调动，可加假动作骗人 [104][114]。

## 核心要点
1. **节奏空间占大头**："动作可能能占 30% 或 40%，节奏啊这些空间占百分之六七十" [105]。挑球问题多半不在手上，在节奏和空间 [104]。
2. **正手动作链**：往右后下方舒展、倒手腕（掌心朝外，手到屁股后一点就行）→ 上小臂保持倒手腕 → 收小臂同时"推手腕+转小臂一同做" [105][106]。倒手腕靠食指中指往后翻，不是后三指（否则拍面朝下）[105]。控制不好推手指，就直接抬小臂转（被动式替代法）[107][108]。
3. **击球点**：球侧面"3 点"（约肚子高度）最佳，好挑好发力；4-5 点只能平打，1 点太高只能往下 [109]。正手击球点在胸口前、右肩前 [105][108]。通用规律：最佳发力高度在肚子到肩 [119]。
4. **不要突然加速**："发力呢是（传出去）"，要快就把整套动作变小变快；突然加速会养成脱节习惯 [107]。
5. **左手是命门**："左手一定要先打开，边迈腿边往后顶……没有做的话，根本发不上力，百分百发不上力" [111][113]。左手往后顶=有人拉着你手，重心在后、站稳、迈得远 [110][111]。
6. **低点球三件套**：压腿、压腰、最后一秒头下压（"你头下得越多，这个球就越高"）；越贴网越要在两点击球不在三点 [111][113]。
7. **反手握拍与动作**：拇指顶斜棱或侧边顶宽面（李宗伟式），拇指正顶宽面只能极高点用，挑球不用 [115]。反手击球点在眼睛高度、右肩前，越高越好做，越低越别扭 [116][117][119]；先翻后倒、推拇指转小臂，"不可以只这样抬" [116][118]。
8. **收左腿像刹车**：不收左腿压不下去、回不了位；不敢跑快其实是卸力方法不对，不是腿力问题 [120][112]。

## 常见错误与避坑
- 塌了才找球、缩着打"像机器人"——对的动作是舒展的 [104]。
- 只推/只翻手腕、原地转球拍——不收小臂不转小臂"会打自己的头，手腕会受伤" [105]。
- 先出腿再做手上动作——"千万千万不要先出腿再来做一二三" [110][112]；提前压腰也迈不出去 [120][121]。
- 击球点不对还硬往上挑（4-5 点）——挑不高首先就是点不对 [109]。
- 反手提前推手腕、提前翻拍——球会走歪/去对角 [115][120]；贴网太低的球别硬挑，改切搓/反搓/勾球 [113]。

## 主动挑 vs 被动挑
| | 主动挑 | 被动挑 |
| --- | --- | --- |
| 站位 | 正常上前，球在右肩内/胸口 [114] | 球越低越往后站："拿距离牺牲高度"，早迈弓箭步 [111][113] |
| 击球点 | 抢 3 点高点，胸口高度 [109][112] | 压低重心找回胸口点；贴网球在两点击球 [111][113] |
| 手上 | 引拍小、可加主动发力"球不得了了" [112] | 左手往后往上顶更多、压腿压腰、头下压、轻挑不发力 [111][113] |
| 步伐 | 踏地同时出手，收左腿 [110] | 收左腿更多，撑不住可脚后跟斜落地 [113] |
| 附加 | 可做停顿假动作 [110][114] | 太低太贴网就放弃挑，改搓/勾 [113] |

## 训练方法
- 对镜分解 1-5 做大动作，练熟再减小；"先大后小，肌肉记忆形成就可以做小" [108][107][122]。
- 扔球到右肩、先学高点动作再学低点球，一步一步来 [108]。
- 反手可先挂球只练四和五（推拇指+转小臂），练熟再连 1-2-3 [118][122]。
- 练被动球别站白线等球，往后站好距离再启动 [111]。
- 通用顺序：动作→节奏→步伐→带上球 [122]。

## 子技能难度×收益评级
| 子技能 | 难度 | 收益 | 理由 |
| --- | --- | --- | --- |
| 击球点选择（3点/肚子高度） | 低 | 高 | 一想就通，点对了"随便一碰就往上走"[109] |
| 左手平衡（往后顶） | 低 | 高 | 改一个习惯就解决发力+站稳+迈远三大问题 [110][111] |
| 正手手上动作（倒手腕+收小臂转） | 中 | 高 | 动作链长易做错，但是所有挑球的地基 [105][106] |
| 反手握拍+推拇指转小臂 | 中 | 高 | 握法一换动作就顺，重点在别用错拇指顶法 [115][116] |
| 步伐节奏（踏地同时出手、收左腿） | 中 | 高 | 决定能否在跑动中用出来和快速回位 [110][120] |
| 低点被动起球（压腿压腰压头） | 高 | 高 | 最常被攻击的场景，练会直接减少丢分 [111][113] |
| 挑对角变线 | 低 | 中 | 动作不变只调位置，性价比极高 [114][121] |
| 假动作挑球（保持9点/倒拍） | 高 | 中 | 需要空间感成熟后才做，锦上添花 [114][121] |
