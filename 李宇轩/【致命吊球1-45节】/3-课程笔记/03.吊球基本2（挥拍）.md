# 03. 吊球基本功 2（挥拍）

> 📺 致命吊球 · 第 3 节 · 约 15 分钟
> 教练：李宇轩

这一节讲挥拍动作。教练说这个在杀球网课里已经细细讲过了，这里只快速过一遍，但是**有几个跟吊球相关的点必须留下来看**。

## 一、站姿：侧身，一前一后

挥拍的第一步是站位。教练用了一个比喻：

> 教练原话："我们打球是这样打的，我们要侧身站。侧身站是为了……跟拉弓一样，我不可能这样子拉弓，我要这样子拉弓。我要能够打开、能够转身，所以我们会一个侧身站。侧身站也是帮助我们可以拉开、产生发力的。"

- 右腿朝前一侧，左脚稍微这样站着就行——"不用一定要这样子，舒服就好"。
- 手臂抬起来，右肩、左手都抬上来，"两个肩一高一低"，重心在这边。

## 二、架拍：展肩的目的是"顶住肩胛骨"

教练先纠正一个常见误解——展肩**不是**要求手臂固定成 90 度。

> 教练原话："我们展肩不一定是 90 度。展肩是为了顶这个肩胛骨，就是拉开这肘，往后拉开。就像打人一样，我就是要拉开而已。"

所以球高就架得高，"可以自然 90 度"；球很低就得往下架，"不可能抬那么高"。目的是**给你空间去蓄力发力**。

还有一个小细节：**小臂永远朝上**，"你压得越低，它夹得越多"。左手抬起来是用来**瞄球**的——"球在这个高度，我会这么瞄球，头往上看"。

## 三、2 拍：拉左手 → 塌地 → 顶肘 → 倒腕

这是整套动作的核心，教练拆得很细：

**先拉左手，顶到肩胛骨**（"不用说顶得很多，有顶到就行"），同时**左脚往下塌地**。

关键在"身体不要往前栽"：

> 教练原话："当我拉左手顶到肩胛骨、左脚往下塌的时候，我的身体不是这样（往前）的，我是展肩的。我在塌的时候，左手会继续往后拉回来。"

同时右手做**顶肘**：右肘从外往前，"抬上来，往前走"，手腕自然往后倒。

倒腕是为了翻拍——**因为握拍时食指在一个窄面、拇指在另一个窄面**，所以往后倒的时候，"我会倒食指这边，不是倒这边"，"拇指贴住宽面往后一推，它就倒了"。

> 教练原话："当你做对引拍动作的时候，你上肘、倒手腕，你的拍面会朝这边（朝内），不会是这样子。"

## 四、翻拍（内旋）：最重要的动作

这是教练反复强调"最重要"的一点，不管什么球都要用：

> 教练原话："这个翻拍是打球里面最重要的动作。不管什么球，我挑球、我平抽、我推球、我杀球，我都会有一个这个翻拍动作。因为球是在移动的，我们一定有一个翻拍动作，球才会飞。这是一个合理的、物理的知识。"

如果没有翻拍，"球在动，你平着打，它会切球"。

具体做法：

> 教练原话："你倒拍的时候……食指往前推这块面，推上来的时候，拇指顶在另外一个宽面去把它摆平。在摆平的过程中，它会有一个上来、转。"

还有个节奏细节：**先动小臂，手腕保持往后倒，稍微伸展一点，再让食指带动手腕做内旋**。

## 五、击球点：一定在脑袋前面

教练用正反两遍演示，就是为了说清这点：

> 教练原话："千万千万不可以这么做。整个过程……在你脑袋后面的，不是这样做。整个过程应该在脑袋前面。"

他也说了落点位置：右撇子的话，**球拍在身体右边一点**，"当你转过身来的时候，它在你的右边"——不会在头顶正上方。

## 六、不转身挥拍（应对很边的球）

最后教练补了第二种挥拍——**不转身版**，用在球很靠边的时候：

> 教练原话："很边的球我们都不转身，原因是球太扁了，我们没办法转身。转身基本上都是球在我们上面，我们才可以做转身动作。"

区别就在**重心不换**：

- 转身版：拉下来换重心到左腿，再甩。
- 不转身版：**重心一直在右腿**，稍微侧站，靠上半身转一点点，拉下来顶到肩胛骨、腰顶住，直接上肘甩拍。

## 最后：这节总结

| 要点 | 原话抓手 |
| :--- | :--- |
| 侧身站 = 拉弓 | "跟拉弓一样，我要能够打开、能够转身" |
| 展肩目的是顶肩胛骨、拉开肘 | "展肩是为了顶这个肩胛骨，给你空间去蓄力发力" |
| 塌地时左手继续往后拉，身体不栽 | "一塌下去的时候，记得左手一定要往后拉" |
| 倒腕方向：倒食指那边 | "拇指贴住宽面往后一推，它就倒了" |
| 翻拍是核心 | "不管什么球，我都会有一个翻拍动作，球才会飞" |
| 击球点在前方，不在脑后 | "整个过程应该在脑袋前面" |
| 很边的球不转身 | "球太扁了，我们没办法转身，重心一直在右腿" |
